## 1. 复杂度分析

### 1.1 时间复杂度速查

| 记号 | 含义 | 典型算法 |
| --- | --- | --- |
| O(1) | 常数时间 | 数组下标访问、哈希查找、位运算 |
| O(log n) | 对数时间 | 二分查找、平衡树查找、堆调整 |
| O(n) | 线性时间 | 遍历、单次扫描、线性查找 |
| O(n log n) | 线性对数 | 归并排序、快排平均、堆排、基于比较的排序下界 |
| O(n²) | 平方时间 | 冒泡、选择、插入排序、DP 两维状态 |
| O(2ⁿ) | 指数时间 | 子集枚举、无记忆化递归 |
| O(n!) | 阶乘 | 全排列、旅行商暴力 |

**基于比较的排序下界为 Ω(n log n)**：决策树有 n! 个叶子，树高至少 log₂(n!) = Θ(n log n)。计数排序/基数排序突破此下界靠的是"不比较"。

### 1.2 均摊分析（Amortized Analysis）

某些操作单次很贵，但长期平均很便宜，必须用均摊分析：

| 结构 | 操作 | 单次最坏 | 均摊 |
| --- | --- | --- | --- |
| 动态数组 `vector` | push_back 扩容 | O(n)（搬移） | O(1) |
| 哈希表 rehash | 扩容重散列 | O(n) | O(1) |
| 并查集 | union/find | O(log n) | O(α(n))（反阿克曼，近似常数） |
| 配对堆 | decrease-key | O(1) | O(log n) |

`vector` 扩容均摊 O(1) 的证明：假设容量从 1 开始翻倍，n 次 push_back 的总搬移次数 = 1+2+4+…+n/2 = n-1，摊到 n 次操作每次 < 1。

### 1.3 空间复杂度与递归栈

递归算法的空间复杂度要算**递归栈深度**：快排 O(log n) 平均、O(n) 最坏；归并 O(n)（辅助数组）+ O(log n)（栈）。面试中常被追问"递归深度会不会爆栈"——10 万层递归在默认 8MB 栈上必崩，需改迭代或增大栈。

## 2. 线性表与栈队列

### 2.1 数组 vs 链表

| 维度 | 数组（连续内存） | 链表（节点+指针） |
| --- | --- | --- |
| 随机访问 | O(1) | O(n) |
| 头部插入 | O(n)（搬移） | O(1) |
| 中间插入（已知位置） | O(n) | O(1) |
| 缓存友好性 | 高（顺序访问预取） | 低（指针跳跃） |
| 内存开销 | 无额外 | 每节点指针开销 |

**后端选型**：读多写少、需要随机访问用数组/`vector`；频繁头尾插入用 `deque`；需要 O(1) 中间删除且有迭代器用 `list`（但缓存差，实际很少用）。

### 2.2 栈与队列的应用

| 结构 | 典型应用 |
| --- | --- |
| 栈 | 函数调用栈、括号匹配、表达式求值、DFS、单调栈 |
| 队列 | BFS、任务调度、消息缓冲、滑动窗口、单调队列 |
| 双端队列 deque | 同时需要头尾操作，单调队列的底层 |

### 2.3 单调栈与单调队列【高频】

**单调栈**：栈内元素保持单调递增/递减，用于求解"下一个更大元素"类问题，每个元素入栈出栈各一次，总 O(n)。

```cpp
// 下一个更大元素（单调递减栈）
vector<int> nextGreater(vector<int>& nums) {
    int n = nums.size();
    vector<int> res(n, -1);
    stack<int> st;  // 存下标，栈顶到栈底递减
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.top()] < nums[i]) {
            res[st.top()] = nums[i];
            st.pop();
        }
        st.push(i);
    }
    return res;
}
```

**单调队列**：双端队列维护窗口内的最值，队首到队尾单调。滑动窗口最大值是经典题。

```cpp
// 滑动窗口最大值（单调递减队列）
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    vector<int> res;
    deque<int> dq;  // 存下标，对应值递减
    for (int i = 0; i < (int)nums.size(); ++i) {
        while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();   // 滑出窗口
        if (i >= k - 1) res.push_back(nums[dq.front()]);
    }
    return res;
}
```

**面试考点**：单调栈/队列为什么是 O(n)？——每个元素最多入队一次、出队一次。为什么用 `<=` 而不是 `<`？——相等时弹出旧的，保证队列里存的是"最靠右的最大值"，避免过期。

## 3. 树与二叉树

### 3.1 二叉树遍历

| 遍历 | 顺序 | 非递归实现要点 |
| --- | --- | --- |
| 前序 | 根→左→右 | 栈，先压右再压左 |
| 中序 | 左→根→右 | 一路向左压栈，弹出后处理，转向右 |
| 后序 | 左→右→根 | 双栈或 prev 指针记录上次访问 |
| 层序 | 逐层 | 队列，记录每层大小 |

```cpp
// 非递归中序（面试必手写）
vector<int> inorder(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> st;
    TreeNode* cur = root;
    while (cur || !st.empty()) {
        while (cur) { st.push(cur); cur = cur->left; }
        cur = st.top(); st.pop();
        res.push_back(cur->val);
        cur = cur->right;
    }
    return res;
}
```

**反序列化**：前序 + 中序可唯一确定二叉树（无重复值）；单靠前序不行（根固定但左右划分不确定）。层序序列化（LeetCode 格式）可唯一确定。

### 3.2 二叉搜索树（BST）与平衡树

| 操作 | BST 平均 | BST 最坏（退化成链表） | AVL | 红黑树 |
| --- | --- | --- | --- | --- |
| 查找 | O(log n) | O(n) | O(log n) | O(log n) |
| 插入 | O(log n) | O(n) | O(log n)，最多 2 次旋转 | O(log n)，最多 3 次旋转 |
| 删除 | O(log n) | O(n) | O(log n)，最多 O(log n) 次旋转 | O(log n)，常数次旋转 |

**AVL**：严格平衡，|左右子树高度差| ≤ 1。查找最快（树最矮），但插入删除旋转多，适合读多写少。

**红黑树**：弱平衡，满足五条性质（根黑、叶黑、红节点子必黑、任意节点到叶的黑节点数相同）。最长路径 ≤ 2×最短路径，保证 O(log n)。插入删除旋转少，适合写多，`std::map`/`std::set` 底层即红黑树。

**B 树/B+ 树**：多路平衡树，节点可存多个 key，降低树高（磁盘 IO 次数 = 树高）。B+ 树内部节点不存数据只存 key，所有数据在叶子，叶子链表相连，适合范围查询——MySQL 索引底层即 B+ 树（详见《../05-存储与序列化/01-MySQL数据库精要.md》）。

### 3.3 堆

堆是完全二叉树的数组表示，`priority_queue` 底层即堆。

| 操作 | 复杂度 | 说明 |
| --- | --- | --- |
| 插入 | O(log n) | 末尾加入，向上调整（sift up） |
| 取顶 | O(1) | 根节点 |
| 删顶 | O(log n) | 末尾替换根，向下调整（sift down） |
| 建堆 | O(n) | 从最后一个非叶节点向下调整，非 O(n log n) |

**TopK 问题**：求最大 K 个 → 维护大小 K 的小顶堆（遍历 O(n log K)）；求最小 K 个 → 大顶堆。海量数据不能全载入时，堆是唯一选择。

```cpp
// 求前 K 大元素（小顶堆维护 TopK）
vector<int> topK(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> minHeap;
    for (int x : nums) {
        if ((int)minHeap.size() < k) minHeap.push(x);
        else if (x > minHeap.top()) { minHeap.pop(); minHeap.push(x); }
    }
    vector<int> res;
    while (!minHeap.empty()) { res.push_back(minHeap.top()); minHeap.pop(); }
    return res;  // 升序
}
```

## 4. 哈希表

### 4.1 核心概念

- 平均查找/插入/删除 **O(1)**，最坏 O(n)（所有 key 冲突到同一桶）。
- **负载因子** = 元素数 / 桶数，超过阈值（STL 默认 1.0，Java 默认 0.75）触发 rehash。
- rehash：开辟新桶数组（通常 2 倍），全部元素重新散列，期间服务卡顿——生产系统用**渐进式 rehash**（Redis 采用，每次操作搬几个桶）。

### 4.2 冲突解决

| 方法 | 原理 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 链地址法 | 每桶挂链表 | 实现简单，删除方便 | 指针开销，缓存不友好 |
| 开放定址-线性探测 | 冲突后依次找下一个空槽 | 缓存友好 | 聚集效应，删除需标记 |
| 开放定址-二次探测 | 冲突后偏移 1²,2²,… | 减少聚集 | 可能找不到空槽 |
| 双重哈希 | 用第二个哈希函数算步长 | 分布最均匀 | 计算量大 |

`std::unordered_map` 用链地址法；Google `absl::flat_hash_map` 用开放定址，性能更好但迭代器失效规则不同。

### 4.3 哈希函数设计

好的哈希函数：均匀分布、计算快、雪崩效应（输入变 1 bit 输出变约一半）。字符串常用 FNV-1a、MurmurHash；整数用乘法散列 `hash(k) = (k * A) >> (w - m)`（A 为黄金比例相关常数）。

```cpp
// FNV-1a 字符串哈希（32位）
uint32_t fnv1a(const char* s) {
    uint32_t h = 2166136261u;
    while (*s) { h ^= (uint8_t)*s++; h *= 16777619u; }
    return h;
}
```

**面试考点**：哈希表最坏 O(n) 怎么来的？——所有 key 哈希到同一桶，链表退化成线性查找。怎么防御？——好的哈希函数 + 监控负载因子 + 极端情况用红黑树兜底（Java 8 HashMap 链表超 8 转红黑树）。

## 5. 图论

### 5.1 图的存储

| 存储 | 空间 | 适用 |
| --- | --- | --- |
| 邻接矩阵 | O(V²) | 稠密图、需要 O(1) 查边 |
| 邻接表 | O(V+E) | 稀疏图（绝大多数实际场景） |
| 前向星（链式前向星） | O(E) | 竞赛/高性能，数组模拟链表 |

### 5.2 最短路径算法

| 算法 | 用途 | 复杂度 | 关键点 |
| --- | --- | --- | --- |
| BFS | 无权图最短路 | O(V+E) | 队列，首次访问即最短 |
| Dijkstra | 非负权最短路 | O(E log V) | 优先队列 + 贪心，不能有负权 |
| Bellman-Ford | 含负权边 | O(VE) | 松弛 V-1 轮，可判负环 |
| SPFA | Bellman-Ford 队列优化 | O(E) 平均 / O(VE) 最坏 | 可能被卡退化 |
| Floyd | 全源最短路 | O(V³) | 三重循环，允许负权（无负环） |

```cpp
// Dijkstra（邻接表 + 小顶堆）
vector<int> dijkstra(int s, const vector<vector<pair<int,int>>>& g) {
    int n = g.size();
    vector<int> dist(n, INT_MAX);
    dist[s] = 0;
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;                 // 惰性删除旧状态
        for (auto& [v, w] : g[u])
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
    }
    return dist;
}
```

### 5.3 最小生成树（MST）

| 算法 | 思路 | 复杂度 | 适用 |
| --- | --- | --- | --- |
| Kruskal | 边按权排序，依次加入不形成环的边 | O(E log E) | 稀疏图 |
| Prim | 从起点出发，每次加最近顶点 | O(E log V)（堆优化） | 稠密图 |

Kruskal 用**并查集**判环：每条边 (u,v)，若 find(u)≠find(v) 则加入并 union。

### 5.4 拓扑排序

DAG（有向无环图）的线性排序，u→v 则 u 在 v 前。Kahn 算法：入度为 0 的顶点入队，依次输出并删除其出边，更新入度。复杂度 O(V+E)。可用于判环（输出顶点数 < V 则有环）、任务调度、课程安排。

## 6. 高级数据结构

### 6.1 字典树（Trie）

| 操作 | 复杂度 | 说明 |
| --- | --- | --- |
| 插入 | O(L) | L = 字符串长度 |
| 查询 | O(L) | 逐字符走 |
| 前缀查询 | O(L) | 天然支持 |

适用：自动补全、拼写检查、前缀统计。每个节点是 26 叉（或 map），空间换时间。

```cpp
struct TrieNode {
    TrieNode* children[26] = {};
    bool isEnd = false;
};
class Trie {
    TrieNode* root = new TrieNode();
public:
    void insert(const string& w) {
        TrieNode* p = root;
        for (char c : w) {
            if (!p->children[c-'a']) p->children[c-'a'] = new TrieNode();
            p = p->children[c-'a'];
        }
        p->isEnd = true;
    }
    bool search(const string& w) {
        TrieNode* p = root;
        for (char c : w) {
            if (!p->children[c-'a']) return false;
            p = p->children[c-'a'];
        }
        return p->isEnd;
    }
};
```

### 6.2 并查集（Disjoint Set Union）

支持 union（合并集合）和 find（查根），均摊 O(α(n))。两大优化：**路径压缩**（find 时把节点直连根）和**按秩合并**（小树挂大树）。

```cpp
class DSU {
    vector<int> parent, rank_;
public:
    DSU(int n) : parent(n), rank_(n, 0) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
    bool unite(int x, int y) {
        x = find(x); y = find(y);
        if (x == y) return false;
        if (rank_[x] < rank_[y]) swap(x, y);
        parent[y] = x;
        if (rank_[x] == rank_[y]) rank_[x]++;
        return true;
    }
};
```

### 6.3 树状数组（Fenwick Tree）与线段树

| 结构 | 操作 | 适用 |
| --- | --- | --- |
| 树状数组 | 单点更新 O(log n)、前缀查询 O(log n) | 动态前缀和、逆序对计数 |
| 线段树 | 区间更新/查询 O(log n) | 区间最值、区间和、懒标记 |

树状数组求逆序对：从右往左遍历，`ans += query(nums[i]-1)`（查已出现的比它小的数），然后 `update(nums[i], 1)`。需要离散化处理大数值。

## 7. 排序算法

### 7.1 比较排序速查

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 思想 |
| --- | --- | --- | --- | --- | --- |
| 冒泡 | O(n²) | O(n²) | O(1) | 是 | 相邻交换，每轮冒最大到尾 |
| 选择 | O(n²) | O(n²) | O(1) | 否 | 每轮选最小放前面 |
| 插入 | O(n²) | O(n²) | O(1) | 是 | 逐个插入已排序区间，小数组最快 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 | 分治，合并有序区间 |
| 快排 | O(n log n) | O(n²) | O(log n) | 否 | 分治，partition 分两半 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 否 | 建堆 + 依次取顶 |

### 7.2 非比较排序

| 算法 | 时间 | 空间 | 适用 |
| --- | --- | --- | --- |
| 计数排序 | O(n+k) | O(k) | 值域 k 不大的整数 |
| 基数排序 | O(d(n+k)) | O(n+k) | 整数/字符串，d 为位数 |
| 桶排序 | O(n) 平均 | O(n+k) | 数据均匀分布 |

**快排优化**：三数取中选 pivot、小区间（< 16）换插入排序、尾递归优化（先递归短的一边）、三路快排（处理大量重复元素）。`std::sort` 就是 introsort（快排 + 深度超 2log n 转堆排 + 小区间插入）。

### 7.3 快速选择（Quickselect）

求第 K 大/小元素，平均 O(n)，最坏 O(n²)（随机化 pivot 后期望 O(n)）。思想同快排但只递归包含 K 的那一半。`std::nth_element` 即此算法。

## 8. 动态规划

### 8.1 DP 解题框架

1. **定义状态**：dp[i] 表示什么（明确维度和含义）
2. **状态转移**：dp[i] 怎么从之前的状态来
3. **初始条件**：dp[0]、边界值
4. **遍历顺序**：确保算 dp[i] 时依赖的状态已算出
5. **返回值**：dp[n] 还是 max(dp)

### 8.2 高频 DP 模式

| 模式 | 代表题 | 状态定义 |
| --- | --- | --- |
| 线性 DP | 爬楼梯、打家劫舍、最大子数组 | dp[i] = 前 i 个的最优解 |
| 背包 DP | 0/1 背包、完全背包 | dp[i][w] = 前 i 物品容量 w 的最大价值 |
| 区间 DP | 最长回文子串、矩阵连乘 | dp[l][r] = 区间 [l,r] 的最优解 |
| 序列 DP | 最长递增子序列 LIS、最长公共子序列 LCS | dp[i][j] = 前 i / 前 j 的最优 |
| 状态压缩 DP | 旅行商 TSP、棋盘问题 | dp[mask][i] = 访问集合 mask 最后在 i |

```cpp
// 0/1 背包（一维优化，逆序遍历保证每件物品只用一次）
int knapsack(vector<int>& w, vector<int>& v, int cap) {
    vector<int> dp(cap + 1, 0);
    for (int i = 0; i < (int)w.size(); ++i)
        for (int j = cap; j >= w[i]; --j)
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[cap];
}
```

**0/1 背包 vs 完全背包**：0/1 背包内层逆序（防止重复选），完全背包内层正序（可重复选）。

## 10. 快速参考卡片

```cpp
复杂度速记：n≤10 → O(n!)/O(2^n)
           n≤20 → O(2^n)
           n≤500 → O(n³)
           n≤10⁴ → O(n²) 边缘
           n≤10⁶ → O(n log n)
           n≤10⁷ → O(n)
均摊分析：vector push_back / 哈希 rehash / 并查集 = 近似 O(1)
排序下界：比较排序 Ω(n log n)，非比较排序可突破
TopK：小顶堆维护最大 K 个，O(n log K)
Dijkstra：非负权 O(E log V)，负权用 Bellman-Ford
红黑树：弱平衡 O(log n)，std::map 底层
B+ 树：多路平衡，MySQL 索引，叶子链表支持范围查
```

**常见坑与最佳实践：**
1. `priority_queue` 默认是**大顶堆**，用 `greater<>` 才是小顶堆；pair 比较先比 first 再比 second。
2. Dijkstra 不允许负权边，负权要用 Bellman-Ford/SPFA；有负环则最短路无意义。
3. 递归深搜可能栈溢出（10 万层必崩），用显式栈改写或增大栈空间（`ulimit -s`）。
4. 整数溢出：求和/乘积累加用 `long long`；二分 `mid = l + (r - l) / 2` 防溢出。
5. 哈希表 rehash 期间卡顿，高并发服务用渐进式 rehash 或预分配足够桶数（`reserve`）。
6. 快排最坏 O(n²) 出现在已排序数组 + 固定 pivot，用随机化或三数取中避免。
7. DP 状态定义不清晰是最常见错误——写代码前先在纸上写出 dp[i] 的精确含义。
8. 图论题先判 V 和 E 的规模选存储：E < V² 用邻接表，稠密图用邻接矩阵。
