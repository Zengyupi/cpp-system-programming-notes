## 11. QML 与 Qt Quick 概述

### 11.1 QML 是什么

QML（历史上解作 Qt Meta-Object Language 或 Qt Modeling Language，现官方直接称 QML）是**声明式 UI 语言**：语法像带类型标注的 JSON，树形嵌套描述界面；属性值可写 **JavaScript 表达式**；属性之间靠**属性绑定**自动建立依赖。Qt Quick 是 QML 的运行时与组件库：`QQmlEngine` 解析执行 QML，场景图（Scene Graph）走 GPU 渲染（OpenGL/Vulkan/Metal/D3D，经 RHI 抽象），`QtQuick` 模块提供 Item/Rectangle/Text 等基础元素。

一句话记忆：**QML 是语言，Qt Quick 是框架**（类比 JavaScript 与浏览器）。

### 11.2 Widgets vs QML 选型对比【面试高频】

| 维度 | Widgets | QML / Qt Quick |
|---|---|---|
| 语言 | C++ 命令式 | 声明式 QML + 内嵌 JS |
| 渲染 | CPU 光栅绘制（QPainter/QStyle） | GPU 场景图（批量绘制） |
| 动画 | `QPropertyAnimation` 手写 | 声明式动画元素 + `Behavior on`，几行搞定 |
| 布局 | QBoxLayout 等布局管理器 | 位置器 / 锚点 / Layouts 三体系 |
| 样式 | QStyle / 样式表 | Controls 风格（5 种）+ 自定义 Delegate |
| 典型平台 | 传统桌面（表单/工具/IDE） | 动效 App、移动端、嵌入式 HMI |
| 学习成本 | 需扎实 C++ | 有前端背景上手极快 |
| 成熟度 | 20+ 年极稳定 | Qt5 起成熟，Qt6 主推方向 |

**选型口诀**：桌面工具、重表格文本、纯 C++ 团队 → Widgets；要动画/触屏/跨设备/现代观感 → QML；老 Widgets 项目局部翻新 → `QQuickWidget` 把 QML 嵌进 Widgets（混合开发一句话）。

### 11.3 最小 QML 文档解剖

```qml
// main.qml —— 最小可运行文档（逐行注释）
import QtQuick                      // Qt6 推荐省略版本号；Qt5 建议 import QtQuick 2.15
import QtQuick.Window               // Window 所在模块；Qt6 中 QtQuick 已含可省

Window {                             // 根对象：顶层窗口
    width: 400                       // 数值无单位，逻辑像素（高 DPI 自动缩放）
    height: 300
    visible: true                    // 必须 true 才显示（默认 false）
    title: "Hello QML"

    Rectangle {                      // 嵌套声明 = 父子（Item 树）
        anchors.centerIn: parent     // 锚点：父对象中居中
        width: 200; height: 100      // 同行多语句用分号
        color: "lightsteelblue"      // 命名色 / "#RRGGBB" / Qt.rgba()
        radius: 8

        Text {
            id: label                // id：小写开头、本文件内唯一【高频】
            text: "你好，QML"
            anchors.centerIn: parent
            font.pixelSize: 24
        }
    }
}
```

| 语法成分 | 规则 |
|---|---|
| `import 模块 [版本]` | Qt6 省版本号；Qt5 写 `2.15` 等 |
| 根对象 | `Window` 或任意 `Item`，一个文件一棵树 |
| `id: 名称` | 小写开头、同文件唯一，声明前后均可引用 |
| 属性 `名: 值` | 字面量 / JS 表达式 / 绑定均可 |
| 注释 | `//` 与 `/* */` |
| 父子 | 嵌套即父子；`Window` 直接子项实际挂在其 `contentItem` 上（`parent` 仍正常解析） |

### 11.4 三种运行方式

| 方式 | 命令 / 代码 | 适用 |
|---|---|---|
| qmlscene（Qt5） | `qmlscene main.qml` | 免 C++ 工程，秒级验证原型【速验首选】 |
| qml（Qt5.14+ / Qt6 官方工具） | `qml main.qml` | 同上，Qt6 中取代 qmlscene |
| C++ 加载（正式工程） | `QQmlApplicationEngine::load()` | 产品代码、与 C++ 交互 |

```cpp
// main.cpp
#include <QGuiApplication>
#include <QQmlApplicationEngine>

int main(int argc, char *argv[])
{
    QGuiApplication app(argc, argv);      // 纯 QML 用 QGuiApplication（Widgets 才需 QApplication）

    QQmlApplicationEngine engine;
    const QUrl url(QStringLiteral("qrc:/qt/qml/QmlDemo/Main.qml"));
    QObject::connect(&engine, &QQmlApplicationEngine::objectCreated,
                     &app, [url](QObject *obj, const QUrl &objUrl) {
        if (!obj && url == objUrl) QCoreApplication::exit(-1);  // QML 加载失败退出
    }, Qt::QueuedConnection);
    engine.load(url);                     // 同步加载根对象并显示 Window
    return app.exec();
}
// Qt5 经典写法：engine.load(QUrl(QStringLiteral("qrc:/main.qml")));
// 路径差异根源见 11.5：qt_add_qml_module 默认资源前缀是 qrc:/qt/qml/<模块URI>/
```

```cmake
# CMakeLists.txt（Qt6）
cmake_minimum_required(VERSION 3.16)
project(QmlDemo VERSION 1.0 LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_AUTOMOC ON)                      # 自动跑 moc（Q_OBJECT 必需）

find_package(Qt6 6.4 REQUIRED COMPONENTS Quick QuickControls2)
qt_add_executable(qmldemo main.cpp)

qt_add_qml_module(qmldemo                  # Qt6 专用：自动生成 qmldir 并注册模块
    URI QmlDemo                            # 模块 URI（QML 里 import QmlDemo 用）
    VERSION 1.0
    QML_FILES Main.qml                     # QML 文件清单
    SOURCES backend.cpp backend.h          # C++ 类（配 QML_ELEMENT 自动注册）
)
target_link_libraries(qmldemo PRIVATE Qt6::Quick Qt6::QuickControls2)
```

### 11.5 CMake / qmake 集成要点（Qt5 ↔ Qt6 对照）

| 事项 | Qt5 | Qt6 |
|---|---|---|
| 查找组件 | `find_package(Qt5 COMPONENTS Quick QuickControls2)` | `find_package(Qt6 COMPONENTS Quick QuickControls2)` |
| 链接目标 | `Qt5::Quick` 等 | `Qt6::Quick`、`Qt6::QuickControls2` |
| qmake | `QT += quick quickcontrols2` | 仍支持（新工程不推荐） |
| QML 类型注册 | `qmlRegisterType<T>()` 手写 | `qt_add_qml_module` + `QML_ELEMENT` 自动注册 |
| 资源打包 | `qt5_add_resources()` / RESOURCES | `qt_add_qml_module` 自动打包（`qt_add_resources` 写法一致） |
| 资源路径 | `qrc:/main.qml`（自定义前缀） | 默认 `qrc:/qt/qml/<模块URI>/文件.qml` |
| QML 加载 | `engine.load(QUrl(...))` | 同左；Qt6.5+ 推荐 `engine.loadFromModule("QmlDemo", "Main")` |
| 命令行工具 | `qmlscene` | `qml`（运行）、`qmllint`（检查）、`qmlformat`（格式化） |

## 12. QML 核心语法【重点】

### 12.1 对象与属性

| 概念 | 规则 | 示例 |
|---|---|---|
| 嵌套即父子 | 子对象写在父对象大括号内 | `Rectangle { Text {} }` |
| id | 小写开头、同文件唯一、可先声明后引用 | `id: root` |
| 自定义属性 | `property 类型 名: 初值` | `property string name: "Tom"` |
| 任意类型 | `property var` 接受任意 JS 值 | `property var items: []` |
| 属性别名【高频】 | `property alias 名: 子id.属性`，读写双向转发；也可别名整个子对象 `property alias body: innerRect` | `property alias label: txt.text` |
| 只读属性 | `readonly property`，外部不可赋值 | `readonly property int count: 5` |
| 命名 | 小驼峰 | `font.pixelSize` |

**property alias 是组件化的钥匙**【高频】：把子对象属性"转发"为组件自身属性，外部无感知内部结构，常配 `readonly` 派生状态（如 `readonly property bool empty: title.length === 0`）。

### 12.2 属性绑定【核心概念·高频】

```qml
Rectangle {
    width: parent.width * 0.5     // 绑定：依赖 parent.width，变化时自动重算
    // 若在 JS 语句中出现 width = 100
    //                              // 赋值：立即生效，且【永久断开上面的绑定，无任何警告】
}
```

| 写法 | 性质 | 依赖变化时 |
|---|---|---|
| `width: parent.width * 0.5` | 声明式绑定 | 自动重新求值 |
| `width = 100`（处理器/函数内） | 一次性赋值 | 不再更新【高频坑】 |
| `Qt.binding(function(){...})` | 赋值语句中重建绑定 | 自动重算（修复断绑） |

条件覆盖用 `Binding` 元素（不破坏原绑定）：`Binding { target: rect; property: "width"; value: 50; when: ctrl.compactMode }`。

### 12.3 基础元素大表

| 元素 | 常用属性 | 说明 |
|---|---|---|
| `Item` | `x` `y` `width` `height` `visible` `opacity` `z` `scale` `rotation` `clip` `anchors` | 一切可视元素基类，本身不绘制（常做容器） |
| `Rectangle` | `color` `radius` `border.width` `border.color` `gradient` | `border.width: 1` 才显示边框 |
| `Text` | `text` `color` `font.pixelSize` `font.family` `font.bold` `wrapMode` `elide` `horizontalAlignment` `maximumLineCount` | `wrapMode: Text.WordWrap`；`elide: Text.ElideRight` 超宽省略号 |
| `Image` | `source` `fillMode` `asynchronous` `cache` `sourceSize` | `source: "qrc:/img/a.png"` 或本地/网络 URL |
| `TextInput` | `text` `echoMode` `validator` `maximumLength` `readOnly` | 单行输入，**无背景无边框** |
| `TextEdit` | `text` `wrapMode` `textFormat` `readOnly` | 多行/富文本，同样无装饰 |
| `MouseArea` | 见下表 | 透明交互层，通常 `anchors.fill: parent` |

`Image.fillMode` 模式表：

| fillMode | 效果 |
|---|---|
| `Image.Stretch` | 默认：拉伸填满（变形） |
| `Image.PreserveAspectFit` | 等比完整显示（可能留白） |
| `Image.PreserveAspectCrop` | 等比裁剪填满（配 `clip: true` 防溢出） |
| `Image.Tile` / `TileVertically` / `TileHorizontally` | 平铺 |
| `Image.Pad` | 不缩放，原始尺寸 |

`MouseArea` 速查：

| 成员 | 说明 |
|---|---|
| `onClicked(mouse)` | `mouse.button` / `mouse.x` / `mouse.modifiers` |
| `onPressed` / `onReleased` / `onDoubleClicked` | 按下 / 松开 / 双击（click 与 double 共存需把 onClicked 的 `mouse.accepted = false`） |
| `onPositionChanged` | 默认按住触发；`hoverEnabled: true` 后悬浮移动也触发 |
| `hoverEnabled` | 默认 false；开启后 `containsMouse` 才有意义 |
| `acceptedButtons` | `Qt.LeftButton \| Qt.RightButton` |
| `propagateComposedEvents` | true 时把 click/dblclick 等**组合事件**穿透给下层 MouseArea（一句话：想让下层也响应时用） |
| `preventStealing` | 防止外层 Flickable 窃取拖拽 |

**TextInput 与 TextField 的区别**【高频】：`TextInput`/`TextEdit` 是基础元素，无背景无样式无占位文本；`TextField`/`TextArea` 是 Controls 控件，带边框背景、placeholderText、焦点主题样式。做表单一律用 Controls 版本。

### 12.4 定位与布局：三体系对比【高频坑】

**① 位置器**

| 位置器 | 排列 | 特有属性 |
|---|---|---|
| `Row` / `Column` | 横 / 纵 | `spacing` |
| `Grid` | 网格 | `rows` `columns` `spacing` `flow` |
| `Flow` | 流式自动换行 | `flow` `spacing` |

> 位置器还有 `add`/`move`/`displaced` 三个 Transition 属性：子项**新增移走**播 add、**移动**播 move，列表进出动画极方便（一句话记住）。

**② 锚点**

| 属性 | 说明 |
|---|---|
| `anchors.left/top/right/bottom` | 对齐目标对应边 |
| `anchors.horizontalCenter` / `verticalCenter` | 轴向居中 |
| `anchors.centerIn` / `anchors.fill` | 整体居中 / 四边锚定填满（两者不能同设） |
| `anchors.margins`（及 `leftMargin` 等） | 锚定边距 |
| `anchors.baseline` | 文本基线对齐 |

【坑】同一轴向不能矛盾：`left`+`right`（自动定宽）可以，再加 `horizontalCenter` 报冲突警告。只能锚**父对象或兄弟**，不能跨层级。

**③ Layouts（`import QtQuick.Layouts`）**

| 属性 | 说明 |
|---|---|
| `Layout.fillWidth` / `fillHeight` | 占满剩余空间（窗口缩放必用） |
| `Layout.preferredWidth/Height` | 首选尺寸 |
| `Layout.minimumWidth` / `maximumWidth` | 尺寸上下限 |
| `Layout.alignment` / `Layout.margins` | 对齐 / 边距 |
| 容器 | `ColumnLayout` / `RowLayout` / `GridLayout`（`columns`、`columnSpacing`） |

**三体系选择建议**：

| 场景 | 推荐 |
|---|---|
| 少量固定子项排队（工具栏） | `Row` / `Column` |
| 相对父/兄弟摆放（徽标贴右上角） | 锚点 |
| 窗口可缩放、内容自适应 | **Layouts（必用）**【只用手排位置，窗口一拉伸就乱】 |

```qml
// 典型自适应表单骨架
ColumnLayout {
    anchors.fill: parent
    anchors.margins: 16
    spacing: 10
    TextField { Layout.fillWidth: true }        // 跟随窗口宽
    Button { Layout.alignment: Qt.AlignRight }
    TextArea { Layout.fillWidth: true; Layout.fillHeight: true; Layout.minimumHeight: 80 }
}
```

### 12.5 事件与交互

**处理器命名规则**：信号 `clicked` → 处理器 `onClicked`（`on` + 信号首字母大写）；自定义信号 `signal clicked()` 同理用 `onClicked:` 接。

| 机制 | 要点 |
|---|---|
| `Keys` 附加属性 | 元素需 `focus: true` 且获得 activeFocus；`event.accepted = true` 阻断传播 |
| `Keys.onPressed/onReturnPressed/onEscapePressed` | 具名按键快捷写法 |
| `FocusScope` | 独立焦点域；Controls 内部都是 FocusScope，避免页签间抢焦点（一句话） |
| `Component.onCompleted/onDestruction` | 创建完毕/销毁前回调【高频】 |

```qml
Item {
    focus: true
    Keys.onPressed: (event) => {      // Qt5.15+ 显式参数写法；Qt5 经典隐式注入 event 同样可用
        if (event.key === Qt.Key_Escape) Qt.quit()
    }
    Keys.onReturnPressed: submit()
    Component.onCompleted: console.log("我创建好了")
}
```

### 12.6 JavaScript 集成

| 能力 | 写法 |
|---|---|
| 内联函数 | `function calc(x) { return x * 2 }`（QML 与 C++ `invokeMethod` 均可调） |
| 表达式直接用 JS | `width: a > b ? 100 : 50`、`text: arr.length + " 项"`，数组方法 `filter/map/reduce` 任意用 |
| 处理器内 JS | 条件/循环任意写 |
| 调 C++ 注入的方法 | `backend.login(pwd.text)`（见《04-Qt网络与多线程.md》第 15 章） |
| 调试 | `console.log()` / `console.warn()` / `console.assert(cond, "msg")` |

### 12.7 组件化与 Loader

**文件即组件**：`MyButton.qml`（文件名首字母大写）在同目录或已 import 模块中直接 `MyButton { }` 实例化。

**Loader 动态加载**【高频】：

| Loader 成员 | 说明 |
|---|---|
| `source: "url"` | 按地址加载（空串卸载） |
| `sourceComponent: comp` | 加载内联 `Component { id: comp }` |
| `asynchronous: true` | 异步加载防大页面卡 UI【大页面必开】 |
| `item` | 访问加载出的根对象：`loader.item.width = 50` |
| `status` | `Loader.Null` / `Ready` / `Error` / `Loading`，`onStatusChanged` 监听【异步加载大页面】 |

```qml
Loader {
    id: loader
    source: "qrc:/qt/qml/QmlDemo/HeavyPage.qml"
    asynchronous: true
    onStatusChanged: if (status === Loader.Error) console.log("加载失败", source)
}
Component { id: comp; Rectangle { color: "tomato"; width: 60; height: 60 } }
// 切换：loader.sourceComponent = comp / loader.source = ""
```

**自定义可复用按钮组件**：

```qml
// MyButton.qml —— property alias 转发 + 自定义信号 + MouseArea
import QtQuick

Rectangle {
    id: root
    width: label.implicitWidth + 32; height: 40; radius: 8
    color: area.pressed ? "#1565c0" : area.containsMouse ? "#42a5f5" : "#2196f3"

    property alias text: label.text      // 【高频】转发内部 Text 的 text
    signal clicked()                      // 自定义信号，外部 onClicked: 接

    Text { id: label; anchors.centerIn: parent; color: "white"; font.pixelSize: 15 }
    MouseArea {
        id: area; anchors.fill: parent; hoverEnabled: true
        onClicked: root.clicked()        // 转发
    }
}
```

```qml
MyButton { text: "登录"; onClicked: console.log("clicked") }   // 使用方
```

### 13.3 风格（Style）系统

## 14. 动画与状态

### 14.1 属性动画元素大表

| 动画元素 | 驱动属性 | 关键属性 |
|---|---|---|
| `NumberAnimation` | 数值 | `target` `property` `from` `to` `duration` `easing.type` `loops` |
| `ColorAnimation` | color | `from: "red"` `to: "blue"` `duration` |
| `RotationAnimation` | angle | `direction: RotationAnimation.Clockwise` |
| `Vector3dAnimation` | x/y/z | 同 NumberAnimation |
| `SequentialAnimation` | （容器） | 子动画依次串行 |
| `ParallelAnimation` | （容器） | 子动画同时并行 |
| `PauseAnimation` | （占位） | `duration`，放串行容器里延时 |
| `Behavior` | （行为动画） | 见 14.2【最常用】 |
| `SmoothedAnimation` | 平滑追踪 | `velocity` `duration`（拖拽跟手） |
| `SpringAnimation` | 弹簧物理 | `spring` `damping`（要回弹手感用它，一句话） |
| `PropertyAction` | 同步设值 | 动画序列中**立即**设属性（不动画） |
| `ScriptAction` | 执行 JS | `script`，动画时间轴某刻调代码 |

动画通用属性：`running`（绑定条件启停）、`loops: Animation.Infinite`、`alwaysRunToEnd`、`paused`。

**easing.type 缓动表**（常用十余种，另有 In/Out/InOutSine、Expo 等变体）：

| easing.type | 手感 |
|---|---|
| `Easing.Linear` | 匀速 |
| `Easing.InQuad` / `OutQuad` / `InOutQuad` | 平滑加减速（UI 通用） |
| `Easing.InCubic` / `InOutCubic` | 更强缓入缓出 |
| `Easing.InBack` / `OutBack` / `InOutBack` | 先回撤/过冲回弹 |
| `Easing.OutElastic` / `OutBounce` | 弹性 / 落地弹跳 |
| `Easing.OutOvershoot` | 过冲回稳（Material 动效常用） |

### 14.2 Behavior on：隐式动画【最常用·高频】

```qml
Rectangle {
    id: rect
    width: 100
    Behavior on width { NumberAnimation { duration: 200; easing.type: Easing.OutQuad } }
    MouseArea { anchors.fill: parent; onClicked: rect.width = 300 }
}
```

**语义**：`Behavior on x` 不改变"谁给 x 赋值"，只改变"x 变化时的呈现方式"——属性值立即更新，视觉在 duration 内插值过渡。绑定重算、JS 赋值、状态切换**任何来源**都生效；它也不影响绑定本身（破坏绑定的是赋值语句，Behavior 只让变化过程平滑）。

### 14.3 触发方式表

| 方式 | 写法 | 场景 |
|---|---|---|
| `running` 绑定 | `NumberAnimation { running: btn.pressed; ... }` | 状态驱动 |
| 创建时 on 绑定 | `NumberAnimation on width { from: 0; to: 100 }` | 入场一次性动画 |
| 方法控制 | `anim.start()` / `stop()` / `restart()` / `pause()` / `resume()` / `toggle()` | 命令式 |
| 行为动画 | `Behavior on p { ... }` | 任何来源的属性变化【高频首选】 |
| 状态/过渡 | `Transition` 自动播放 | 见 14.4 |

### 14.4 状态机：states / transitions

```qml
Item {
    id: panel
    property bool open: false             // 外部控制显隐（when 条件引用）
    width: 200; height: 80
    state: "hidden"                       // 当前状态名（"" 是默认状态=初始声明值）

    states: [
        State { name: "shown";  PropertyChanges { target: panel; x: 0; opacity: 1 } },
        State { name: "hidden"; when: !open        // when 条件满足自动切换
                PropertyChanges { target: panel; x: -panel.width; opacity: 0 } }
    ]
    transitions: Transition {
        from: "hidden"; to: "shown"       // 省略 from/to 则匹配所有切换
        NumberAnimation { properties: "x,opacity"; duration: 250; easing.type: Easing.OutCubic }
    }
}
```

| 成员 | 说明 |
|---|---|
| `states: [State{}]` | `PropertyChanges` 声明该状态下的属性目标值 |
| `state = "shown"` | 命令式切换（JS 赋值） |
| `when: 条件` | 条件驱动自动切换 |
| `transitions` | 状态间动画；from/to 可省略表通配 |

## 17. 常见问题与坑

| # | 问题 | 原因与解决方案 |
|---|---|---|
| 1 | 信号槽连接没反应【高频】 | 三查：①类缺 `Q_OBJECT`（moc 没生成元信息）；②`SIGNAL()/SLOT()` 宏字符串拼写或参数签名不匹配；③跨线程参数类型未注册。改用新式 `connect(obj, &C::sig, this, &C::slot)` 让编译期暴露错误。 |
| 2 | `undefined reference to vtable for XXX` | 改了头文件（新增 `Q_OBJECT`/属性/信号）但没重跑 moc。删整个 build 目录重新 cmake/qmake；CMake 确认 `set(CMAKE_AUTOMOC ON)`。 |
| 3 | 子线程直接操作控件崩溃【高频】 | `QWidget`/`QQuickItem` **只能在主（GUI）线程访问**，跨线程 touch 是未定义行为。子线程发信号连主线程槽（自动 queued），或 `QMetaObject::invokeMethod(obj, "update", Qt::QueuedConnection)`。 |
| 4 | `delete`/`deleteLater` 误用及悬垂 | 有 parent 的 QObject 由 parent 析构，手动 `delete` 会 double free → 用 `deleteLater`（事件循环回来后安全删）。注意它只是排队：本轮事件里对象还活着、之后销毁 → 悬垂指针，用 `QPointer<T>` 判空，删除后不再访问。 |
| 5 | `QNetworkReply` 内存泄漏 | `QNetworkAccessManager` **不会**自动释放 reply。用完必删：`connect(reply, &QNetworkReply::finished, reply, &QObject::deleteLater);` 或在 finished 槽里 `reply->deleteLater()`。 |
| 6 | 模态对话框正常，非模态一闪而过 | `exec()` 阻塞事件循环可栈上创建；`show()` 立即返回、函数退出栈对象析构 → **非模态必须 `new` 堆上**并配 `WA_DeleteOnClose`。 |
| 7 | 跨线程 queued 信号自定义类型收不到 | queued 连接需要运行期类型信息。在 `main()` 早期 `qRegisterMetaType<MyStruct>("MyStruct");`。 |
| 8 | QML 绑定失效：父宽度变了子项不跟随【高频】 | 某处 JS 语句 `width = 100` **无警告地断开了绑定**。恢复：`width = Qt.binding(() => parent.width * 0.5)`；或改状态/`Binding{when:...}`；严禁在处理器里直接给绑定属性赋值。 |
| 9 | Q_PROPERTY 变了但 QML 不刷新【高频】 | 属性缺 `NOTIFY`，绑定只在创建时求值一次。补 `NOTIFY xxxChanged`；setter 值变化才 emit（相同值跳过）；真不变用 `CONSTANT`。 |
| 10 | anchors 冲突警告（Cannot specify ...） | 同轴向矛盾锚定（`left`+`right`+`horizontalCenter`）、或 `fill` 与 `centerIn` 同设。每轴向只留一组约束。 |
| 11 | 修改 JS 数组模型，列表不更新【高频】 | 原地 `push/splice` 不触发 QML 重新求值。整体重新赋值 `model = newArray`，或改用 `ListModel`/C++ 模型。 |
| 12 | ListView delegate 滚动后状态串行 | delegate 实例被复用而内部状态没随数据重置。UI 状态绑定模型 role（`checked: model.selected`）；`reuseItems: true` 时在 `ListView.onReused`（Qt5.15+）重置；别在 delegate 里缓存跨数据状态。 |
| 13 | ListView 内容溢出边界/看不到滚动 | 忘了 `clip: true`；或 ListView 自身尺寸为 0（检查 `anchors.fill` / `Layout.fillHeight`）。 |
| 14 | qmlscene 里好看，正式运行样式不同 | 没统一样式设置。C++ `QQuickStyle::setStyle("Material")`（创建 engine 前），或打进 `qtquickcontrols2.conf`（`:/qt/etc/qtquickcontrols2.conf`）。 |
| 15 | windeployqt 拷完仍缺 dll / 白屏 | ①没带 `--qmldir`，QML 模块插件（如 Material）没进包；②编译器 ABI 不一致（MSVC 与 MinGW 运行库混用）；③MSVC 还需 `--compiler-runtime`。逐项核对。 |
| 16 | Qt6 下 `import QtQuick` 报找不到模块 | 省版本号没问题，问题在 URI：模块名大小写敏感；自定义模块 `import QmlDemo` 必须与 `qt_add_qml_module` 的 `URI QmlDemo` 完全一致。 |
| 17 | 控制台刷 `Binding loop detected` | A 绑 B、B 又绑 A 成环。拆环：一方改用 `Binding{when:...}` 或显式赋值，绑定链保持单向无环。 |
| 18 | 高 DPI 下界面模糊 / 尺寸异常 | Qt5 未开 `Qt::AA_EnableHighDpiScaling`（须在 QApplication 构造前）；Qt6 默认开启但取整策略可能不符预期，设 `setHighDpiScaleFactorRoundingPolicy(Qt::HighDpiScaleFactorRoundingPolicy::PassThrough)`。 |
