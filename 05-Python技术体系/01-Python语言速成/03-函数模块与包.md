## 1. 工程场景：从单文件到多文件工具包

50行的日志过滤脚本单文件足够，但当解析器、过滤器、报告生成器、CLI入口各有几百行时，需要拆分成多文件模块，通过import组织成包。C++对应拆分`.cpp`+`.h`用`#include`，Rust用`mod`和`crate`，Python对应**模块（module）**和**包（package）**。

## 2. 函数参数模型

### 2.1 位置/关键字/默认参数

```python
def connect(host: str, port: int, timeout: float = 5.0) -> None:
    print(f"连接 {host}:{port}, 超时 {timeout}s")

connect("192.168.1.1", 8080)                    # 位置参数
connect(host="192.168.1.1", port=8080)          # 关键字参数（顺序任意）
connect("192.168.1.1", port=8080, timeout=10.0) # 混合：位置在前
```

工程建议：参数超过3个或含义不直观时用关键字参数提高可读性。C++没有关键字参数，这是Python的显著优势。

### 2.2 可变默认参数陷阱（重点）

Python最著名的坑之一，C++/Rust工程师几乎必踩。默认参数在**函数定义时**求值一次，所有调用共享同一个对象。

```python
# 错误：默认参数[]在定义时创建，所有调用共享
def add_log(entry: str, log_list: list = []) -> list:
    log_list.append(entry)
    return log_list

print(add_log("启动成功"))  # ['启动成功']
print(add_log("连接建立"))  # ['启动成功', '连接建立'] —— 不是预期的['连接建立']！
```

用C++类比：相当于函数里有一个`static std::vector<std::string>`，跨调用共享。

**正确写法**：用`None`做哨兵，函数内部创建新对象。

```python
def add_log(entry: str, log_list: list = None) -> list:
    if log_list is None:
        log_list = []   # 每次调用创建新的list
    log_list.append(entry)
    return log_list
```

**规则**：默认参数永远用不可变类型（`None`、数字、字符串、tuple），不要用`[]`、`{}`、`set()`。

### 2.3 `*args`与`**kwargs`

`*args`收集任意位置参数为tuple，`**kwargs`收集任意关键字参数为dict。

```python
def log(level: str, *args: str, **kwargs: object) -> None:
    msg = " ".join(str(a) for a in args)
    extra = " ".join(f"{k}={v}" for k, v in kwargs.items())
    print(f"[{level}] {msg} {extra}".strip())

log("INFO", "设备启动", device="GW-01", port=8080)
# [INFO] 设备启动 device=GW-01 port=8080

# 解包传递
params = ("192.168.1.1", 8080)
options = {"timeout": 10.0}
connect(*params, **options)  # 等价connect("192.168.1.1", 8080, timeout=10.0)
```

工程用途：装饰器透传参数、包装函数透传、配置动态传递。C++对应变参模板，Rust不支持变参函数。

### 2.4 仅限位置与仅限关键字参数

Python 3.8+用`/`标记仅限位置参数，`*`标记仅限关键字参数。

```python
def create_packet(
    proto: str,        # /之前：仅限位置
    /,
    length: int,       # 可位置可关键字
    *,
    flags: int = 0,    # *之后：仅限关键字
    verify: bool = True,
) -> bytes:
    return proto.encode() + length.to_bytes(2, "big") + flags.to_bytes(1, "big")

create_packet("TCP", 100, flags=0x01)   # 正确
# create_packet(proto="TCP", 100)        # 错误：proto仅限位置
# create_packet("TCP", 100, 0x01)        # 错误：flags仅限关键字
```

工程价值：仅限位置参数保护内部命名（标准库大量使用）；仅限关键字参数强制显式指定易混淆参数。

## 3. LEGB作用域与闭包

变量查找顺序：**L**ocal（函数内）→ **E**nclosing（外层函数）→ **G**lobal（模块级）→ **B**uilt-in（内置）。

```python
greeting = "Hello"  # G

def outer():
    name = "World"  # E
    def inner():
        msg = "!"   # L
        print(f"{greeting}, {name}{msg}")  # L→E→G→B查找
    inner()
```

修改外层变量需要显式声明：`global`修改全局变量，`nonlocal`修改外层函数变量。

```python
count = 0
def increment():
    global count
    count += 1

def make_counter():
    count = 0
    def counter():
        nonlocal count
        count += 1
        return count
    return counter
```

工程建议：尽量避免`global`，用类实例属性或显式传参替代。

**闭包延迟绑定陷阱**：闭包捕获的是变量本身，不是创建时的值。

```python
# 错误：所有闭包共享循环结束后的i=4
def make_multipliers():
    return [lambda x: x * i for i in range(5)]

fns = make_multipliers()
print(fns[0](10))  # 40 —— 不是0！

# 正确：用默认参数捕获当前值
def make_multipliers():
    return [lambda x, i=i: x * i for i in range(5)]
```

## 4. lambda的适用边界

`lambda 参数: 表达式`创建匿名函数，函数体只能是一个表达式。

```python
# 常用场景：sort/max/filter的key参数
devices = [{"name": "GW-01", "latency": 100}, {"name": "GW-02", "latency": 50}]
devices.sort(key=lambda d: d["latency"])
worst = max(devices, key=lambda d: d["latency"])
```

**适用边界**：适合简单一次性表达式（不超过一行）；不适合复杂逻辑、多语句、需要文档字符串——这些用`def`定义命名函数。C++/Rust的lambda支持多语句，Python的lambda更受限。

## 5. import机制与sys.path

`import module`的执行过程：在`sys.modules`缓存查找→在`sys.path`中查找文件→执行模块顶层代码→创建模块对象加入缓存。**模块顶层代码只执行一次**。

`sys.path`的初始来源：脚本所在目录→`PYTHONPATH`→标准库目录→site-packages。

```python
import sys
print(sys.path)  # 模块搜索路径列表

# import的多种写法
import os
import numpy as np
from pathlib import Path
from collections import defaultdict, deque
```

**工程规则**：
- 不要在代码中修改`sys.path`（`sys.path.insert(0, "../")`是坏味道），用`pip install -e .`安装包或设置`PYTHONPATH`
- 模块名不要与标准库重名（`json.py`、`logging.py`会遮蔽标准库）

## 6. 循环导入

两个模块互相import时，可能在模块未完全初始化时访问属性，导致`ImportError`。

```python
# packet.py → from frame import Frame
# frame.py → from packet import Packet （循环！）
# 执行import packet时，packet还在初始化，Packet还没定义，frame导入失败
```

**解决方案**（按优先级）：
1. **重构**：提取共同依赖到第三个模块（最根本）
2. **延迟导入**：在函数内部import，而不是模块顶层
3. **import模块而非from import**：用`import packet`然后`packet.Packet`（属性访问延迟到运行时）

```python
# 方案2：延迟导入
class Frame:
    def to_packet(self):
        from packet import Packet  # 函数内部导入
        return Packet(self.raw)
```

循环导入通常是设计耦合的信号，优先重构。

## 7. 包结构与__init__

包是包含`__init__.py`的目录。`__init__.py`的作用：标记包、执行初始化、声明`__all__`、提供便捷导入。

```text
log_analyzer/
├── __init__.py
├── cli.py
├── parser.py
├── filter.py
└── reporter.py
```

```python
# log_analyzer/__init__.py
"""工业网关日志分析工具包。"""
__version__ = "0.1.0"
__all__ = ["parse_log", "LogFilter", "generate_report"]

# 便捷导入：用户可以 from log_analyzer import parse_log
from .parser import parse_log
from .filter import LogFilter
from .reporter import generate_report
```

`__init__.py`中不要放复杂逻辑，只放版本号、便捷导入、`__all__`。

## 8. if __name__ == "__main__"与相对导入

模块被直接运行时`__name__`为`"__main__"`，被import时为模块名。这让模块既可导入又可独立运行。

```python
# parser.py
def parse_log(filepath: str) -> list:
    return []

if __name__ == "__main__":
    import sys
    if len(sys.argv) > 1:
        print(f"解析到 {len(parse_log(sys.argv[1]))} 条记录")
```

C++对照：相当于每个`.cpp`都可以有自己的`main()`，但只有链接为可执行文件的那个会被调用。

**相对导入**：用`.`表示当前包，`..`表示上级包，用于包内部导入。

```python
# text_parser.py 中
from . import binary_parser           # 同级
from ..utils.encoding import to_utf8  # 上级
```

相对导入只能在包内部使用，直接运行脚本（`python text_parser.py`）会失败，必须用模块方式（`python -m log_analyzer.parser.text_parser`）或安装为包。

**工程建议**：包内部用相对导入（重构方便），包外部用绝对导入。

## 9. 完整示例：多文件日志分析工具包

```text
log-analyzer/
├── pyproject.toml
└── src/log_analyzer/
    ├── __init__.py
    ├── cli.py
    ├── parser.py
    ├── filter.py
    └── reporter.py
```

`parser.py`：
```python
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path

@dataclass
class LogRecord:
    timestamp: datetime
    level: str
    message: str

def parse_log(filepath: Path | str) -> list[LogRecord]:
    records = []
    with open(filepath, "r", encoding="utf-8") as f:
        for line in f:
            parts = line.strip().split(maxsplit=3)
            if len(parts) < 4: continue
            try:
                ts = datetime.strptime(f"{parts[0]} {parts[1]}", "%Y-%m-%d %H:%M:%S")
            except ValueError: continue
            records.append(LogRecord(ts, parts[2], parts[3]))
    return records
```

`filter.py`：
```python
from datetime import datetime
from .parser import LogRecord

class LogFilter:
    def __init__(self, level: str = "ERROR") -> None:
        self.level = level
        self._order = {"DEBUG":10,"INFO":20,"WARN":30,"ERROR":40}

    def matches(self, r: LogRecord) -> bool:
        return self._order.get(r.level, 0) >= self._order.get(self.level, 0)

    def filter(self, records: list[LogRecord]) -> list[LogRecord]:
        return [r for r in records if self.matches(r)]
```

`reporter.py`：
```python
from collections import Counter
from .parser import LogRecord

def generate_report(records: list[LogRecord]) -> str:
    if not records: return "无记录"
    level_counts = Counter(r.level for r in records)
    lines = [f"总记录: {len(records)}", "级别分布:"]
    for level, count in level_counts.most_common():
        lines.append(f"  {level}: {count}")
    return "\n".join(lines)
```

`cli.py`：
```python
import argparse
from pathlib import Path
from .parser import parse_log
from .filter import LogFilter
from .reporter import generate_report

def main() -> None:
    p = argparse.ArgumentParser(description="日志分析工具")
    p.add_argument("input", type=Path)
    p.add_argument("--level", default="ERROR", choices=["DEBUG","INFO","WARN","ERROR"])
    args = p.parse_args()
    records = parse_log(args.input)
    filtered = LogFilter(level=args.level).filter(records)
    print(generate_report(filtered))

if __name__ == "__main__":
    main()
```

## 10. 快速参考卡片

| 需求 | 做法 |
| --- | --- |
| 默认参数 | `def f(a, b=1)`；**默认值只求值一次**，可变默认值（`[]`/`{}`）是经典陷阱，用 `None` 哨兵 |
| 可变/不可变参数 | 关键字参数 `def f(*, x)` 强制具名；`**kwargs` 收集；`functools.partial` 预绑定 |
| 参数传递语义 | 传的是对象引用（"按赋值传递"）：改 `list.append` 影响调用方，`x = [...]` 不影响 |
| 作用域规则 | LEGB：Local → Enclosing → Global → Builtins；函数内赋值即为局部，需 `global`/`nonlocal` 才能改外层 |
| 导入机制 | `import pkg.mod` / `from pkg.mod import name`；`if __name__ == "__main__":` 保护入口 |
| 包结构 | 目录 + `__init__.py`（可空）；`__all__` 控制 `from pkg import *` |
| 循环导入 | 把导入移到函数内、抽公共模块、或用 `TYPE_CHECKING` 延迟导入 |
| 模块搜索路径 | `sys.path`（脚本目录 + PYTHONPATH + site-packages）；`python -m` 方式运行避免路径偏差 |
| 函数即对象 | 可作参数/返回值/存容器；`functools.lru_cache` 直接装饰 |

## 11. 常见坑

**坑1：模块名与标准库重名**
```python
# 文件命名为 json.py，import json导入的是自己
# AttributeError: module 'json' has no attribute 'loads'
```
永远不要用标准库模块名命名文件。

**坑2：循环导入**
见第6节。优先重构提取共同模块。

**坑3：直接运行含相对导入的脚本**
```bash
python src/log_analyzer/parser.py
# ImportError: attempted relative import with no known parent package
```
用`python -m log_analyzer.parser`或安装为包。

**坑4：修改sys.path**
```python
import sys
sys.path.insert(0, "../..")  # 坏味道
```
用`pip install -e .`或`PYTHONPATH`。

**坑5：from module import * 名称冲突**
显式导入需要的名称，或导入模块本身。

## 12. 本节小结

- **参数模型**：位置+关键字+默认+`*args`/`**kwargs`+仅限位置/关键字，灵活度远超C++/Rust。可变默认参数是最大的坑，永远用`None`做哨兵。
- **作用域LEGB**：Local→Enclosing→Global→Built-in。修改外层用`global`/`nonlocal`，但尽量避免。闭包延迟绑定陷阱用默认参数解决。
- **lambda边界**：只用于简单表达式（key/callback），复杂逻辑用`def`。
- **import机制**：模块顶层代码只执行一次，缓存在`sys.modules`。不要修改`sys.path`，不要与标准库重名。
- **循环导入**：优先重构提取共同模块，其次延迟导入或import模块方式。
- **包结构**：`__init__.py`标记包、提供便捷导入。`if __name__ == "__main__"`让模块既可导入又可独立运行。
- **相对导入**：包内部用`.`/`..`，必须以模块方式运行。
