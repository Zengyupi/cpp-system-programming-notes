## 1. 工程场景：工具脚本需要类吗

C++/Rust工程师写Python时最容易**过度使用类**——因为C++中几乎一切都要放类里（RAII、封装），Rust中数据和行为通过`impl`关联。但Python是多范式语言，函数式写法和OOP同样自然。一个50行的日志过滤脚本，用模块级函数+dict/list就够了。只有需要维护状态、封装多操作、或利用多态时，类才有价值。

## 2. class最小知识

### 2.1 定义、实例化与self

```python
class Device:
    """通讯设备类。"""
    def __init__(self, name: str, ip: str, port: int) -> None:
        self.name = name      # 实例属性
        self.ip = ip
        self.port = port
        self.online = False

    def connect(self) -> bool:
        """实例方法：self指向实例本身。"""
        self.online = True
        return True

dev = Device("GW-01", "192.168.1.1", 8080)
dev.connect()
print(dev.name, dev.online)  # GW-01 True
```

`__init__`对应C++构造函数，`self`对应`this`指针。区别是Python的`self`必须显式写在参数中，实例属性在`__init__`中动态创建（不需要声明成员变量）。

### 2.2 实例属性与类属性

- **实例属性**：`__init__`中`self.xxx = ...`创建，每个实例独立
- **类属性**：类体中直接定义，所有实例共享

```python
class Packet:
    MAX_SIZE = 1500       # 类属性：所有实例共享
    _total = 0             # 类属性：计数器

    def __init__(self, data: bytes) -> None:
        self.data = data   # 实例属性
        self.length = len(data)
        Packet._total += 1

p1, p2 = Packet(b"\x01"), Packet(b"\x02\x03")
print(p1.MAX_SIZE)     # 1500（共享）
Packet.MAX_SIZE = 9000 # 修改类属性影响所有实例
print(p2.MAX_SIZE)     # 9000

# 注意：通过实例赋值类属性名会创建遮蔽的实例属性
p1.MAX_SIZE = 1200
print(p1.MAX_SIZE)     # 1200（实例属性）
print(p2.MAX_SIZE)     # 9000（仍是类属性）
```

工程规则：常量/计数器用类属性；每个实例不同的数据用实例属性；永远不要通过实例赋值类属性名。

### 2.3 三种方法与继承MRO

```python
class Config:
    DEFAULT_TIMEOUT = 5.0

    def __init__(self, timeout: float) -> None:
        self.timeout = timeout

    # 实例方法：操作实例状态（90%的方法）
    def get_timeout(self) -> float:
        return self.timeout

    # 类方法：工厂方法，cls指向类
    @classmethod
    def from_default(cls) -> "Config":
        return cls(cls.DEFAULT_TIMEOUT)

    # 静态方法：放在类命名空间的普通函数，不需要self/cls
    @staticmethod
    def validate_timeout(value: float) -> bool:
        return 0 < value <= 300.0

cfg = Config.from_default()  # 工厂方法
print(Config.validate_timeout(10.0))  # True
```

继承与MRO（方法解析顺序）：Python支持多继承，MRO用C3线性化算法。一句话：**从左到右、深度优先，但父类不会在子类之前被访问**。

```python
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass
print(D.__mro__)  # D → B → C → A → object
```

工程建议：工具脚本中尽量避免多继承，优先用组合（has-a）而非继承（is-a）。

## 3. 工程常用双下划线方法

### 3.1 __init__/__repr__/__str__

`__init__`：构造初始化（见2.1）。

`__repr__`：面向开发者的表示，应尽量能`eval`还原。每个类都该定义。
`__str__`：面向用户的友好表示。只定义`__repr__`时`str()`和`print()`也用它。

```python
class Packet:
    def __init__(self, proto: str, length: int) -> None:
        self.proto = proto
        self.length = length

    def __repr__(self) -> str:
        return f"Packet(proto={self.proto!r}, length={self.length!r})"

    def __str__(self) -> str:
        return f"[{self.proto}] 长度={self.length}"

p = Packet("TCP", 100)
print(repr(p))  # Packet(proto='TCP', length=100)
print(p)         # [TCP] 长度=100
```

### 3.2 __eq__/__hash__

`__eq__`：值相等比较。定义后Python自动将`__hash__`设为`None`（不可哈希），如需可哈希必须显式定义`__hash__`，且`a==b`必须蕴含`hash(a)==hash(b)`。

```python
class DeviceId:
    def __init__(self, vendor: str, serial: str) -> None:
        self.vendor = vendor
        self.serial = serial

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, DeviceId):
            return NotImplemented
        return self.vendor == other.vendor and self.serial == other.serial

    def __hash__(self) -> int:
        return hash((self.vendor, self.serial))

a = DeviceId("ACME", "SN001")
b = DeviceId("ACME", "SN001")
print(a == b)    # True（值相等）
print(a is b)    # False（不同对象）
d = {a: "网关"}  # 可哈希，可做dict key
print(d[b])      # 网关（b能找到a的值，因为相等且哈希相同）
```

C++对照：`__eq__`对应`operator==`，`__hash__`对应`std::hash`特化。Rust对应`PartialEq`/`Eq`和`Hash`。

### 3.3 __iter__/__call__

`__iter__`+`__next__`：可迭代对象，能用`for`遍历。实际工程中大多数用生成器（`yield`）更简单，见《05-迭代器生成器与装饰器.md》。

`__call__`：对象可以像函数一样调用。用于需要维护状态的"函数"（限流器、计数器、带配置的处理器）。

```python
class RateLimiter:
    def __init__(self, max_per_second: float) -> None:
        self._interval = 1.0 / max_per_second
        self._last = 0.0

    def __call__(self) -> bool:
        import time
        now = time.monotonic()
        if now - self._last >= self._interval:
            self._last = now
            return True
        return False

limiter = RateLimiter(2.0)
print(limiter())  # True（像函数一样调用）
print(limiter())  # False
```

C++对照：对应仿函数`operator()`，Rust对应`Fn`/`FnMut` trait。

### 3.4 __enter__/__exit__（上下文管理器）

定义这两个方法的对象可以用`with`语句，对应C++ RAII。`__enter__`获取资源，`__exit__`释放资源（无论是否有异常）。

```python
class TcpConnection:
    def __init__(self, host: str, port: int) -> None:
        self.host = host
        self.port = port
        self._sock = None

    def __enter__(self) -> "TcpConnection":
        import socket
        self._sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self._sock.connect((self.host, self.port))
        return self

    def __exit__(self, exc_type, exc_val, exc_tb) -> bool:
        if self._sock:
            self._sock.close()
        return False  # False=不吞异常

with TcpConnection("192.168.1.1", 8080) as conn:
    print("使用连接")
# 退出with块，自动关闭
```

标准库中文件对象、`threading.Lock`、`socket.socket`等都是上下文管理器。更简单的实现方式见《05-迭代器生成器与装饰器.md》的`contextlib.contextmanager`。

## 4. dataclass：当C++struct/Rust struct用

`dataclass`（3.7+）自动生成`__init__`、`__repr__`、`__eq__`等样板代码。纯数据载体的首选。

```python
from dataclasses import dataclass, field
from datetime import datetime

@dataclass
class LogRecord:
    timestamp: datetime
    level: str
    message: str
    source: str = "unknown"           # 默认值
    extra: dict = field(default_factory=dict)  # 可变默认值必须用default_factory

r = LogRecord(timestamp=datetime.now(), level="ERROR", message="连接超时")
print(r)  # 自动__repr__
r2 = LogRecord(timestamp=r.timestamp, level="ERROR", message="连接超时")
print(r == r2)  # True（自动__eq__）
```

常用参数：
- `frozen=True`：不可变（对应Rust默认不可变），自动可哈希
- `order=True`：自动生成比较运算符
- `slots=True`（3.10+）：用`__slots__`减少内存

```python
@dataclass(frozen=True)
class ImmutablePoint:
    x: int
    y: int

p = ImmutablePoint(1, 2)
# p.x = 3  # dataclasses.FrozenInstanceError
```

C++/Rust对照：相当于C++ struct + 自动生成的构造/比较/打印，或Rust的`#[derive(Debug, PartialEq)]`。**只要是纯数据载体，优先用dataclass，不要手写`__init__`和`__repr__`。**

## 5. Enum与property

**Enum**：有限集合的命名常量，替代魔法字符串/数字。

```python
from enum import Enum, auto

class ProtocolType(Enum):
    TCP = 1
    UDP = 2
    MQTT = auto()  # 自动赋值3

proto = ProtocolType.TCP
print(proto.name, proto.value)  # TCP 1
print(ProtocolType(1))           # ProtocolType.TCP（从值获取）
for p in ProtocolType: print(p.name)
```

**property**：将方法变成属性访问，用于计算属性、只读属性、属性校验。

```python
class Packet:
    def __init__(self, data: bytes) -> None:
        self._data = data

    @property
    def length(self) -> int:
        """计算属性：每次访问时计算。"""
        return len(self._data)

    @property
    def data(self) -> bytes:
        return self._data

    @data.setter
    def data(self, value: bytes) -> None:
        if len(value) > 1500:
            raise ValueError("报文过长")
        self._data = value

pkt = Packet(b"\x01\x02")
print(pkt.length)  # 2（像属性访问，不需要括号）
pkt.data = b"\x03" # 触发setter校验
```

C++对照：对应getter/setter方法，但Python的property语法更自然。不要过度使用——简单存取直接用公共属性即可。

## 6. 何时根本不需要类

这是最重要的判断准则。**不需要类的场景**：
1. 纯函数操作（输入→输出，无状态）：`parse_line(line) -> dict`
2. 一次性脚本（从头到尾执行一次）
3. 简单数据容器：用dataclass/tuple/dict/NamedTuple
4. 函数组合足够：几个函数通过参数传递数据

**需要类的场景**：
1. 维护状态（连接管理器、状态机、解析器上下文）
2. 多态/继承（不同协议的编码器）
3. 封装复杂逻辑（一组相关操作+数据）
4. 可调用对象（像函数但维护状态）

**判断口诀**：一个类只有一个方法（除`__init__`），它可能应该是函数。所有方法都是静态方法，它可能应该是模块。

```python
# 反例：过度设计
class LogParser:
    def __init__(self, filepath: str) -> None: self.filepath = filepath
    def parse(self) -> list: ...  # 只有一个方法

# 正例：简单函数
def parse_log(filepath: str) -> list: ...
```

## 7. 完整示例：报文解析器类设计

需要维护状态的流式解析器，适合用类：

```python
from dataclasses import dataclass
from enum import Enum, auto
from typing import Iterator

class PacketType(Enum):
    DATA = auto()
    HEARTBEAT = auto()
    CONTROL = auto()

@dataclass(frozen=True)
class Packet:
    pkt_type: PacketType
    seq: int
    payload: bytes

class PacketParser:
    """流式报文解析器：从字节流逐步提取完整报文。"""
    HEADER_SIZE = 4  # 1字节类型 + 2字节序号 + 1字节长度

    def __init__(self) -> None:
        self._buffer = bytearray()
        self._packets: list[Packet] = []

    def feed(self, data: bytes) -> None:
        """喂入新数据，尝试解析完整报文。"""
        self._buffer.extend(data)
        self._try_parse()

    def _try_parse(self) -> None:
        while len(self._buffer) >= self.HEADER_SIZE:
            try:
                pkt_type = PacketType(self._buffer[0])
            except ValueError:
                self._buffer.pop(0)
                continue
            seq = int.from_bytes(self._buffer[1:3], "big")
            length = self._buffer[3]
            total = self.HEADER_SIZE + length
            if len(self._buffer) < total:
                break
            payload = bytes(self._buffer[self.HEADER_SIZE:total])
            self._packets.append(Packet(pkt_type, seq, payload))
            del self._buffer[:total]

    def __iter__(self) -> Iterator[Packet]:
        return iter(self._packets)

    def __len__(self) -> int:
        return len(self._packets)

    @property
    def pending_bytes(self) -> int:
        return len(self._buffer)

# 使用
parser = PacketParser()
parser.feed(bytes([1, 0, 1, 3, 0xAA, 0xBB, 0xCC]))  # DATA报文
parser.feed(bytes([2, 0, 2, 0]))                        # HEARTBEAT报文
for pkt in parser:
    print(f"{pkt.pkt_type.name} seq={pkt.seq} payload={pkt.payload.hex()}")
print(f"已解析{len(parser)}个，缓冲区剩余{parser.pending_bytes}字节")
```

## 8. 常见坑

**坑1：可变类属性被所有实例共享**
```python
class Manager:
    items = []  # 类属性，可变！
m1, m2 = Manager(), Manager()
m1.items.append(1)
print(m2.items)  # [1] —— 被污染
# 正确：在__init__中创建实例属性
```

**坑2：__eq__定义后不可哈希**
定义了`__eq__`的类，Python自动将`__hash__`设为`None`。需要可哈希时必须显式定义`__hash__`，或用`@dataclass(frozen=True)`。

**坑3：property递归调用**
```python
@property
def name(self): return self.name  # 递归！RecursionError
# 正确：属性存储在_name，property访问_name
```

**坑4：多继承super()行为不符合预期**
多继承时`super()`调用的是MRO中的下一个类，不一定是父类。先打印`__mro__`确认顺序，尽量避免多继承。

## 9. 本节小结

- **类的最小知识**：`__init__`初始化、`self`指向实例、实例属性vs类属性、实例/类/静态三种方法、继承与MRO。工具脚本尽量避免多继承。
- **常用双下划线方法**：`__repr__`（每个类都该有）、`__eq__`/`__hash__`（值相等与可哈希，定义eq后必须显式定义hash）、`__iter__`/`__call__`（可迭代/可调用对象）、`__enter__`/`__exit__`（上下文管理器=RAII）。
- **dataclass**：纯数据载体首选，自动生成样板代码，对应C++struct/Rust struct。可变默认值用`field(default_factory=...)`。
- **Enum**：有限集合的命名常量，替代魔法字符串/数字。
- **property**：计算属性、只读属性、属性校验，对应C++ getter/setter但更自然。
- **何时不需要类**：纯函数、一次性脚本、简单数据容器、函数组合足够时，直接用函数+模块。只有维护状态、多态、封装复杂逻辑时才用类。
