## 1. 工程场景：Python 在调试与性能分析中的角色

C++/Rust 程序的调试与性能分析产生大量半结构化报告：ASAN 的内存错误报告、Valgrind 的内存泄漏报告、perf 的性能采样、gdb 的调用栈、core 文件的崩溃信息。这些报告通常很长且重复，手动分析效率极低。

Python 在调试与性能分析中的角色是**报告解析器和自动化编排器**：用正则解析报告中的关键字段（错误类型、调用栈、地址、大小），按错误签名聚类去重，统计高频问题，批量处理 core 文件，关联不同来源的日志时间线。

典型场景：

- **Sanitizer 报告聚类**：CI 跑完后产生几十份 ASAN 报告，按错误类型和调用栈聚类，找出唯一 bug
- **Valgrind 泄漏统计**：从 Valgrind 输出中提取所有内存泄漏点，按泄漏大小排序
- **perf 热点分析**：解析 `perf report` 输出，统计热点函数，生成火焰图数据
- **core 批量回溯**：对一批 core 文件批量跑 gdb `bt`，提取崩溃函数和调用栈
- **跨日志关联**：把程序日志、ASAN 报告、系统日志按时间线关联，还原崩溃前的事件序列

## 2. 批量解析 Sanitizer 报告

### 2.1 ASAN 报告解析

AddressSanitizer（ASAN）报告格式固定，包含错误类型、访问地址、调用栈（分配/释放/访问）、影子内存信息。

```python
import re
from collections import defaultdict
from dataclasses import dataclass, field

@dataclass
class AsanReport:
    error_type: str = ""
    access_address: str = ""
    access_size: int = 0
    thread_id: int = 0
    stack: list[dict] = field(default_factory=list)  # 访问调用栈
    allocation_stack: list[dict] = field(default_factory=list)  # 分配调用栈
    free_stack: list[dict] = field(default_factory=list)  # 释放调用栈
    raw: str = ""

# 匹配 ASAN 报告头部
ASAN_HEADER = re.compile(
    r'==\d+==ERROR: AddressSanitizer: (?P<type>[\w-]+) '
    r'(?:on (?P<access>unknown address|address) )?'
    r'(?P<addr>0x[0-9a-f]+)?'
    r'(?: at pc (?P<pc>0x[0-9a-f]+) bp (?P<bp>0x[0-9a-f]+) sp (?P<sp>0x[0-9a-f]+))?'
)

# 匹配调用栈帧
STACK_FRAME = re.compile(
    r'#(?P<frame>\d+)\s+(?P<addr>0x[0-9a-f]+)\s+'
    r'(?P<func>.+?)\s+'
    r'(?P<file>[\w./-]+):(?P<line>\d+)(?::(?P<col>\d+))?'
)

# 匹配栈段标题
STACK_SECTION = re.compile(
    r'(?P<section>allocated by thread \d+ here|freed by thread \d+ here|'
    r'previously allocated by thread \d+ here|SUMMARY:)'
)

def parse_asan_report(text: str) -> AsanReport:
    """解析单份 ASAN 报告。"""
    report = AsanReport(raw=text)
    current_stack = "stack"

    for line in text.splitlines():
        # 报告头部
        m = ASAN_HEADER.search(line)
        if m:
            report.error_type = m.group("type")
            if m.group("addr"):
                report.access_address = m.group("addr")
            # 提取访问大小
            size_m = re.search(r'(\d+)-byte', line)
            if size_m:
                report.access_size = int(size_m.group(1))
            continue

        # 栈段切换
        m = STACK_SECTION.search(line)
        if m:
            section = m.group("section")
            if "allocated" in section:
                current_stack = "allocation_stack"
            elif "freed" in section:
                current_stack = "free_stack"
            elif "SUMMARY" in section:
                current_stack = None
            continue

        # 调用栈帧
        if current_stack:
            m = STACK_FRAME.search(line)
            if m:
                frame = {
                    "frame": int(m.group("frame")),
                    "address": m.group("addr"),
                    "function": m.group("func").strip(),
                    "file": m.group("file"),
                    "line": int(m.group("line")),
                }
                getattr(report, current_stack).append(frame)

    return report

def parse_asan_reports_from_log(log_text: str) -> list[AsanReport]:
    """从包含多份 ASAN 报告的日志中提取所有报告。"""
    # 按 ASAN 报告头部分割
    parts = re.split(r'(==\d+==ERROR: AddressSanitizer:)', log_text)
    reports = []
    for i in range(1, len(parts), 2):
        report_text = parts[i] + parts[i + 1] if i + 1 < len(parts) else parts[i]
        reports.append(parse_asan_report(report_text))
    return reports
```

### 2.2 UBSAN/TSAN 报告解析

UBSAN（未定义行为 sanitizer）和 TSAN（线程 sanitizer）报告格式与 ASAN 类似但更简单。

```python
@dataclass
class UbsanReport:
    error_type: str = ""
    file: str = ""
    line: int = 0
    message: str = ""
    stack: list[dict] = field(default_factory=list)

UBSAN_PATTERN = re.compile(
    r'(?P<file>[\w./-]+):(?P<line>\d+):(?P<col>\d+):\s+'
    r'runtime error: (?P<msg>.+)'
)

def parse_ubsan_report(text: str) -> UbsanReport:
    """解析 UBSAN 报告。"""
    report = UbsanReport()
    for line in text.splitlines():
        m = UBSAN_PATTERN.search(line)
        if m:
            report.file = m.group("file")
            report.line = int(m.group("line"))
            report.message = m.group("msg")
            # 从消息中提取错误类型
            if "load of value" in report.message:
                report.error_type = "invalid_load"
            elif "store to" in report.message:
                report.error_type = "invalid_store"
            elif "signed integer overflow" in report.message:
                report.error_type = "integer_overflow"
            elif "division by zero" in report.message:
                report.error_type = "division_by_zero"
            elif "null pointer" in report.message:
                report.error_type = "null_pointer"
            else:
                report.error_type = "other"
            continue

        m = STACK_FRAME.search(line)
        if m and report.error_type:
            report.stack.append({
                "frame": int(m.group("frame")),
                "function": m.group("func").strip(),
                "file": m.group("file"),
                "line": int(m.group("line")),
            })

    return report

@dataclass
class TsanReport:
    error_type: str = ""  # data_race, deadlock, etc.
    thread1_stack: list[dict] = field(default_factory=list)
    thread2_stack: list[dict] = field(default_factory=list)
    variable: str = ""

def parse_tsan_report(text: str) -> TsanReport:
    """解析 TSAN 报告（简化版）。"""
    report = TsanReport()
    if "data race" in text:
        report.error_type = "data_race"
    elif "deadlock" in text:
        report.error_type = "deadlock"
    elif "lock-order-inversion" in text:
        report.error_type = "lock_order_inversion"
    else:
        report.error_type = "other"

    # 提取变量名
    m = re.search(r"(?:atomic|global) '(?P<var>[^']+)'", text)
    if m:
        report.variable = m.group("var")

    # 提取两个线程的调用栈（简化：按 "Thread T" 分割）
    sections = re.split(r'Thread T\d+ \(tid=\d+, ', text)
    for i, section in enumerate(sections[1:3], 1):
        stack = []
        for line in section.splitlines():
            m = STACK_FRAME.search(line)
            if m:
                stack.append({
                    "frame": int(m.group("frame")),
                    "function": m.group("func").strip(),
                    "file": m.group("file"),
                    "line": int(m.group("line")),
                })
        if i == 1:
            report.thread1_stack = stack
        else:
            report.thread2_stack = stack

    return report
```

### 2.3 报告聚类与去重

大量 Sanitizer 报告中，很多是同一个 bug 的重复触发。按"错误类型 + 关键调用栈帧"聚类。

```python
def report_signature(report: AsanReport | UbsanReport | TsanReport,
                     stack_depth: int = 3) -> str:
    """生成报告签名：错误类型 + 前 N 个非系统调用栈帧。"""
    # 获取主调用栈
    if isinstance(report, AsanReport):
        stack = report.stack
        error_type = report.error_type
    elif isinstance(report, UbsanReport):
        stack = report.stack
        error_type = report.error_type
    else:
        stack = report.thread1_stack
        error_type = report.error_type

    # 过滤掉系统库帧（只保留项目源码帧）
    project_frames = [
        f for f in stack
        if not f["file"].startswith(("/usr", "/lib", "/opt", "???"))
        and "sanitizer" not in f["file"].lower()
    ]

    # 取前 N 个项目帧
    key_frames = project_frames[:stack_depth]
    frame_str = "|".join(
        f"{f['function']}@{f['file']}:{f['line']}" for f in key_frames
    )
    return f"{error_type}::{frame_str}"

def cluster_reports(reports: list) -> dict:
    """按签名聚类报告。"""
    clusters = defaultdict(list)
    for report in reports:
        sig = report_signature(report)
        clusters[sig].append(report)

    # 按报告数降序排列
    sorted_clusters = sorted(clusters.items(), key=lambda x: -len(x[1]))
    return {
        "total_reports": len(reports),
        "unique_bugs": len(sorted_clusters),
        "clusters": [
            {
                "signature": sig,
                "count": len(reps),
                "error_type": reps[0].error_type if hasattr(reps[0], "error_type") else "unknown",
                "sample": reps[0],
            }
            for sig, reps in sorted_clusters
        ],
    }
```

## 3. 解析 Valgrind 报告

Valgrind 的 memcheck 工具输出包含内存泄漏、无效读写、使用未初始化值等报告。

```python
@dataclass
class ValgrindLeak:
    leak_type: str = ""  # definitely_lost, indirectly_lost, possibly_lost, still_reachable
    size: int = 0
    blocks: int = 0
    stack: list[dict] = field(default_factory=list)

@dataclass
class ValgrindError:
    error_type: str = ""  # InvalidRead, InvalidWrite, UseOfUninit, etc.
    address: str = ""
    size: int = 0
    stack: list[dict] = field(default_factory=list)

VALGRIND_LEAK = re.compile(
    r'(?P<type>definitely lost|indirectly lost|possibly lost|still reachable): '
    r'(?P<size>[\d,]+) bytes in (?P<blocks>[\d,]+) blocks'
)

VALGRIND_ERROR = re.compile(
    r'==\d+== (Invalid (?P<op>read|write) of size (?P<size>\d+))'
)

VALGRIND_FRAME = re.compile(
    r'==\d+==\s+at 0x[0-9A-F]+: (?P<func>.+?) \((?P<file>[^:]+):(?P<line>\d+)\)'
)

def parse_valgrind_output(text: str) -> dict:
    """解析 Valgrind memcheck 输出。"""
    leaks = []
    errors = []
    current_leak = None
    current_error = None

    for line in text.splitlines():
        # 泄漏记录
        m = VALGRIND_LEAK.search(line)
        if m:
            if current_leak:
                leaks.append(current_leak)
            leak_type = m.group("type").replace(" ", "_")
            current_leak = ValgrindLeak(
                leak_type=leak_type,
                size=int(m.group("size").replace(",", "")),
                blocks=int(m.group("blocks").replace(",", "")),
            )
            continue

        # 错误记录
        m = VALGRIND_ERROR.search(line)
        if m:
            if current_error:
                errors.append(current_error)
            current_error = ValgrindError(
                error_type=f"Invalid{m.group('op').capitalize()}",
                size=int(m.group("size")),
            )
            continue

        # 调用栈帧
        m = VALGRIND_FRAME.search(line)
        if m:
            frame = {
                "function": m.group("func").strip(),
                "file": m.group("file"),
                "line": int(m.group("line")),
            }
            if current_leak:
                current_leak.stack.append(frame)
            elif current_error:
                current_error.stack.append(frame)

    if current_leak:
        leaks.append(current_leak)
    if current_error:
        errors.append(current_error)

    # 汇总
    total_definitely_lost = sum(l.size for l in leaks if l.leak_type == "definitely_lost")

    return {
        "leaks": leaks,
        "errors": errors,
        "summary": {
            "total_leaks": len(leaks),
            "total_errors": len(errors),
            "definitely_lost_bytes": total_definitely_lost,
        },
    }
```

## 4. 解析 perf 输出做统计

`perf record` 采样后，`perf report --stdio` 输出文本格式的热点函数列表。

```python
@dataclass
class PerfSymbol:
    overhead: float = 0.0
    command: str = ""
    shared_object: str = ""
    symbol: str = ""

PERF_LINE = re.compile(
    r'\s*(?P<overhead>[\d.]+)%\s+'
    r'(?P<command>\S+)\s+'
    r'(?P<dso>\S+)\s+'
    r'\[(?P<symbol_type>\w+)\]\s+'
    r'(?P<symbol>.+)'
)

def parse_perf_report(text: str) -> list[PerfSymbol]:
    """解析 perf report --stdio 输出。"""
    symbols = []
    for line in text.splitlines():
        m = PERF_LINE.match(line)
        if m:
            symbols.append(PerfSymbol(
                overhead=float(m.group("overhead")),
                command=m.group("command"),
                shared_object=m.group("dso"),
                symbol=m.group("symbol").strip(),
            ))
    return symbols

def aggregate_by_function(symbols: list[PerfSymbol]) -> list[dict]:
    """按函数名聚合计时（忽略命令和 DSO）。"""
    agg = defaultdict(float)
    for s in symbols:
        agg[s.symbol] += s.overhead

    return [
        {"symbol": sym, "overhead": round(overhead, 2)}
        for sym, overhead in sorted(agg.items(), key=lambda x: -x[1])
    ]

def generate_flamegraph_data(symbols: list[PerfSymbol], output_path: Path):
    """生成火焰图输入数据（折叠栈格式）。

    注意：perf report --stdio 只有平面数据，真正的火焰图需要
    perf script 输出的调用栈。这里演示平面数据的统计。
    """
    top20 = aggregate_by_function(symbols)[:20]
    lines = []
    for item in top20:
        # 折叠栈格式：func1;func2 count
        lines.append(f"{item['symbol']} {int(item['overhead'] * 100)}")
    output_path.write_text("\n".join(lines) + "\n", encoding="utf-8")

# 用法：从 perf 采集到解析
def run_perf_analysis(program: Path, output_dir: Path, duration: int = 10):
    """运行 perf 采集并解析。"""
    output_dir.mkdir(parents=True, exist_ok=True)
    perf_data = output_dir / "perf.data"

    # 采集
    subprocess.run(
        ["perf", "record", "-F", "99", "-g", "-o", str(perf_data),
         str(program), "&"],
        timeout=duration,
    )

    # 生成文本报告
    result = subprocess.run(
        ["perf", "report", "--stdio", "-i", str(perf_data)],
        capture_output=True, text=True,
    )

    # 解析
    symbols = parse_perf_report(result.stdout)
    top_funcs = aggregate_by_function(symbols)

    # 保存
    report = {
        "total_samples": len(symbols),
        "top_functions": top_funcs[:20],
    }
    (output_dir / "perf_report.json").write_text(
        json.dumps(report, indent=2, ensure_ascii=False), encoding="utf-8"
    )

    print(f"Top 10 热点函数:")
    for i, func in enumerate(top_funcs[:10], 1):
        print(f"  {i:2d}. {func['overhead']:5.1f}%  {func['symbol'][:70]}")
```

## 5. gdb 批处理与 GDB Python API

### 5.1 gdb 批处理模式

gdb 支持 `-batch` 模式：执行一系列命令后退出，适合脚本化调试。

```python
def gdb_batch(program: Path, commands: list[str],
              core_file: Path | None = None,
              timeout: int = 30) -> str:
    """gdb 批处理模式。"""
    cmd = ["gdb", "-batch", "-nx", str(program)]
    if core_file:
        cmd.append(str(core_file))
    for c in commands:
        cmd.extend(["-ex", c])

    result = subprocess.run(cmd, capture_output=True, text=True, timeout=timeout)
    return result.stdout + result.stderr

# 常用批处理命令
def backtrace_full(program: Path, core_file: Path) -> str:
    """完整回溯。"""
    return gdb_batch(program, ["bt full", "info threads", "quit"], core_file)

def dump_registers(program: Path, core_file: Path) -> str:
    """转储寄存器。"""
    return gdb_batch(program, ["info registers", "bt", "quit"], core_file)

def analyze_core(program: Path, core_file: Path) -> dict:
    """分析 core 文件，提取崩溃信息。"""
    output = gdb_batch(program, [
        "bt",
        "frame 0",
        "info args",
        "info locals",
        "quit",
    ], core_file)

    result = {"core": str(core_file), "raw": output}

    # 提取崩溃函数
    m = re.search(r'#0\s+(?:0x[0-9a-f]+ in )?(.+?)\s+\(', output)
    if m:
        result["crash_function"] = m.group(1).strip()

    # 提取信号
    m = re.search(r'Program received signal (\w+),', output)
    if m:
        result["signal"] = m.group(1)

    return result
```

### 5.2 GDB Python API 基础

GDB 内置 Python 解释器，可以在 gdb 中运行 Python 脚本，访问调试对象（帧、变量、类型、断点）。这比解析 gdb 文本输出强大得多。

```python
# gdb_script.py — 在 gdb 中运行: gdb -x gdb_script.py -batch program
import gdb

def get_backtrace() -> list[dict]:
    """获取当前线程的调用栈（结构化数据）。"""
    frames = []
    frame = gdb.newest_frame()
    while frame:
        try:
            name = frame.name() or "???"
            sal = frame.find_sal()
            fileline = f"{sal.symtab.filename}:{sal.line}" if sal and sal.symtab else "???"
            frames.append({
                "function": name,
                "file": fileline,
                "address": str(frame.pc()),
            })
        except gdb.error:
            frames.append({"function": "???", "file": "???", "address": "???"})
        frame = frame.older()
    return frames

def get_local_variables() -> dict:
    """获取当前帧的局部变量。"""
    frame = gdb.selected_frame()
    block = frame.block()
    variables = {}
    while block:
        for symbol in block:
            if symbol.is_variable or symbol.is_argument:
                try:
                    value = symbol.value(frame)
                    variables[symbol.name] = str(value)
                except gdb.error:
                    variables[symbol.name] = "<optimized out>"
        block = block.superblock
    return variables

# 执行并输出 JSON
def main():
    gdb.execute("run", to_string=True)
    bt = get_backtrace()
    locals_ = get_local_variables()
    import json
    print(json.dumps({"backtrace": bt, "locals": locals_}, indent=2))

main()
```

运行方式：

```bash
gdb -batch -x gdb_script.py ./myprogram
```

### 5.3 自定义命令与遍历容器

GDB Python API 可以注册自定义命令，方便在交互式调试中使用。

```python
# gdb_commands.py — 在 gdb 中 source 后使用
import gdb

class PrintVector(gdb.Command):
    """打印 std::vector 内容。

    用法: pvec <vector_variable> [max_elements]
    """

    def __init__(self):
        super().__init__("pvec", gdb.COMMAND_DATA)

    def invoke(self, arg, from_tty):
        args = arg.split()
        if not args:
            print("用法: pvec <vector_variable> [max_elements]")
            return

        var_name = args[0]
        max_elements = int(args[1]) if len(args) > 1 else 100

        try:
            vec = gdb.parse_and_eval(var_name)
        except gdb.error as e:
            print(f"错误: {e}")
            return

        # std::vector 内部结构: _M_start, _M_finish, _M_end_of_storage
        # (libstdc++ 实现，其他 STL 实现可能不同)
        try:
            start = vec["_M_impl"]["_M_start"]
            finish = vec["_M_impl"]["_M_finish"]
            size = int(finish - start)
            print(f"std::vector {var_name}: size={size}")

            for i in range(min(size, max_elements)):
                elem = (start + i).dereference()
                print(f"  [{i}] = {elem}")

            if size > max_elements:
                print(f"  ... 还有 {size - max_elements} 个元素")
        except gdb.error as e:
            print(f"解析 vector 失败: {e}")

class PrintMap(gdb.Command):
    """打印 std::map 内容（简化版）。"""

    def __init__(self):
        super().__init__("pmap", gdb.COMMAND_DATA)

    def invoke(self, arg, from_tty):
        args = arg.split()
        if not args:
            print("用法: pmap <map_variable> [max_elements]")
            return

        var_name = args[0]
        max_elements = int(args[1]) if len(args) > 1 else 50

        try:
            # 用 gdb 的 pretty-printer 输出，比手动解析节点更可靠
            result = gdb.execute(f"print {var_name}", to_string=True)
            print(result)
        except gdb.error as e:
            print(f"错误: {e}")

class DumpAllThreads(gdb.Command):
    """打印所有线程的调用栈。"""

    def __init__(self):
        super().__init__("dumpthreads", gdb.COMMAND_STACK)

    def invoke(self, arg, from_tty):
        inferior = gdb.selected_inferior()
        for thread in inferior.threads():
            thread.switch()
            print(f"\n=== Thread {thread.num} (gdb id) ===")
            gdb.execute("bt 10", to_string=False)

# 注册命令
PrintVector()
PrintMap()
DumpAllThreads()
print("自定义命令已加载: pvec, pmap, dumpthreads")
```

### 5.4 自动打印与断点脚本

GDB Python API 可以在断点处自动执行 Python 代码，实现条件打印、数据收集、自动继续。

```python
import gdb

class LogBreakpoint(gdb.Breakpoint):
    """断点：命中时打印变量值并自动继续，不中断程序。"""

    def __init__(self, spec, variable):
        super().__init__(spec)
        self.variable = variable
        self.hit_count = 0

    def stop(self):
        """返回 False 表示不停止，自动继续。"""
        self.hit_count += 1
        try:
            value = gdb.parse_and_eval(self.variable)
            frame = gdb.selected_frame()
            print(f"[命中 #{self.hit_count}] {frame.name()}: {self.variable} = {value}")
        except gdb.error:
            print(f"[命中 #{self.hit_count}] 无法读取 {self.variable}")
        return False  # 不停止

class ConditionalBreakpoint(gdb.Breakpoint):
    """条件断点：只有满足条件时才中断。"""

    def __init__(self, spec, condition_func):
        super().__init__(spec)
        self.condition_func = condition_func

    def stop(self):
        try:
            return self.condition_func()
        except Exception:
            return False

# 使用示例
def setup():
    # 在 process_message 函数处设置日志断点，自动打印 msg_type
    LogBreakpoint("process_message", "msg_type")

    # 条件断点：只有 error_code != 0 时才中断
    def check_error():
        try:
            return int(gdb.parse_and_eval("error_code")) != 0
        except gdb.error:
            return False
    ConditionalBreakpoint("handle_response", check_error)

    print("断点已设置，程序将自动运行...")
    gdb.execute("run")

setup()
```

```python
def batch_core_analysis(program: Path, core_dir: Path,
                         output_dir: Path, timeout: int = 30) -> dict:
    """批量分析 core 文件。"""
    output_dir.mkdir(parents=True, exist_ok=True)
    results = []

    core_files = sorted(core_dir.glob("core*"))
    print(f"发现 {len(core_files)} 个 core 文件")

    for i, core_file in enumerate(core_files):
        print(f"[{i + 1}/{len(core_files)}] 分析 {core_file.name}...")
        try:
            info = analyze_core(program, core_file)
            results.append(info)

            # 保存完整回溯
            bt_output = backtrace_full(program, core_file)
            (output_dir / f"{core_file.name}.bt").write_text(bt_output, encoding="utf-8")

        except subprocess.TimeoutExpired:
            results.append({"core": str(core_file), "error": "timeout"})
        except Exception as e:
            results.append({"core": str(core_file), "error": str(e)})

    # 聚类
    crash_functions = defaultdict(int)
    for r in results:
        if "crash_function" in r:
            crash_functions[r["crash_function"]] += 1

    summary = {
        "total_cores": len(results),
        "analyzed": sum(1 for r in results if "error" not in r),
        "failed": sum(1 for r in results if "error" in r),
        "crash_function_distribution": dict(
            sorted(crash_functions.items(), key=lambda x: -x[1])
        ),
        "details": results,
    }

    (output_dir / "core_analysis.json").write_text(
        json.dumps(summary, indent=2, ensure_ascii=False), encoding="utf-8"
    )

    print(f"\n{'='*60}")
    print(f"分析完成: {summary['analyzed']}/{summary['total_cores']} 成功")
    print(f"崩溃函数分布:")
    for func, count in list(crash_functions.items())[:10]:
        print(f"  {count:3d}x  {func}")

    return summary
```

## 7. 跨日志时间线关联

崩溃发生时，需要把程序日志、ASAN 报告、系统日志（dmesg、syslog）按时间线关联，还原事件序列。

```python
from datetime import datetime, timedelta

@dataclass
class TimelineEvent:
    timestamp: datetime
    source: str  # app_log, asan, dmesg, syslog
    level: str   # INFO, WARN, ERROR, FATAL
    message: str

def parse_app_log_line(line: str) -> TimelineEvent | None:
    """解析程序日志行。"""
    m = re.match(
        r'(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d+)\s+\[(\w+)\]\s+(.*)',
        line,
    )
    if not m:
        return None
    return TimelineEvent(
        timestamp=datetime.strptime(m.group(1), "%Y-%m-%d %H:%M:%S.%f"),
        source="app_log",
        level=m.group(2),
        message=m.group(3),
    )

def parse_dmesg_line(line: str) -> TimelineEvent | None:
    """解析 dmesg 行（需要 -T 选项输出人类可读时间）。"""
    m = re.match(r'\[(\w+ \d+ \d+:\d+:\d+ \d+)\]\s+(.*)', line)
    if not m:
        return None
    try:
        ts = datetime.strptime(m.group(1), "%a %b %d %H:%M:%S %Y")
    except ValueError:
        return None
    msg = m.group(2)
    level = "ERROR" if any(kw in msg.lower() for kw in ["segfault", "oom", "killed", "error"]) else "INFO"
    return TimelineEvent(timestamp=ts, source="dmesg", level=level, message=msg)

def build_timeline(log_files: list[Path], crash_time: datetime,
                   window_before: int = 60, window_after: int = 5) -> list[TimelineEvent]:
    """构建崩溃前后的时间线。

    window_before: 崩溃前多少秒
    window_after: 崩溃后多少秒
    """
    events = []
    start = crash_time - timedelta(seconds=window_before)
    end = crash_time + timedelta(seconds=window_after)

    parsers = {
        "app.log": parse_app_log_line,
        "dmesg": parse_dmesg_line,
    }

    for log_file in log_files:
        parser = parsers.get(log_file.name, parse_app_log_line)
        with log_file.open("r", encoding="utf-8", errors="replace") as f:
            for line in f:
                event = parser(line.rstrip("\n"))
                if event and start <= event.timestamp <= end:
                    events.append(event)

    # 按时间排序
    events.sort(key=lambda e: e.timestamp)
    return events

def print_timeline(events: list[TimelineEvent]):
    """打印时间线。"""
    for e in events:
        marker = "!!!" if e.level in ("ERROR", "FATAL") else "   "
        print(f"{marker} [{e.timestamp.strftime('%H:%M:%S.%f')[:-3]}] "
              f"[{e.source:8s}] [{e.level:5s}] {e.message[:100]}")
```

## 8. 完整实战：调试报告聚合器

整合以上能力，实现一个调试报告聚合器：扫描目录中的 ASAN/UBSAN/Valgrind 报告和 core 文件，解析、聚类、生成统一报告。

```python
#!/usr/bin/env python3
"""调试报告聚合器。

用法: python debug_aggregator.py --reports-dir reports/ --program build/myapp --output debug_report.json
"""
import argparse
import json
from pathlib import Path
from collections import defaultdict

class DebugReportAggregator:
    """调试报告聚合器。"""

    def __init__(self, reports_dir: Path, program: Path | None = None):
        self.reports_dir = reports_dir
        self.program = program
        self.asan_reports = []
        self.ubsan_reports = []
        self.tsan_reports = []
        self.valgrind_reports = []
        self.core_files = []

    def scan(self):
        """扫描报告目录。"""
        for f in self.reports_dir.rglob("*"):
            if not f.is_file():
                continue
            name = f.name.lower()
            if "asan" in name or f.suffix == ".asan":
                self.asan_reports.append(f)
            elif "ubsan" in name or f.suffix == ".ubsan":
                self.ubsan_reports.append(f)
            elif "tsan" in name or f.suffix == ".tsan":
                self.tsan_reports.append(f)
            elif "valgrind" in name or f.suffix == ".valgrind":
                self.valgrind_reports.append(f)
            elif name.startswith("core"):
                self.core_files.append(f)

        print(f"扫描完成:")
        print(f"  ASAN: {len(self.asan_reports)}")
        print(f"  UBSAN: {len(self.ubsan_reports)}")
        print(f"  TSAN: {len(self.tsan_reports)}")
        print(f"  Valgrind: {len(self.valgrind_reports)}")
        print(f"  Core: {len(self.core_files)}")

    def parse_all(self) -> dict:
        """解析所有报告。"""
        all_sanitizer = []

        # ASAN
        for f in self.asan_reports:
            text = f.read_text(encoding="utf-8", errors="replace")
            reports = parse_asan_reports_from_log(text)
            all_sanitizer.extend(reports)

        # UBSAN
        for f in self.ubsan_reports:
            text = f.read_text(encoding="utf-8", errors="replace")
            all_sanitizer.append(parse_ubsan_report(text))

        # TSAN
        for f in self.tsan_reports:
            text = f.read_text(encoding="utf-8", errors="replace")
            all_sanitizer.append(parse_tsan_report(text))

        # Valgrind
        valgrind_summary = {"leaks": [], "errors": [], "summary": {}}
        for f in self.valgrind_reports:
            text = f.read_text(encoding="utf-8", errors="replace")
            vg = parse_valgrind_output(text)
            valgrind_summary["leaks"].extend(vg["leaks"])
            valgrind_summary["errors"].extend(vg["errors"])

        # Core 文件
        core_results = []
        if self.program and self.core_files:
            for core in self.core_files[:20]:  # 最多分析 20 个
                try:
                    info = analyze_core(self.program, core)
                    core_results.append(info)
                except Exception as e:
                    core_results.append({"core": str(core), "error": str(e)})

        # 聚类
        sanitizer_clusters = cluster_reports(all_sanitizer)

        # Valgrind 泄漏按大小排序
        leaks_sorted = sorted(
            valgrind_summary["leaks"],
            key=lambda l: l.size, reverse=True,
        )

        return {
            "sanitizer": {
                "total_reports": sanitizer_clusters["total_reports"],
                "unique_bugs": sanitizer_clusters["unique_bugs"],
                "clusters": [
                    {
                        "error_type": c["error_type"],
                        "count": c["count"],
                        "signature": c["signature"][:200],
                    }
                    for c in sanitizer_clusters["clusters"]
                ],
            },
            "valgrind": {
                "total_leaks": len(valgrind_summary["leaks"]),
                "total_errors": len(valgrind_summary["errors"]),
                "top_leaks": [
                    {
                        "type": l.leak_type,
                        "size": l.size,
                        "blocks": l.blocks,
                        "top_frame": l.stack[0]["function"] if l.stack else "???",
                    }
                    for l in leaks_sorted[:10]
                ],
            },
            "core_files": {
                "total": len(self.core_files),
                "analyzed": len(core_results),
                "crash_functions": dict(
                    sorted(
                        defaultdict(int, {
                            r.get("crash_function", "unknown"): 1
                            for r in core_results
                            if "crash_function" in r
                        }).items(),
                        key=lambda x: -x[1],
                    )
                ),
            },
        }

    def generate_report(self, output_path: Path):
        """生成聚合报告。"""
        self.scan()
        report = self.parse_all()

        output_path.parent.mkdir(parents=True, exist_ok=True)
        output_path.write_text(
            json.dumps(report, indent=2, ensure_ascii=False, default=str),
            encoding="utf-8",
        )

        # 打印摘要
        print(f"\n{'='*60}")
        print(f"调试报告聚合摘要:")
        print(f"  Sanitizer: {report['sanitizer']['total_reports']} 份报告, "
              f"{report['sanitizer']['unique_bugs']} 个唯一 bug")
        print(f"  Valgrind: {report['valgrind']['total_leaks']} 处泄漏, "
              f"{report['valgrind']['total_errors']} 个错误")
        print(f"  Core: {report['core_files']['total']} 个文件")
        print(f"\n报告已保存: {output_path}")

def main():
    parser = argparse.ArgumentParser(description="调试报告聚合器")
    parser.add_argument("--reports-dir", type=Path, required=True)
    parser.add_argument("--program", type=Path, help="被测程序（用于 core 分析）")
    parser.add_argument("--output", type=Path, default=Path("debug_report.json"))
    args = parser.parse_args()

    aggregator = DebugReportAggregator(args.reports_dir, args.program)
    aggregator.generate_report(args.output)

if __name__ == "__main__":
    main()
```

## 10. 常见坑与避坑指南

| 坑 | 现象 | 解决方案 |
|---|---|---|
| ASAN 报告地址不可读 | 调用栈全是 `???:?` | 编译时加 `-g -fno-omit-frame-pointer`，保留符号表 |
| gdb 批处理超时 | 大程序 gdb 加载符号表慢 | 增大 timeout，或用 `gdb -nx` 跳过初始化脚本 |
| GDB Python API 版本差异 | 脚本在旧版 gdb 上报错 | 检查 `gdb.VERSION`，用 try/except 兼容旧版 API |
| Valgrind 报告帧不全 | 调用栈只有几层 | 编译时加 `-g`，Valgrind 加 `--num-callers=50` |
| perf 符号解析失败 | 热点函数显示为 `[unknown]` | 编译加 `-fno-omit-frame-pointer -g`，perf 加 `--call-graph dwarf` |
| core 文件不完整 | 分析时栈帧损坏 | 检查 `ulimit -c unlimited`，确认 core 文件完整生成 |
| 时间线时间不同步 | 程序日志和 dmesg 时间对不上 | 统一用 NTP 同步，dmesg 用 `-T` 选项，注意时区 |
| Sanitizer 报告聚类不准 | 同一个 bug 被分成多个 cluster | 调整签名的栈深度，过滤更多系统帧，或用模糊匹配 |
| GDB Python 脚本影响性能 | 日志断点导致程序变慢 | 减少断点数量，用 `silent` 命令，避免在热点函数设断点 |

## 11. 本节小结

- ASAN/UBSAN/TSAN 报告格式固定，用正则可提取错误类型、访问地址、调用栈，按"错误类型+关键栈帧"聚类去重
- Valgrind 报告包含内存泄漏（definitely/indirectly/possibly lost）和无效读写，按泄漏大小排序找出最严重问题
- perf report 输出可解析为热点函数列表，按函数名聚合计时，生成统计报告
- gdb 批处理模式（`-batch -ex`）适合脚本化调试，GDB Python API 可访问帧、变量、类型，注册自定义命令和条件断点
- 自定义 gdb 命令（pvec/pmap/dumpthreads）可遍历 STL 容器、打印所有线程栈，提升交互式调试效率
- 日志断点和条件断点可自动打印变量、按条件中断，适合长时间运行的调试场景
- core 文件批量回溯用 gdb 批处理提取崩溃函数，按崩溃函数聚类找出高频崩溃点
- 跨日志时间线关联把程序日志、ASAN 报告、dmesg 按时间排序，还原崩溃前后事件序列
- 调试报告聚合器整合了 Sanitizer、Valgrind、core 文件的解析和聚类，生成统一的 JSON 报告
