## 1. 工程场景：为什么系统程序员需要文件批处理

写 C++/Rust 的日常工作中，文件系统操作无处不在：编译后 `build/` 目录里散落着 `.o`、`.a`、`.so`、`compile_commands.json`；CI 跑完后需要把日志按日期归档；切换分支前要清理 `cmake-build-*` 目录；交叉编译产物要按平台分类打包。

shell 一行流（`find ... -exec ...`）在简单场景够用，但一旦涉及条件判断、编码转换、原子重命名、错误汇总，shell 就变得难以维护。Python 的 `pathlib` + 标准库提供了跨平台、可测试、可组合的文件批处理能力，是系统程序员工具箱的基础层。

典型场景：

- **构建产物整理**：把 `build/` 下的可执行文件按 `debug/release` + `x86_64/arm64` 分类到 `dist/`
- **日志归档**：扫描 `logs/`，把超过 7 天的 `.log` 压缩到 `archive/YYYY-MM/`，删除原始文件
- **代码目录清洗**：递归删除 `__pycache__`、`.pytest_cache`、`*.pyc`，统计释放空间

## 2. pathlib 全解：面向对象的路径操作

`pathlib` 是 Python 3.4 引入的面向对象路径库，3.6 后成为官方推荐。相比 `os.path` 字符串操作，`Path` 对象支持链式调用、运算符拼接、跨平台一致性。

### 2.1 Path 基础与路径拼接

```python
from pathlib import Path

# 构造路径
p = Path("/home/dev/project/build")
p = Path.home() / "project" / "build"          # / 运算符拼接
p = Path.cwd() / ".." / "include"               # 相对路径

# 路径分解
p = Path("/home/dev/project/src/main.cpp")
p.name          # 'main.cpp'
p.stem          # 'main'
p.suffix        # '.cpp'
p.suffixes      # ['.cpp'] （处理 main.tar.gz 时为 ['.tar', '.gz']）
p.parent        # PosixPath('/home/dev/project/src')
p.parents[0]    # 同上
p.parents[1]    # PosixPath('/home/dev/project')
p.parts         # ('/', 'home', 'dev', 'project', 'src', 'main.cpp')

# 路径转换
p.resolve()     # 解析符号链接和 ..，返回绝对路径
p.absolute()    # 转绝对路径（不解析符号链接）
p.with_suffix(".hpp")   # 替换扩展名
p.with_name("util.cpp") # 替换文件名
p.with_stem("util")     # Python 3.9+，替换主名
```

**C++/Rust 场景**：根据源文件路径推导对应头文件或构建产物路径。

```python
src = Path("src/net/tcp_connection.cpp")
header = src.with_suffix(".hpp")               # src/net/tcp_connection.hpp
obj = Path("build") / src.with_suffix(".o")    # build/src/net/tcp_connection.o
```

### 2.2 路径查询与判断

```python
p = Path("build/libcore.a")

p.exists()          # 是否存在
p.is_file()         # 是否文件
p.is_dir()          # 是否目录
p.is_symlink()      # 是否符号链接
p.is_absolute()     # 是否绝对路径
p.is_reserved()     # Windows 保留名（如 CON, NUL）

# 文件元信息
stat = p.stat()
stat.st_size        # 字节数
stat.st_mtime       # 修改时间（epoch 秒）
stat.st_mode        # 权限位
p.owner()           # 属主（POSIX）
p.group()           # 属组
```

### 2.3 目录遍历与 glob 递归

`Path.glob()` 支持 `*`、`**`、`?`、`[seq]` 模式，返回迭代器（惰性）。

```python
build = Path("build")

# 非递归：只扫当前目录
for f in build.glob("*.o"):
    print(f)

# 递归：** 匹配任意层级
for f in build.glob("**/*.o"):
    print(f)

# rglob 是 glob("**/pattern") 的简写
for f in build.rglob("*.so"):
    print(f)

# 迭代目录条目（不递归，性能更好）
for entry in build.iterdir():
    if entry.is_file() and entry.suffix == ".a":
        print(entry)
```

**性能注意**：`glob("**/*")` 在大目录树（如含 `.git`、`node_modules`）下会很慢。应先用 `iterdir()` 跳过无关目录，或在 `walk` 中修剪。

```python
# 手动 walk 并修剪目录（Python 3.12+ 支持 Path.walk）
for root, dirs, files in Path(".").walk(top_down=True):
    # 原地修改 dirs 可阻止进入这些目录
    dirs[:] = [d for d in dirs if d not in (".git", "build", "node_modules")]
    for f in files:
        if f.endswith(".cpp"):
            print(Path(root) / f)
```

## 3. 文件读写与编码治理

### 3.1 读写文本与二进制

`Path` 对象自带 `read_text()` / `write_text()` / `read_bytes()` / `write_bytes()`，适合小文件一次性读写。大文件用 `open()` 流式处理。

```python
p = Path("config.toml")

# 一次性读写（小文件）
text = p.read_text(encoding="utf-8")
p.write_text(text, encoding="utf-8")

# 二进制
data = p.read_bytes()
p.write_bytes(data)

# 追加写入
with p.open("a", encoding="utf-8") as f:
    f.write("# appended comment\n")

# 大文件流式读取（GB 级日志）
with Path("huge.log").open("r", encoding="utf-8", errors="replace") as f:
    for line in f:
        if "ERROR" in line:
            process(line)
```

### 3.2 编码：utf-8-sig、gbk 与乱码排查

系统程序员经常遇到跨平台编码问题：Windows 上 Visual Studio 生成的源码可能是 GBK，Linux 工具链期望 UTF-8；某些日志工具输出带 BOM 的 UTF-8。

```python
# 读取带 BOM 的 UTF-8 文件（自动去掉 BOM）
text = Path("vs_output.log").read_text(encoding="utf-8-sig")

# 读取 GBK 文件（Windows 中文环境常见）
text = Path("old_source.cpp").read_text(encoding="gbk")

# 批量转换编码：GBK → UTF-8
for src in Path("src_legacy").rglob("*.cpp"):
    raw = src.read_bytes()
    try:
        text = raw.decode("gbk")
    except UnicodeDecodeError:
        text = raw.decode("gbk", errors="replace")
        print(f"警告：{src} 含无法解码字节，已替换")
    dst = Path("src_utf8") / src.relative_to("src_legacy")
    dst.parent.mkdir(parents=True, exist_ok=True)
    dst.write_text(text, encoding="utf-8")
```

**乱码排查流程**：

1. 用 `chardet` 或 `charset-normalizer` 检测编码（第三方库，`pip install charset-normalizer`）
2. 检查文件头是否有 BOM（`EF BB BF` = UTF-8 BOM，`FF FE` = UTF-16 LE）
3. 尝试 `errors="replace"` 读取，定位乱码位置
4. 确认终端/编辑器显示编码与文件实际编码一致

```python
# 检测编码（charset-normalizer 3.x）
from charset_normalizer import from_path
result = from_path("mystery.log").best()
print(result.encoding)   # 如 'gbk'
```

### 3.3 换行符与行尾处理

Windows 用 `\r\n`（CRLF），Linux/macOS 用 `\n`（LF）。Git 的 `core.autocrlf` 可能在 checkout 时转换，导致构建脚本中换行符不一致。

```python
# 统一转换为 LF
for p in Path("scripts").rglob("*.sh"):
    text = p.read_text(encoding="utf-8")
    p.write_text(text.replace("\r\n", "\n"), encoding="utf-8", newline="\n")

# 检测换行符类型
raw = Path("file.txt").read_bytes()
if b"\r\n" in raw:
    print("CRLF")
elif b"\n" in raw:
    print("LF")
```

`open()` 的 `newline` 参数控制换行符转换：`None`（默认）启用通用换行模式，`""` 不转换，`"\n"` 写入时用 `\n`。

## 4. 批量重命名、分类与移动

### 4.1 批量重命名构建产物

场景：CMake 构建后，可执行文件名是 `myapp`，需要按平台+构建类型重命名为 `myapp-linux-x86_64-release`。

```python
import platform
from pathlib import Path

def rename_build_artifacts(build_dir: Path, build_type: str = "release"):
    system = platform.system().lower()
    machine = platform.machine().lower()
    tag = f"{system}-{machine}-{build_type}"

    renamed = []
    for p in build_dir.iterdir():
        if p.is_file() and not p.suffix:  # 无扩展名 = 可执行文件
            new_name = f"{p.stem}-{tag}"
            new_path = p.with_name(new_name)
            p.rename(new_path)
            renamed.append((p.name, new_name))
    return renamed

# 用法
renamed = rename_build_artifacts(Path("build"), "release")
for old, new in renamed:
    print(f"{old} -> {new}")
```

### 4.2 按扩展名/日期分类归档

场景：日志目录下混杂 `.log`、`.log.gz`、`.csv`、`.txt`，按类型和月份归档。

```python
import gzip
import shutil
from datetime import datetime
from pathlib import Path

def archive_logs(log_dir: Path, archive_dir: Path, days: int = 7):
    now = datetime.now()
    for p in log_dir.glob("*.log"):
        mtime = datetime.fromtimestamp(p.stat().st_mtime)
        age = (now - mtime).days
        if age < days:
            continue

        # 按修改月份归档
        month_dir = archive_dir / mtime.strftime("%Y-%m")
        month_dir.mkdir(parents=True, exist_ok=True)

        # 压缩
        gz_path = month_dir / f"{p.name}.gz"
        with p.open("rb") as f_in, gzip.open(gz_path, "wb") as f_out:
            shutil.copyfileobj(f_in, f_out)

        # 验证后删除原文件
        if gz_path.exists() and gz_path.stat().st_size > 0:
            p.unlink()
            print(f"归档并删除: {p} -> {gz_path}")
        else:
            print(f"压缩失败，保留原文件: {p}")
```

### 4.3 安全移动与冲突处理

`Path.rename()` 在跨文件系统时会失败（`OSError: [Errno 18] Invalid cross-device link`），应使用 `shutil.move()`。目标已存在时需要处理冲突。

```python
import shutil
from pathlib import Path

def safe_move(src: Path, dst: Path, overwrite: bool = False) -> Path:
    """安全移动文件，处理跨设备和命名冲突。"""
    if not src.exists():
        raise FileNotFoundError(src)

    dst.parent.mkdir(parents=True, exist_ok=True)

    if dst.exists():
        if overwrite:
            dst.unlink()
        else:
            # 自动加后缀避免覆盖
            stem, suffix = dst.stem, dst.suffix
            counter = 1
            while dst.exists():
                dst = dst.with_name(f"{stem}_{counter}{suffix}")
                counter += 1

    shutil.move(str(src), str(dst))
    return dst
```

## 5. 临时文件与目录监控

### 5.1 tempfile 安全临时文件

构建脚本中经常需要临时文件：编译中间产物、测试数据、diff 缓存。`tempfile` 提供跨平台安全临时文件，自动清理。

```python
import tempfile
from pathlib import Path

# 临时文件（with 块结束自动删除）
with tempfile.NamedTemporaryFile(mode="w", suffix=".cpp", delete=True, encoding="utf-8") as f:
    f.write('int main() { return 0; }\n')
    f.flush()
    # 编译这个临时文件
    # subprocess.run(["g++", f.name, "-o", "/tmp/test_out"])

# 临时目录（with 块结束自动删除整个目录）
with tempfile.TemporaryDirectory() as tmpdir:
    tmp = Path(tmpdir)
    (tmp / "src").mkdir()
    (tmp / "src" / "main.cpp").write_text("int main(){}\n")
    # 在临时目录里跑构建，结束后自动清理

# 持久化临时目录（手动管理）
tmpdir = tempfile.mkdtemp(prefix="build_", suffix="_x86_64")
print(tmpdir)  # /tmp/build_xxxx_x86_64
# 用完后 shutil.rmtree(tmpdir)
```

### 5.2 watchdog 监控目录变化

场景：监控 `build/` 目录，当新的 `.so` 文件出现时自动复制到部署目录；监控源码目录变化触发增量编译。`watchdog` 是第三方库（`pip install watchdog`）。

```python
import time
import shutil
from pathlib import Path
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler

class BuildArtifactHandler(FileSystemEventHandler):
    def __init__(self, build_dir: Path, deploy_dir: Path):
        self.build_dir = build_dir.resolve()
        self.deploy_dir = deploy_dir.resolve()
        self.deploy_dir.mkdir(parents=True, exist_ok=True)

    def on_created(self, event):
        if event.is_directory:
            return
        p = Path(event.src_path)
        if p.suffix == ".so":
            # 等待文件写入完成（轮询大小稳定）
            self._wait_stable(p)
            dst = self.deploy_dir / p.name
            shutil.copy2(p, dst)
            print(f"部署: {p.name}")

    def on_modified(self, event):
        self.on_created(event)  # 重新部署

    @staticmethod
    def _wait_stable(p: Path, timeout: float = 5.0):
        """等待文件大小稳定（避免复制到正在写入的文件）。"""
        last_size = -1
        stable_count = 0
        deadline = time.time() + timeout
        while time.time() < deadline:
            try:
                size = p.stat().st_size
            except FileNotFoundError:
                time.sleep(0.1)
                continue
            if size == last_size:
                stable_count += 1
                if stable_count >= 3:
                    return
            else:
                stable_count = 0
            last_size = size
            time.sleep(0.1)

# 启动监控
observer = Observer()
handler = BuildArtifactHandler(Path("build"), Path("deploy/lib"))
observer.schedule(handler, str(Path("build")), recursive=True)
observer.start()
try:
    while True:
        time.sleep(1)
except KeyboardInterrupt:
    observer.stop()
observer.join()
```

## 7. 完整实战：构建产物一键整理脚本

整合以上能力，写一个完整的构建产物整理工具：扫描 `build/`，按平台+构建类型分类可执行文件和库，清理中间产物，生成清单。

```python
#!/usr/bin/env python3
"""构建产物一键整理脚本。

用法: python organize_build.py <build_dir> [--dist dist] [--clean]
"""
import argparse
import json
import platform
import shutil
from datetime import datetime
from pathlib import Path

EXECUTABLE_EXTS = {"", ".exe"}
LIBRARY_EXTS = {".a", ".so", ".dylib", ".lib", ".dll"}
INTERMEDIATE_EXTS = {".o", ".obj", ".d", ".gcda", ".gcno"}

def classify_file(p: Path) -> str:
    suffix = p.suffix.lower()
    if suffix in EXECUTABLE_EXTS and _is_executable(p):
        return "bin"
    if suffix in LIBRARY_EXTS:
        return "lib"
    if suffix in INTERMEDIATE_EXTS:
        return "intermediate"
    return "other"

def _is_executable(p: Path) -> bool:
    if platform.system() == "Windows":
        return p.suffix.lower() == ".exe"
    return p.stat().st_mode & 0o111 != 0

def organize(build_dir: Path, dist_dir: Path, clean: bool = False) -> dict:
    system = platform.system().lower()
    machine = platform.machine().lower()
    tag = f"{system}-{machine}"

    bin_dir = dist_dir / tag / "bin"
    lib_dir = dist_dir / tag / "lib"
    bin_dir.mkdir(parents=True, exist_ok=True)
    lib_dir.mkdir(parents=True, exist_ok=True)

    manifest = {"bin": [], "lib": [], "cleaned": [], "timestamp": datetime.now().isoformat()}

    for p in build_dir.rglob("*"):
        if not p.is_file():
            continue
        category = classify_file(p)

        if category == "bin":
            dst = bin_dir / p.name
            shutil.copy2(p, dst)
            manifest["bin"].append({"name": p.name, "size": p.stat().st_size})
        elif category == "lib":
            dst = lib_dir / p.name
            shutil.copy2(p, dst)
            manifest["lib"].append({"name": p.name, "size": p.stat().st_size})
        elif category == "intermediate" and clean:
            size = p.stat().st_size
            p.unlink()
            manifest["cleaned"].append({"name": str(p), "size": size})

    # 写清单
    manifest_path = dist_dir / tag / "manifest.json"
    manifest_path.write_text(json.dumps(manifest, indent=2, ensure_ascii=False), encoding="utf-8")
    return manifest

def main():
    parser = argparse.ArgumentParser(description="整理构建产物")
    parser.add_argument("build_dir", type=Path)
    parser.add_argument("--dist", type=Path, default=Path("dist"))
    parser.add_argument("--clean", action="store_true", help="删除中间产物")
    args = parser.parse_args()

    if not args.build_dir.is_dir():
        raise SystemExit(f"构建目录不存在: {args.build_dir}")

    manifest = organize(args.build_dir, args.dist, args.clean)
    print(f"可执行文件: {len(manifest['bin'])} 个")
    print(f"库文件: {len(manifest['lib'])} 个")
    if args.clean:
        freed = sum(item["size"] for item in manifest["cleaned"])
        print(f"清理中间产物: {len(manifest['cleaned'])} 个，释放 {freed / 1024:.1f} KB")

if __name__ == "__main__":
    main()
```

## 8. 常见坑与避坑指南

| 坑 | 现象 | 解决方案 |
|---|---|---|
| `Path.rename()` 跨设备失败 | `OSError: [Errno 18]` | 用 `shutil.move()` |
| `glob("**/*")` 极慢 | 大目录树卡死 | 用 `walk()` 修剪目录，或 `iterdir()` 分层 |
| 编码默认值不一致 | Windows 上 `read_text()` 乱码 | 始终显式指定 `encoding="utf-8"` |
| 临时文件被占用 | Windows 上 `NamedTemporaryFile` 无法二次打开 | 设 `delete=False`，手动关闭后再操作，最后 `unlink()` |
| 符号链接循环 | `rglob` 陷入无限递归 | 检查 `is_symlink()` 并跳过，或用 `Path.walk(follow_symlinks=False)`（Python 3.12+）替代 rglob |
| 竞态条件 | 监控目录时复制到正在写入的文件 | 轮询文件大小稳定后再操作 |
| Windows 路径长度限制 | 路径超过 260 字符报错 | 使用 `\\?\` 前缀或 Python 3.6+ 的长路径支持（需系统启用） |

## 9. 本节小结

- `pathlib.Path` 是文件批处理的核心，支持链式路径操作、`glob`/`rglob` 递归扫描、`walk` 目录修剪
- 文件读写必须显式指定编码，`utf-8-sig` 处理 BOM，`gbk` 处理 Windows 遗留文件，`charset-normalizer` 检测未知编码
- 批量重命名/分类/移动用 `Path.rename()` + `shutil.move()`，注意跨设备和命名冲突
- `tempfile` 提供安全临时文件/目录，`watchdog` 监控目录变化用于自动部署和增量编译
- 完整实战脚本展示了构建产物分类、中间产物清理、清单生成的端到端流程
