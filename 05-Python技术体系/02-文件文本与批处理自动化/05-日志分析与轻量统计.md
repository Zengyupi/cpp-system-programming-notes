## 1. 工程场景：日志分析在系统编程中的位置

工业网关、嵌入式设备、服务端程序每天产生 GB 级日志：设备上下线、报文收发、错误码、性能指标。这些日志是排查问题、优化性能、统计设备状态的第一手数据。

系统程序员的日志分析需求不同于数据分析师：不需要复杂的机器学习，不需要可视化大屏，需要的是**快速、准确、可复现**地从原始日志中提取关键信息。典型场景：

- **错误码聚合**：从一周日志中统计每种错误码出现次数，找出 top10 高频错误
- **时间窗分析**：统计每小时的报文收发量，找出流量突增时段
- **设备状态追踪**：关联设备上下线日志和错误日志，找出频繁掉线的设备
- **性能统计**：从日志中提取响应时间，计算 P50/P95/P99
- **日志去重**：相同错误重复出现上千次，按错误签名去重后只看唯一错误

## 2. GB 级日志流式扫描

### 2.1 逐行读取与内存控制

GB 级日志不能 `readlines()` 全部加载到内存，必须逐行流式处理。

```python
from pathlib import Path

def scan_log(log_path: Path, process_line):
    """逐行扫描日志，内存占用恒定。"""
    with log_path.open("r", encoding="utf-8", errors="replace") as f:
        for line_no, line in enumerate(f, 1):
            try:
                process_line(line.rstrip("\n"), line_no)
            except Exception as e:
                print(f"行 {line_no} 处理失败: {e}", file=__import__("sys").stderr)
```

**内存控制要点**：
- 用 `for line in f` 迭代，不要 `f.readlines()`
- 处理结果用计数器/聚合器累积，不要保存原始行
- 如需保存匹配行，限制数量（如只保存前 100 条错误样本）

### 2.2 多文件与压缩文件扫描

日志通常按日期分割，且旧日志可能被 gzip 压缩。需要统一扫描。

```python
import gzip
from pathlib import Path

def iter_log_lines(log_dir: Path, pattern: str = "*.log*"):
    """遍历目录下所有日志文件（含 .gz），逐行产出。"""
    for log_path in sorted(log_dir.glob(pattern)):
        if log_path.suffix == ".gz":
            opener = lambda p: gzip.open(p, "rt", encoding="utf-8", errors="replace")
        else:
            opener = lambda p: p.open("r", encoding="utf-8", errors="replace")

        with opener(log_path) as f:
            for line_no, line in enumerate(f, 1):
                yield log_path.name, line_no, line.rstrip("\n")

# 用法
for filename, line_no, line in iter_log_lines(Path("logs")):
    if "ERROR" in line:
        print(f"{filename}:{line_no}: {line[:120]}")
```

### 2.3 日志行解析模式

常见日志格式：`时间 级别 模块 消息`，或 JSON Lines（每行一个 JSON 对象）。

```python
import re
import json
from datetime import datetime

# 模式1：文本日志
# 2026-09-07 14:30:22.123 [ERROR] [tcp_conn] device 1001 disconnected: timeout
TEXT_PATTERN = re.compile(
    r'^(?P<ts>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d+)\s+'
    r'\[(?P<level>\w+)\]\s+'
    r'\[(?P<module>[\w_]+)\]\s+'
    r'(?P<msg>.*)$'
)

def parse_text_line(line: str) -> dict | None:
    m = TEXT_PATTERN.match(line)
    if not m:
        return None
    data = m.groupdict()
    data["ts"] = datetime.strptime(data["ts"], "%Y-%m-%d %H:%M:%S.%f")
    return data

# 模式2：JSON Lines
# {"ts":"2026-09-07T14:30:22.123Z","level":"ERROR","module":"tcp_conn","device_id":1001,"msg":"timeout"}
def parse_json_line(line: str) -> dict | None:
    try:
        return json.loads(line)
    except json.JSONDecodeError:
        return None
```

## 3. collections 实战

### 3.1 Counter：计数与 topN

`Counter` 是 dict 的子类，专门用于计数。

```python
from collections import Counter

# 统计错误码出现次数
error_counter = Counter()
for line in log_lines:
    m = re.search(r'error_code=(\d+)', line)
    if m:
        error_counter[m.group(1)] += 1

# topN
print("Top 10 错误码:")
for code, count in error_counter.most_common(10):
    print(f"  {code}: {count}")

# 其他常用操作
error_counter.total()           # 总计数（Python 3.10+）
error_counter["9999"]           # 不存在的 key 返回 0，不抛 KeyError
error_counter.update(["0001", "0001", "0002"])  # 批量更新
list(error_counter.elements())   # 展开为元素列表（每个元素重复计数次）
error_counter + another_counter  # 合并计数
error_counter - another_counter  # 减去计数
```

### 3.2 defaultdict：聚合与分组

`defaultdict` 在访问不存在的 key 时自动创建默认值，避免 `if key not in dict` 判断。

```python
from collections import defaultdict

# 按模块分组错误消息
errors_by_module = defaultdict(list)
for line in log_lines:
    parsed = parse_text_line(line)
    if parsed and parsed["level"] == "ERROR":
        errors_by_module[parsed["module"]].append(parsed["msg"])

# 按设备 ID 聚合统计
device_stats = defaultdict(lambda: {"errors": 0, "messages": 0, "last_seen": None})
for line in log_lines:
    m = re.search(r'device\s+(\d+)', line)
    if not m:
        continue
    dev_id = m.group(1)
    device_stats[dev_id]["messages"] += 1
    if "ERROR" in line:
        device_stats[dev_id]["errors"] += 1

# 嵌套 defaultdict：按日期+模块统计
nested = defaultdict(lambda: defaultdict(int))
for line in log_lines:
    parsed = parse_text_line(line)
    if parsed:
        date_str = parsed["ts"].strftime("%Y-%m-%d")
        nested[date_str][parsed["module"]] += 1
```

### 3.3 deque：时间窗与滑动窗口

`deque` 是双端队列，两端 append/pop 都是 O(1)，适合实现滑动窗口。

```python
from collections import deque
from datetime import datetime, timedelta

class SlidingWindowCounter:
    """滑动时间窗计数器：统计最近 N 秒内的事件数。"""

    def __init__(self, window_seconds: int):
        self.window = timedelta(seconds=window_seconds)
        self.timestamps = deque()  # 存储事件时间戳

    def add(self, ts: datetime):
        self.timestamps.append(ts)
        self._evict(ts)

    def _evict(self, current: datetime):
        """移除窗口外的旧事件。"""
        cutoff = current - self.window
        while self.timestamps and self.timestamps[0] < cutoff:
            self.timestamps.popleft()

    def count(self) -> int:
        return len(self.timestamps)

# 用法：统计每分钟错误数，检测错误突增
window = SlidingWindowCounter(60)
for line in log_lines:
    parsed = parse_text_line(line)
    if parsed and parsed["level"] == "ERROR":
        window.add(parsed["ts"])
        if window.count() > 100:
            print(f"告警: {parsed['ts']} 最近60秒错误数={window.count()}")
```

### 3.4 ChainMap：多层配置合并

`ChainMap` 将多个 dict 逻辑合并为一个视图，查找时按顺序返回第一个命中的 key。适用于多层配置（默认值 → 全局配置 → 局部配置）。

```python
from collections import ChainMap

# 构建系统的多层配置
default_config = {"build_type": "Debug", "jobs": 4, "compiler": "gcc"}
global_config = {"build_type": "Release", "jobs": 8}
local_config = {"compiler": "clang"}  # 局部覆盖

# ChainMap 查找顺序：local → global → default
effective = ChainMap(local_config, global_config, default_config)
print(effective["build_type"])  # 'Release'（来自 global）
print(effective["compiler"])     # 'clang'（来自 local）
print(effective["jobs"])         # 8（来自 global）

# 新增 key 只写入第一个 map
effective["new_option"] = "value"
print(local_config["new_option"])  # 'value'
```

## 4. 聚合分析：错误码、时间窗、topN

### 4.1 错误码聚合统计

```python
from collections import Counter, defaultdict

def analyze_error_codes(log_dir: Path) -> dict:
    """统计错误码：总次数、首次出现、最后出现、关联设备。"""
    code_count = Counter()
    code_first = {}
    code_last = {}
    code_devices = defaultdict(set)

    for filename, line_no, line in iter_log_lines(log_dir):
        parsed = parse_text_line(line)
        if not parsed or parsed["level"] != "ERROR":
            continue

        m = re.search(r'error_code[=:]\s*(\w+)', parsed["msg"])
        if not m:
            continue
        code = m.group(1)
        code_count[code] += 1

        ts = parsed["ts"]
        if code not in code_first or ts < code_first[code]:
            code_first[code] = ts
        if code not in code_last or ts > code_last[code]:
            code_last[code] = ts

        dev_m = re.search(r'device\s+(\d+)', parsed["msg"])
        if dev_m:
            code_devices[code].add(dev_m.group(1))

    # 组装结果
    result = []
    for code, count in code_count.most_common():
        result.append({
            "error_code": code,
            "count": count,
            "first_seen": code_first[code].isoformat(),
            "last_seen": code_last[code].isoformat(),
            "affected_devices": len(code_devices[code]),
            "device_samples": list(code_devices[code])[:5],
        })
    return {"total_unique_errors": len(result), "errors": result}
```

### 4.2 滑动时间窗统计

```python
def hourly_stats(log_dir: Path) -> dict:
    """按小时统计各级别日志数量。"""
    hourly = defaultdict(lambda: Counter())

    for filename, line_no, line in iter_log_lines(log_dir):
        parsed = parse_text_line(line)
        if not parsed:
            continue
        hour_key = parsed["ts"].strftime("%Y-%m-%d %H:00")
        hourly[hour_key][parsed["level"]] += 1

    # 按时间排序输出
    result = []
    for hour in sorted(hourly):
        levels = hourly[hour]
        result.append({
            "hour": hour,
            "total": sum(levels.values()),
            "ERROR": levels.get("ERROR", 0),
            "WARN": levels.get("WARN", 0),
            "INFO": levels.get("INFO", 0),
        })
    return result
```

### 4.3 topN 与频次分布

```python
def top_n_devices_by_errors(log_dir: Path, n: int = 10) -> list:
    """按错误数排名 topN 设备。"""
    device_errors = Counter()
    device_total = Counter()

    for filename, line_no, line in iter_log_lines(log_dir):
        m = re.search(r'device\s+(\d+)', line)
        if not m:
            continue
        dev_id = m.group(1)
        device_total[dev_id] += 1
        if "ERROR" in line:
            device_errors[dev_id] += 1

    result = []
    for dev_id, err_count in device_errors.most_common(n):
        total = device_total[dev_id]
        result.append({
            "device_id": dev_id,
            "errors": err_count,
            "total_messages": total,
            "error_rate": f"{err_count / total * 100:.1f}%" if total else "N/A",
        })
    return result
```

## 5. 两文件按 key 关联

场景：有设备清单 `devices.csv` 和错误日志 `errors.log`，需要关联出每个设备的型号、厂商和错误数。

```python
import csv
from collections import defaultdict

def load_devices(csv_path: Path) -> dict:
    """加载设备清单，以 device_id 为 key。"""
    devices = {}
    with csv_path.open("r", encoding="utf-8-sig") as f:
        reader = csv.DictReader(f)
        for row in reader:
            devices[row["device_id"]] = row
    return devices

def join_errors_with_devices(error_log: Path, devices_csv: Path) -> list:
    """将错误日志与设备清单按 device_id 关联。"""
    devices = load_devices(devices_csv)
    device_errors = defaultdict(list)

    with error_log.open("r", encoding="utf-8", errors="replace") as f:
        for line in f:
            parsed = parse_text_line(line)
            if not parsed or parsed["level"] != "ERROR":
                continue
            m = re.search(r'device\s+(\d+)', parsed["msg"])
            if m:
                device_errors[m.group(1)].append(parsed["msg"])

    # 关联
    result = []
    for dev_id, errors in device_errors.items():
        info = devices.get(dev_id, {"model": "UNKNOWN", "vendor": "UNKNOWN"})
        result.append({
            "device_id": dev_id,
            "model": info.get("model", "UNKNOWN"),
            "vendor": info.get("vendor", "UNKNOWN"),
            "error_count": len(errors),
            "error_samples": errors[:3],
        })

    # 按错误数降序
    result.sort(key=lambda x: x["error_count"], reverse=True)
    return result
```

**关联策略选择**：
- 小文件（< 10万行）：加载到 dict，内存关联，简单快速
- 大文件（> 100万行）：先按 key 排序两个文件，再流式归并关联（类似数据库 sort-merge join）
- 超大数据：考虑用 SQLite 导入后 SQL JOIN

## 6. 排序与去重

```python
# 简单去重：保留顺序
seen = set()
unique_lines = []
for line in lines:
    if line not in seen:
        seen.add(line)
        unique_lines.append(line)

# 按错误签名去重：相同错误（忽略行号、时间、设备ID）只保留一条
def error_signature(line: str) -> str:
    """提取错误签名：去掉时间、行号、设备ID等可变部分。"""
    sig = re.sub(r'\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d+', '<TS>', line)
    sig = re.sub(r'device\s+\d+', 'device <ID>', sig)
    sig = re.sub(r'0x[0-9a-fA-F]+', '<ADDR>', sig)
    return sig

seen_sigs = set()
unique_errors = []
for line in error_lines:
    sig = error_signature(line)
    if sig not in seen_sigs:
        seen_sigs.add(sig)
        unique_errors.append(line)

# 大文件排序去重：内存不够时用外部排序（分块→排序→归并）
def external_sort_dedup(input_path: Path, output_path: Path, chunk_size: int = 100000):
    """外部排序去重：分块读入、排序、写临时文件、最后归并。"""
    import tempfile
    chunks = []

    # 分块排序
    with input_path.open("r", encoding="utf-8", errors="replace") as f:
        chunk = []
        for line in f:
            chunk.append(line)
            if len(chunk) >= chunk_size:
                chunk.sort()
                tmp = tempfile.NamedTemporaryFile(mode="w", delete=False, encoding="utf-8")
                tmp.writelines(chunk)
                tmp.close()
                chunks.append(tmp.name)
                chunk = []
        if chunk:
            chunk.sort()
            tmp = tempfile.NamedTemporaryFile(mode="w", delete=False, encoding="utf-8")
            tmp.writelines(chunk)
            tmp.close()
            chunks.append(tmp.name)

    # 归并去重（用 heapq.merge）
    import heapq
    files = [open(c, "r", encoding="utf-8") for c in chunks]
    with output_path.open("w", encoding="utf-8") as out:
        prev = None
        for line in heapq.merge(*files):
            if line != prev:
                out.write(line)
                prev = line
    for f in files:
        f.close()
    for c in chunks:
        Path(c).unlink()
```

## 7. numpy/pandas：什么时候才值得引入

### 7.1 数据量阈值判断

| 数据量 | 推荐方案 | 理由 |
|---|---|---|
| < 10 万行 | 标准库（collections + 正则） | 无需依赖，启动快，内存足够 |
| 10 万 ~ 100 万行 | 标准库流式处理 | 逐行扫描 + 聚合器，内存恒定 |
| 100 万 ~ 1000 万行 | 考虑 pandas | pandas 列式存储 + 向量化运算，比纯 Python 快 10-100 倍 |
| > 1000 万行 | pandas + 分块读取，或 SQLite/ClickHouse | 单机内存可能不够，需要分块或数据库 |

**系统程序员的经验**：90% 的日志分析任务在 100 万行以内，标准库完全够用。只有当需要频繁做复杂聚合（多维度 groupby、窗口函数、join）且数据量超过百万行时，才引入 pandas。

### 7.2 pandas 最小用法

```python
import pandas as pd

# 读取日志（假设是 CSV 格式或已解析为结构化数据）
df = pd.read_csv("logs/parsed.csv", parse_dates=["ts"])

# 基本统计
print(df["level"].value_counts())

# 按小时聚合
df["hour"] = df["ts"].dt.floor("h")
hourly = df.groupby(["hour", "level"]).size().unstack(fill_value=0)

# 错误码 topN
top_errors = df[df["level"] == "ERROR"]["error_code"].value_counts().head(10)

# 按设备聚合错误率
device_stats = df.groupby("device_id").agg(
    total=("level", "count"),
    errors=("level", lambda x: (x == "ERROR").sum()),
)
device_stats["error_rate"] = device_stats["errors"] / device_stats["total"]
device_stats = device_stats.sort_values("error_rate", ascending=False)

# 分块读取大文件（内存不够时）
chunk_iter = pd.read_csv("huge.csv", chunksize=100000)
result = []
for chunk in chunk_iter:
    # 每块做过滤/聚合，减少内存
    filtered = chunk[chunk["level"] == "ERROR"]
    result.append(filtered.groupby("error_code").size())
final = pd.concat(result).groupby(level=0).sum().sort_values(ascending=False)
```

**pandas 注意事项**：
- `pip install pandas` 约 50MB，CI 镜像会变大
- pandas 读取整个文件到内存，GB 级文件需要分块
- 时间列必须 `parse_dates` 解析，否则是字符串
- 中文列名和编码问题：`encoding="utf-8-sig"` 处理 BOM

## 8. 完整实战：设备日志分析报告生成器

整合以上能力，实现一个完整的日志分析工具：扫描日志目录，生成包含错误码统计、时间分布、topN 设备、唯一错误列表的 JSON 报告。

```python
#!/usr/bin/env python3
"""设备日志分析报告生成器。

用法: python log_analyzer.py <log_dir> [--output report.json]
"""
import argparse
import json
import re
from collections import Counter, defaultdict
from datetime import datetime
from pathlib import Path

LOG_PATTERN = re.compile(
    r'^(?P<ts>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d+)\s+'
    r'\[(?P<level>\w+)\]\s+'
    r'\[(?P<module>[\w_]+)\]\s+'
    r'(?P<msg>.*)$'
)

def parse_line(line: str) -> dict | None:
    m = LOG_PATTERN.match(line)
    if not m:
        return None
    data = m.groupdict()
    data["ts"] = datetime.strptime(data["ts"], "%Y-%m-%d %H:%M:%S.%f")
    return data

def error_signature(msg: str) -> str:
    sig = re.sub(r'device\s+\d+', '<DEV>', msg)
    sig = re.sub(r'0x[0-9a-fA-F]+', '<ADDR>', sig)
    sig = re.sub(r'\d+\.\d+\.\d+\.\d+', '<IP>', sig)
    return sig

def analyze(log_dir: Path) -> dict:
    level_count = Counter()
    module_count = Counter()
    error_code_count = Counter()
    device_error_count = Counter()
    device_total_count = Counter()
    hourly = defaultdict(Counter)
    unique_errors = {}  # signature -> first occurrence
    first_ts = None
    last_ts = None
    total_lines = 0

    for log_path in sorted(log_dir.glob("*.log*")):
        opener = (
            __import__("gzip").open if log_path.suffix == ".gz"
            else lambda p, **kw: p.open(**kw)
        )
        with opener(log_path, mode="rt", encoding="utf-8", errors="replace") as f:
            for line in f:
                total_lines += 1
                parsed = parse_line(line.rstrip("\n"))
                if not parsed:
                    continue

                ts = parsed["ts"]
                if first_ts is None or ts < first_ts:
                    first_ts = ts
                if last_ts is None or ts > last_ts:
                    last_ts = ts

                level_count[parsed["level"]] += 1
                module_count[parsed["module"]] += 1
                hourly[ts.strftime("%Y-%m-%d %H:00")][parsed["level"]] += 1

                dev_m = re.search(r'device\s+(\d+)', parsed["msg"])
                if dev_m:
                    dev_id = dev_m.group(1)
                    device_total_count[dev_id] += 1
                    if parsed["level"] == "ERROR":
                        device_error_count[dev_id] += 1

                if parsed["level"] == "ERROR":
                    code_m = re.search(r'error_code[=:]\s*(\w+)', parsed["msg"])
                    if code_m:
                        error_code_count[code_m.group(1)] += 1

                    sig = error_signature(parsed["msg"])
                    if sig not in unique_errors:
                        unique_errors[sig] = {
                            "signature": sig,
                            "first_msg": parsed["msg"],
                            "first_ts": ts.isoformat(),
                            "module": parsed["module"],
                            "count": 1,
                        }
                    else:
                        unique_errors[sig]["count"] += 1

    # 组装报告
    top_devices = []
    for dev_id, err_count in device_error_count.most_common(10):
        total = device_total_count[dev_id]
        top_devices.append({
            "device_id": dev_id,
            "errors": err_count,
            "total": total,
            "error_rate": round(err_count / total * 100, 1) if total else 0,
        })

    hourly_report = []
    for hour in sorted(hourly):
        levels = hourly[hour]
        hourly_report.append({
            "hour": hour,
            "total": sum(levels.values()),
            "ERROR": levels.get("ERROR", 0),
            "WARN": levels.get("WARN", 0),
            "INFO": levels.get("INFO", 0),
        })

    unique_error_list = sorted(
        unique_errors.values(), key=lambda x: x["count"], reverse=True
    )[:50]

    return {
        "summary": {
            "total_lines": total_lines,
            "time_range": {
                "from": first_ts.isoformat() if first_ts else None,
                "to": last_ts.isoformat() if last_ts else None,
            },
            "levels": dict(level_count),
            "unique_errors": len(unique_errors),
        },
        "top_error_codes": error_code_count.most_common(10),
        "top_devices_by_errors": top_devices,
        "hourly_distribution": hourly_report,
        "unique_errors": unique_error_list,
    }

def main():
    parser = argparse.ArgumentParser(description="设备日志分析报告生成器")
    parser.add_argument("log_dir", type=Path)
    parser.add_argument("--output", type=Path, default=Path("log_report.json"))
    args = parser.parse_args()

    if not args.log_dir.is_dir():
        raise SystemExit(f"日志目录不存在: {args.log_dir}")

    report = analyze(args.log_dir)
    args.output.write_text(
        json.dumps(report, indent=2, ensure_ascii=False), encoding="utf-8"
    )

    s = report["summary"]
    print(f"分析完成: {s['total_lines']} 行, {s['unique_errors']} 个唯一错误")
    print(f"时间范围: {s['time_range']['from']} ~ {s['time_range']['to']}")
    print(f"报告已保存: {args.output}")

if __name__ == "__main__":
    main()
```

## 9. 快速参考卡片

| 需求 | 做法 |
| --- | --- |
| 逐行扫描 | `for line in open(f, errors="replace")`；大文件不要 `read()` 全读 |
| 正则提取 | `re.compile(r"(?P<ip>\d+\.\d+\.\d+\.\d+).*?(?P<ms>\d+)ms")`，预编译复用 |
| 计数 TopN | `collections.Counter` + `most_common(20)` |
| 分组聚合 | `collections.defaultdict(list)` 或 `itertools.groupby`（先排序） |
| 取最大 N | `heapq.nlargest(10, xs, key=...)`（不全排序） |
| 时间窗统计 | 解析时间戳后按分钟/小时 `floor` 分桶计数 |
| 结构化输出 | 结果写 CSV（`csv.DictWriter`）或 JSON（`json.dump(ensure_ascii=False)`） |
| 压缩日志 | `gzip.open("x.log.gz", "rt")` 透明解压；`zcat` 同理 |
| 性能取舍 | 单文件 <100MB 纯 Python 够用；GB 级考虑 `awk`/`polars`/多进程分片 |
| 与 C++ 对照 | C++ 侧做同类分析要写几百行且难改，Python 临时脚本 20 行解决 |

## 10. 常见坑与避坑指南

| 坑 | 现象 | 解决方案 |
|---|---|---|
| `readlines()` OOM | GB 级日志内存爆炸 | 用 `for line in f` 逐行迭代 |
| 编码错误中断 | `UnicodeDecodeError` 导致扫描中断 | `errors="replace"`，不要用默认的 strict |
| 正则回溯灾难 | 某些行匹配极慢 | 避免嵌套量词（如 `(a+)+`），用 `[^"]*` 替代 `.*?` |
| Counter 内存增长 | 保存所有唯一错误导致内存不足 | 限制 unique_errors 数量，或只存签名不存原文 |
| 时间解析慢 | `strptime` 每行调用耗时 | 简单格式可用字符串切片 + `int()` 手动解析 |
| gzip 文件慢 | gzip 逐行读取比纯文本慢 5-10 倍 | 旧日志归档用 gzip，近期日志保持纯文本 |
| pandas 内存溢出 | `read_csv` 加载整个文件 | 用 `chunksize` 分块读取，或 `usecols` 只读需要的列 |
| 去重不彻底 | 相同错误因时间/ID不同被当作不同错误 | 用 error_signature 去掉可变部分后再去重 |
| 多文件顺序混乱 | glob 返回顺序不确定 | `sorted(log_dir.glob(...))` 按文件名排序 |

## 11. 本节小结

- GB 级日志必须逐行流式扫描，用 `for line in f` 而非 `readlines()`，配合 `errors="replace"` 避免编码中断
- `collections.Counter` 是计数和 topN 的核心，`defaultdict` 用于聚合分组，`deque` 实现滑动时间窗，`ChainMap` 合并多层配置
- 错误码聚合、时间窗统计、topN 设备排名是日志分析的三大基础模式
- 两文件按 key 关联用 dict 加载小文件 + 流式扫描大文件，超大数据用 sort-merge 或 SQLite
- 排序去重用 set 保留顺序，错误去重用 error_signature 去掉可变部分，大文件用外部排序
- numpy/pandas 只在数据量超过百万行且需要复杂聚合时才引入，90% 的系统程序员日志分析任务用标准库即可
- 完整日志分析报告生成器展示了从扫描到报告的端到端流程
