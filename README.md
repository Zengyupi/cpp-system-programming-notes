# C++ / Linux / 嵌入式开发知识手册

> **English intro**: A personal system-programming knowledge base of **196+ engineering notes (Chinese)**, organized into 5 tracks — **C++ (122 notes, the core track)**, **Network Protocols & Packet Parsing (10)**, **AI-Assisted Coding (5)**, **Rust (34, taught by contrast with C++)**, and **Python as a scripting toolchain (25)**. Every note follows the same handbook structure: *goal → TOC → deep dive → quick-reference card → common pitfalls*, with cross-references between notes. All command-line content was verified on WSL Ubuntu 24.04.

> 面向 **C++/Linux 后端、嵌入式与工业自动化开发**的个人知识手册。五大方向：**C++ 技术体系**（核心主线，122 篇）、**网络协议与报文解析**（10 篇）、**AI 辅助编程实战**（5 篇）、**Rust 技术体系**（34 篇，对照 C++ 讲法）、**Python 技术体系**（25 篇，定位为脚本与工具链，非就业方向）。全部 Markdown 离线可读，文档间用《文件名》交叉引用，每篇含"本节目标 → 正文 → 快速参考卡片 → 常见坑"手册结构。

## 使用约定

- 《文件名》表示知识库内交叉引用，按文件名在对应模块检索；跨目录引用带相对路径前缀；
- 代码以 C++17/20 + Linux 为主，命令类内容尽量在 WSL Ubuntu 24.04 实跑验证，无法实跑的标注官方文档来源；
- 每篇结构：H1 → 本节目标（适用场景）→ 本章速览 TOC → 正文 → 快速参考卡片 → 常见坑 → 篇尾导航；
