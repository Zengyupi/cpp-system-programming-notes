## 1. 知识地图：六子模块关系

Rust 技术体系分为六个子模块，从语言内核到工程实践逐层递进：

│  (线程/异步/Future)   │    (TCP/UDP/IO/FFI/unsafe)          │
├─────────────────────────────────────────────────────────────┤
│  02-Rust进阶机制      │    04-工程化与质量保障                │

## 2. 推荐学习顺序

对于已掌握 C++/Linux 的系统程序员，建议按以下路径学习：

1. **01-Rust语言核心**（必须最先完成，8篇连读）
   - 环境搭建 → 基础语法 → 所有权（核心难点）→ 结构体枚举 → Trait → 错误处理 → 集合迭代器 → 智能指针
   - 所有权篇是整个 Rust 学习的分水岭，务必写透练透

2. **02-Rust进阶机制**（语言核心的自然延伸）
   - 宏系统、类型系统进阶、DST 与 fat pointer、unsafe 基础

3. **03-并发与异步编程**（Rust 最大优势领域）
   - 线程与同步原语 → async/await 原理 → Future trait → 运行时对比
   - 可与 C++ 体系《../01-C++技术体系/04-并发编程/04-原子操作与C++内存模型.md》《../01-C++技术体系/04-并发编程/06-无锁进阶：SPSC队列与ABA防护.md》对照学习

4. **04-工程化与质量保障**（随时可插入）
   - 测试体系、criterion 基准、CI 配置、文档生成

5. **05-网络与系统编程**（实战导向）
   - 标准库网络、tokio/mio、FFI 互操作、unsafe 系统调用

6. **06-领域方向与实战路线**（按需选学）
   - 根据职业方向选择存储引擎、网络服务、嵌入式等专题

> **加速策略**：C++ 程序员学习 Rust 的最大障碍是所有权与借用检查器。建议在所有权篇投入至少 3 天，配合大量编译错误练习，形成"编译器即老师"的肌肉记忆。

## 3. Rust ↔ C++ 概念对照表

以下是 Rust 与 C++ 核心概念的 18 组对照，帮助快速建立映射：

| 序号 | Rust 概念 | C++ 对应概念 | 关键差异 |
|---|---|---|---|
| 1 | 所有权 (Ownership) | RAII + 移动语义 | Rust 在编译期强制单一所有者，C++ 依赖约定 |
| 2 | 借用 (Borrowing) | 引用 (Reference) | Rust 编译期 enforce 一可变多不可变，C++ 无此约束 |
| 3 | 生命周期 (Lifetime) | 无直接对应（对象生存期） | Rust 显式标注引用有效期，C++ 悬垂引用是运行时 bug |
| 4 | `&T` / `&mut T` | `const T&` / `T&` | Rust 可变引用独占，C++ 可同时存在多个非 const 引用 |
| 5 | `trait` | 虚函数基类 + Concepts | Rust trait 可对外部类型实现，无继承；支持静态/动态分发 |
| 6 | `Option<T>` | `std::optional<T>` / `nullptr` | Rust 编译器强制处理 None，C++ optional 可被忽略 |
| 7 | `Result<T, E>` | 异常 / `std::expected` / 错误码 | Rust 错误是类型，`?` 运算符传播，无异常栈展开开销 |
| 8 | `panic!` | `std::terminate` / 断言 | panic 默认展开栈，可设置 abort；不可被"捕获"恢复 |
| 9 | `Send` / `Sync` | 无直接对应（线程安全约定） | Rust 编译期标记可跨线程/可共享，C++ 靠文档和 discipline |
| 10 | `async/await` | 协程 (C++20 coroutines) | Rust Future 是惰性 pull 模型，C++ 协程更底层灵活 |
| 11 | `Box<T>` | `std::unique_ptr<T>` | 语义几乎一致，Box 无自定义 deleter（需通过 trait） |
| 12 | `Rc<T>` / `Arc<T>` | `std::shared_ptr<T>` | Rc 单线程无原子开销，Arc 多线程；均无 weak 循环自动回收 |
| 13 | `RefCell<T>` / `Cell<T>` | 无直接对应（内部可变性） | Rust 运行时借用检查，C++ 用 `mutable` 关键字 |
| 14 | `Weak<T>` | `std::weak_ptr<T>` | 语义一致，用于打破引用计数循环 |
| 15 | `enum` (代数数据类型) | `std::variant` / tagged union | Rust enum 是语言级支持，模式匹配穷尽性编译器保证 |
| 16 | `match` 模式匹配 | `switch` + `std::visit` | Rust match 穷尽性检查、解构、守卫，远比 switch 强大 |
| 17 | `no_std` | 嵌入式 C / freestanding C++ | Rust no_std 可保留核心库，C++ freestanding 更受限 |
| 18 | `unsafe` 块 | 全部 C++ 代码（默认 unsafe） | Rust 将不安全操作隔离在明确标记的块中，C++ 无此机制 |

## 5. 学习建议与前置要求

### 前置知识

- 熟练掌握 C++17/20（类、模板、智能指针、移动语义、lambda）
- 熟悉 Linux 系统编程（文件 IO、网络 socket、多线程）
- 了解编译链接基本原理

### 学习方法

1. **编译器驱动学习**：Rust 编译器的错误信息是最好的老师。主动写错误代码，阅读完整错误提示，理解修复建议。
2. **对照 C++ 学习**：每学一个 Rust 概念，主动思考"C++ 中怎么实现？有什么坑？Rust 如何在编译期避免？"
3. **标准库源码阅读**：Rust 标准库代码质量极高，`Option`、`Result`、`Iterator` 的实现是学习 Rust 范式的最佳素材。
4. **项目驱动**：完成语言核心后，立即用 Rust 重写一个熟悉的 C++ 小工具（如日志库、线程池、简单 HTTP 服务器）。

### 常见误区

- **把 Rust 当 C++ 写**：试图用继承、异常、裸指针的思维写 Rust，会处处碰壁。需要接受所有权、trait、组合优于继承的范式。
- **过度使用 `clone()`**：遇到借用错误就 `clone()`，会掩盖对所有权的理解。先尝试调整结构和生命周期，实在不行再 clone。
- **害怕 `unsafe`**：`unsafe` 不是罪恶，而是对编译器的承诺。系统编程中 FFI、自引用结构等场景必须使用 unsafe，关键是将其隔离在最小范围内。
- **忽视 trait 对象**：只知道静态分发，不理解 `dyn Trait` 的对象安全规则和 vtable 机制，在需要运行时多态时会卡住。
