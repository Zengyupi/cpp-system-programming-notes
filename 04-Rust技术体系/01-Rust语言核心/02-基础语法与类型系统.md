## 1. 变量绑定：let / mut / 遮蔽

### 1.1 不可变默认与 mut 关键字

Rust 中 `let` 创建的绑定默认不可变，这与 C++ 默认可变形成鲜明对比：

```rust
fn main() {
    let x = 5;          // 不可变绑定，等价于 C++ 的 const int x = 5;
    // x = 6;           // 编译错误：cannot assign twice to immutable variable `x`

    let mut y = 5;      // 可变绑定，等价于 C++ 的 int y = 5;
    y = 6;              // OK
    println!("y = {}", y);
}
```

> **设计哲学**：C++ 中 `const` 是需要主动添加的"额外约束"，而 Rust 中不可变是默认状态，可变性需要显式声明 `mut`。这迫使程序员思考"这个变量是否真的需要修改"，从语言层面减少意外修改。C++ 中常见的"忘了加 const 导致变量被意外修改"的 bug 在 Rust 中被编译期杜绝。

可变性是绑定的属性，而非值的属性：

```rust
let mut v = vec![1, 2, 3];  // v 是可变绑定
v.push(4);                    // OK，可以修改 v 指向的值

let v2 = v;                   // v2 是不可变绑定（move 后 v 不可用）
// v2.push(5);               // 编译错误：v2 不可变
```

### 1.2 遮蔽 shadowing

Rust 允许在同一作用域中用 `let` 重新声明同名变量，称为遮蔽（shadowing）：

```rust
fn main() {
    let x = 5;          // x: i32 = 5
    let x = x + 1;      // 遮蔽前一个 x，新 x: i32 = 6
    let x = x * 2;      // 再次遮蔽，x: i32 = 12
    println!("x = {}", x); // 输出 12

    // 遮蔽可以改变类型
    let spaces = "   ";  // spaces: &str
    let spaces = spaces.len(); // spaces: usize，类型改变
}
```

遮蔽与 `mut` 的关键区别：

| 特性 | 遮蔽 (shadowing) | mut 可变 |
|---|---|---|
| 类型能否改变 | 可以 | 不可以 |
| 是否创建新变量 | 是，旧变量被遮蔽 | 否，修改同一变量 |
| 作用域结束后 | 外层同名变量恢复 | 无此概念 |
| 内存语义 | 旧变量存活至作用域结束（仅名称被遮蔽，非 Copy 也不提前 drop） | 值被修改 |

```rust
fn main() {
    let x = 5;
    {
        let x = 10;      // 内层遮蔽外层
        println!("inner x = {}", x); // 10
    }
    println!("outer x = {}", x); // 5，外层 x 恢复
}
```

> **对照 C++**：C++ 也允许内层作用域声明同名变量遮蔽外层，但不允许同一作用域重复声明（`int x = 5; int x = 6;` 编译错误）。Rust 的遮蔽在同一作用域也合法，且常用于"转换后复用变量名"的场景，如 `let s = s.to_string();`。C++ 中需要用不同变量名或 `const_cast`，代码可读性较差。

### 1.3 const 与 static

```rust
const MAX_POINTS: u32 = 100_000;  // 编译期常量，必须标注类型
static HELLO: &str = "Hello";      // 全局静态变量，有固定内存地址

static mut COUNTER: u32 = 0;       // 可变静态变量，访问必须 unsafe

fn main() {
    unsafe {
        COUNTER += 1;
        println!("COUNTER = {}", COUNTER);
    }
}
```

| 特性 | const | static |
|---|---|---|
| 内存位置 | 无，编译期内联 | 有固定地址 |
| 可变性 | 不可变 | 可声明 `static mut`（unsafe 访问） |
| 类型标注 | 必须 | 必须 |
| 表达式 | 必须是常量表达式 | 必须是常量表达式 |
| C++ 对应 | `constexpr` | 全局变量 / `static` 变量 |

## 2. 标量类型

### 2.1 整数类型与 isize/usize

| 长度 | 有符号 | 无符号 |
|---|---|---|
| 8-bit | `i8` | `u8` |
| 16-bit | `i16` | `u16` |
| 32-bit | `i32`（默认） | `u32` |
| 64-bit | `i64` | `u64` |
| 128-bit | `i128` | `u128` |
| 指针宽度 | `isize` | `usize` |

`isize`/`usize` 的大小等于目标平台的指针宽度（64 位平台上是 64 位），用于集合索引、内存大小等场景。C++ 中对应 `intptr_t`/`uintptr_t` 和 `size_t`。

```rust
fn main() {
    let decimal = 98_222;        // 十进制，下划线分隔
    let hex = 0xff;              // 十六进制
    let octal = 0o77;            // 八进制
    let binary = 0b1111_0000;   // 二进制
    let byte = b'A';             // 字节字面量，u8 类型

    // 整数溢出：debug 模式 panic，release 模式回绕（two's complement）
    let mut x: u8 = 255;
    // x += 1;  // debug 下 panic: attempt to add with overflow

    // 显式处理溢出
    let (result, overflowed) = x.overflowing_add(1);
    println!("result = {}, overflowed = {}", result, overflowed); // 0, true

    let result = x.wrapping_add(1);  // 回绕
    let result = x.saturating_add(1); // 饱和到最大值
    let result = x.checked_add(1);   // 返回 Option，溢出为 None
}
```

> **对照 C++**：C++ 中无符号整数溢出是定义良好的（模运算），有符号整数溢出是未定义行为（UB）。Rust 在 debug 模式下对所有整数溢出 panic，release 模式下统一回绕。Rust 还提供了 `wrapping_*`、`saturating_*`、`checked_*`、`overflowing_*` 四组方法显式选择溢出行为，C++ 需要手动编写判断逻辑。

### 2.2 浮点类型与陷阱

```rust
fn main() {
    let x = 2.0;      // f64（默认），双精度
    let y: f32 = 3.0; // f32，单精度

    // 浮点比较陷阱：永远不要用 == 比较浮点数
    let a = 0.1 + 0.2;
    println!("0.1 + 0.2 = {}", a);  // 0.30000000000000004
    // println!("{}", a == 0.3);    // false！

    // 正确做法：使用近似比较
    fn approx_eq(a: f64, b: f64, eps: f64) -> bool {
        (a - b).abs() < eps
    }
    println!("approx equal: {}", approx_eq(a, 0.3, 1e-10)); // true

    // 特殊值
    let inf = f64::INFINITY;
    let neg_inf = f64::NEG_INFINITY;
    let nan = f64::NAN;
    println!("nan != nan: {}", nan != nan); // true，NaN 不等于自身
}
```

Rust 的浮点数遵循 IEEE 754-2008，与 C++ 一致。但 Rust 的 `f32`/`f64` 没有实现 `Eq`（因为 NaN != NaN），只实现了 `PartialEq`，这意味着浮点数不能作为 `HashMap` 的 key（需要 `Eq`）。C++ 中 `double` 可以作为 `std::map` 的 key（使用 `<` 比较），但 NaN 会导致未定义行为。

### 2.3 布尔与字符

```rust
fn main() {
    let t = true;
    let f: bool = false;

    // char 是 Unicode 标量值，4 字节（不是 C++ 的 char 1 字节）
    let c = 'z';
    let z = 'ℤ';
    let heart = '❤';  // U+2764，单个 Unicode 标量值；注意 ❤️（含变体选择符 U+FE0F）是多个 char 组成的字形簇
    println!("heart as u32: {}", heart as u32);

    // 字符范围
    for c in 'a'..='d' {
        print!("{} ", c); // a b c d
    }
}
```

> **对照 C++**：C++ 的 `char` 是 1 字节（本质是整数），`wchar_t` 平台相关（Windows 2 字节，Linux 4 字节），C++20 引入 `char8_t`/`char16_t`/`char32_t`。Rust 的 `char` 统一为 4 字节 Unicode 标量值（U+0000 到 U+D7FF 和 U+E000 到 U+10FFFF），类型系统更清晰。

## 3. 复合类型：元组 / 数组 / 切片

```rust
fn main() {
    // 元组：固定长度，元素类型可不同
    let tup: (i32, f64, char) = (500, 6.4, 'a');
    let (x, y, z) = tup;  // 解构
    println!("x = {}, y = {}, z = {}", x, y, z);
    println!("tup.0 = {}, tup.1 = {}", tup.0, tup.1); // 索引访问

    // 单元类型 ()，等价于 C++ 的 void
    let unit: () = ();

    // 数组：固定长度，元素类型相同，栈分配
    let arr: [i32; 5] = [1, 2, 3, 4, 5];
    let zeros = [0; 10];  // 10 个 0

    // 数组越界：运行时 panic（C++ 中是 UB）
    // println!("{}", arr[10]);  // panic: index out of bounds

    // 切片：指向数组的视图，包含指针和长度（fat pointer）
    let slice: &[i32] = &arr[1..4];  // 元素 [2, 3, 4]
    println!("slice length = {}", slice.len()); // 3

    // 字符串切片
    let s = String::from("hello world");
    let hello: &str = &s[0..5];
    let world: &str = &s[6..11];
}
```

| 类型 | 长度 | 元素类型 | 内存位置 | C++ 对应 |
|---|---|---|---|---|
| 元组 `(T1, T2)` | 编译期固定 | 可不同 | 栈 | `std::tuple<T1, T2>` |
| 数组 `[T; N]` | 编译期固定 N | 相同 | 栈 | `std::array<T, N>` / C 数组 |
| 切片 `&[T]` | 运行时可变 | 相同 | 引用堆/栈数据 | `std::span<T>` (C++20) |
| `Vec<T>` | 运行时可变 | 相同 | 堆 | `std::vector<T>` |

> **切片的本质**：`&[T]` 是一个胖指针（fat pointer），包含数据指针和长度，占 16 字节（64 位平台）。C++20 的 `std::span` 语义类似，但 Rust 的切片在语言层面集成，且借用检查器保证切片不会悬垂。

## 4. 类型推导与显式标注

Rust 编译器有强大的类型推导能力（基于 Hindley-Milner 变体），但与 C++ 的 `auto` 不同，Rust 的推导是双向的：

```rust
fn main() {
    let x = 5;              // 推导为 i32（默认整数类型）
    let y = 2.0;            // 推导为 f64（默认浮点类型）

    // 上下文推导：根据使用方式推导类型
    let numbers = vec![1, 2, 3];  // 推导为 Vec<i32>

    // 有时需要显式标注，因为推导信息不足
    let guess: u32 = "42".parse().expect("Not a number");
    // 如果不标注类型，编译器不知道 parse 成什么类型：
    // let guess = "42".parse().expect("Not a number");
    // 编译错误：type annotations needed

    // 也可以用 turbofish 语法 ::<> 指定
    let guess = "42".parse::<u32>().expect("Not a number");

    // 函数签名必须显式标注类型（不推导）
    fn add(a: i32, b: i32) -> i32 {
        a + b  // 表达式，无分号，作为返回值
    }
}
```

> **对照 C++**：C++ 的 `auto` 是从初始化表达式推导类型（单向推导），而 Rust 的类型推导考虑整个函数体的使用上下文（双向推导），更强大。但 Rust 函数签名必须显式标注，这是有意设计——函数签名是 API 契约，不应该被实现细节影响。C++ 中函数返回类型可以用 `auto` 推导（C++14），但这会导致头文件中看不到返回类型，API 不清晰。

## 5. Rust 是表达式语言

Rust 中几乎所有结构都是表达式，有值、有类型。语句（statement）只执行操作，不返回值。关键区别：**表达式不以分号结尾，语句以分号结尾**。

```rust
fn main() {
    // if 是表达式，可以赋值
    let condition = true;
    let number = if condition { 5 } else { 6 };
    println!("number = {}", number); // 5

    // 块是表达式，最后一个表达式的值是块的值
    let x = {
        let y = 10;
        y + 5  // 无分号，表达式，值为 15
    };
    println!("x = {}", x); // 15

    // 函数返回值：最后一个表达式
    fn square(n: i32) -> i32 {
        n * n  // 无分号，表达式
        // 等价于 return n * n;
    }

    // 加了分号变成语句，返回 ()
    fn returns_unit() -> i32 {
        // 5;  // 编译错误：mismatched types，期望 i32 得到 ()
        5
    }

    // loop 也是表达式
    let mut counter = 0;
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2;  // break 带值
        }
    };
    println!("result = {}", result); // 20
}
```

> **对照 C++**：C++ 中 `if`、`for`、`while` 是语句，不能直接赋值。C++ 中需要用三元运算符 `?:` 或立即调用的 lambda 来实现类似效果。Rust 的表达式语言设计使得代码更简洁，控制流可以自然地参与表达式组合。

## 6. 控制流：if / loop / while / for

### 6.1 if 表达式

```rust
fn main() {
    let n = 7;

    if n % 2 == 0 {
        println!("even");
    } else if n % 3 == 0 {
        println!("divisible by 3");
    } else {
        println!("odd");
    }

    // if let 简化 Option 匹配（详见模式匹配章节）
    let some_value = Some(3);
    if let Some(3) = some_value {
        println!("three");
    }
}
```

注意：Rust 的 `if` 条件必须是 `bool` 类型，不会自动转换：

```rust
let x = 1;
// if x { }  // 编译错误：mismatched types，期望 bool 得到整数
if x != 0 { } // OK
```

C++ 中 `if (x)` 会自动将非零值转为 true，Rust 禁止这种隐式转换，减少歧义。

### 6.2 loop 与 break 带值

`loop` 是无限循环，必须用 `break` 退出：

```rust
fn main() {
    let mut count = 0;

    // 带标签的循环（处理嵌套循环 break/continue）
    'outer: loop {
        println!("outer iteration: {}", count);
        count += 1;

        'inner: loop {
            if count >= 3 {
                break 'outer;  // 跳出外层循环
            }
            println!("  inner");
            break 'inner;  // 跳出内层循环
        }
    }

    // break 带值：loop 表达式的值
    let mut i = 0;
    let found = loop {
        if i * i > 100 {
            break i;  // 返回 i
        }
        i += 1;
    };
    println!("first n where n^2 > 100: {}", found); // 11
}
```

> **对照 C++**：C++ 的 `break` 不能带值，需要在循环外声明变量并赋值。C++ 的 `goto` 可以跳出嵌套循环，但被认为是不良风格。Rust 的循环标签 `'outer` 是结构化的嵌套循环控制方案，`break 'label` 清晰且安全。

### 6.3 while 与 for

```rust
fn main() {
    // while 循环
    let mut n = 3;
    while n != 0 {
        println!("{}!", n);
        n -= 1;
    }
    println!("LIFTOFF!!!");

    // for 循环遍历迭代器
    let arr = [10, 20, 30, 40, 50];
    for element in arr {
        println!("value: {}", element);
    }

    // 范围
    for i in 1..5 {       // 1, 2, 3, 4（左闭右开）
        println!("{}", i);
    }
    for i in (1..5).rev() { // 4, 3, 2, 1（逆序）
        println!("{}", i);
    }

    // enumerate 获取索引
    for (i, v) in arr.iter().enumerate() {
        println!("arr[{}] = {}", i, v);
    }
}
```

> **对照 C++**：Rust 的 `for` 循环本质是 `for item in iterator`，等价于 C++11 的范围 for `for (auto& item : container)`。但 Rust 的 `for` 直接消费迭代器，配合迭代器适配器（map/filter 等）可以表达复杂逻辑。C++ 的传统 `for (int i = 0; i < n; i++)` 在 Rust 中用 `for i in 0..n` 替代，更安全（不会写错边界条件）。

## 7. 字符串全景：str / &str / String

Rust 的字符串系统是初学者最容易困惑的部分，核心是区分"字符串字面量"和"可增长字符串"。

### 7.1 str 与 &str

`str` 是字符串切片类型，表示 UTF-8 编码的字节序列，是 DST（动态大小类型），不能直接使用。`&str` 是对 `str` 的引用（胖指针：指针 + 长度），是最常用的字符串视图。

```rust
fn main() {
    // 字符串字面量：&'static str，存储在只读数据段
    let s1: &str = "hello";
    let s2: &'static str = "world";  // 'static 生命周期：整个程序运行期

    // 从 String 创建切片
    let s = String::from("hello world");
    let hello: &str = &s[0..5];  // 借用 s 的一部分
    let world: &str = &s[6..11];

    // 字符串字面量拼接（编译期）
    let combined = "hello" ", " "world";  // "hello, world"

    // &str 的方法
    let s = "Hello, Rust!";
    println!("length: {}", s.len());       // 12（字节数，非字符数）
    println!("is empty: {}", s.is_empty()); // false
    println!("starts with: {}", s.starts_with("Hello")); // true
    println!("contains: {}", s.contains("Rust")); // true

    // 按字符迭代（UTF-8 安全）
    for c in "你好".chars() {
        println!("{}", c); // 你, 好
    }

    // 按字节迭代
    for b in "你好".bytes() {
        println!("{}", b); // 228, 189, 160, 229, 165, 189
    }
}
```

### 7.2 String 与可变性

`String` 是可增长、可变、拥有所有权的 UTF-8 字符串，内部是 `Vec<u8>` 的封装。

```rust
fn main() {
    // 创建 String
    let mut s = String::new();
    s.push_str("hello");
    s.push(' ');
    s.push_str("world");

    let s2 = String::from("hello");
    let s3 = "hello".to_string();
    let s4 = format!("{} {}", "hello", "world"); // 格式化创建

    // 修改
    let mut s = String::from("foo");
    s.push_str("bar");      // 追加 &str
    s.push('!');             // 追加 char
    s.insert(0, '>');        // 插入
    s.replace_range(0..1, "<"); // 替换范围
    println!("{}", s); // <foobar!

    // 拼接
    let s1 = String::from("Hello, ");
    let s2 = String::from("world!");
    let s3 = s1 + &s2;  // s1 被 move，s2 被借用
    // println!("{}", s1); // 编译错误：s1 已被 move

    // 更清晰的拼接
    let s = format!("{}-{}-{}", "a", "b", "c"); // "a-b-c"

    // String 与 &str 的转换
    let s = String::from("hello");
    let s_ref: &str = &s;       // 自动解引用
    let s_owned: String = s_ref.to_string(); // &str -> String
}
```

| 类型 | 所有权 | 可变性 | 内存位置 | C++ 对应 |
|---|---|---|---|---|
| `&str` | 借用 | 不可变 | 引用任意位置 | `std::string_view` (C++17) |
| `String` | 拥有 | 可变 | 堆 | `std::string` |
| `&'static str` | 借用（静态） | 不可变 | 只读数据段 | 字符串字面量 `const char*` |

> **对照 C++**：C++ 中 `const char*` 和 `std::string` 的转换是隐式的（`std::string` 构造函数接受 `const char*`），但容易导致悬垂指针。Rust 中 `String` 和 `&str` 的转换是显式的（`&s` 或 `.to_string()`），借用检查器保证 `&str` 不会在 `String` 被释放后使用。

### 7.3 字节串与原始字符串

```rust
fn main() {
    // 字节串：b"..." 类型为 &[u8; N]
    let bytes: &[u8; 5] = b"hello";
    println!("{:?}", bytes); // [104, 101, 108, 108, 111]

    // 原始字符串：r"..." 不处理转义
    let path = r"C:\Users\name\file.txt";  // 不需要 \\
    let regex = r"\d+\.\d+";                 // 正则表达式友好

    // 带分隔符的原始字符串：r#"..."# 处理包含 " 的情况
    let html = r#"<a href="link">text</a>"#;

    // 原始字节串
    let raw_bytes = br#"hello "world""#;
}
```

### 7.4 格式化输出

```rust
fn main() {
    let name = "Rust";
    let version = 1.75;

    // 基本格式化
    println!("Hello, {}!", name);           // Hello, Rust!
    println!("Version: {:.1}", version);    // Version: 1.8（四舍五入）

    // 命名参数
    println!("{greeting}, {name}!", greeting = "Hello", name = "World");

    // 位置参数
    println!("{0} + {1} = {2}", 1, 2, 3);

    // 格式 trait
    println!("Debug: {:?}", vec![1, 2, 3]); // Debug: [1, 2, 3]
    println!("Pretty: {:#?}", vec![1, 2, 3]); // 多行美化输出

    // 填充与对齐
    println!("{:>5}", "x");    // "    x"（右对齐，宽度5）
    println!("{:<5}", "x");    // "x    "（左对齐）
    println!("{:^5}", "x");    // "  x  "（居中）
    println!("{:0>5}", 42);    // "00042"（零填充）
    println!("{:#x}", 255);    // "0xff"（十六进制带前缀）
    println!("{:#b}", 5);      // "0b101"（二进制带前缀）

    // format! 宏创建 String
    let s = format!("{} is version {}", name, version);
}
```

格式化参数在编译期检查，格式字符串与参数不匹配会编译错误（C++ 的 `printf` 是运行时检查，`std::format` C++20 才支持编译期检查）。

## 8. 快速参考卡片

| 需求 | 写法 |
| --- | --- |
| 变量绑定 | `let x = 1;`（不可变）；`let mut y = 2;`（可变）；`let x = x + 1;`（遮蔽 shadowing） |
| 标量类型 | `i8..i128` / `u8..u128`、`f32/f64`、`bool`、`char`（4 字节 Unicode） |
| 整数溢出 | debug panic、release 回绕；显式 `wrapping_` / `checked_` / `saturating_` |
| 复合类型 | `(i32, f64)` 元组；`[T; N]` 数组；`&[T]` 切片 |
| 字符串 | `&str`（借用）vs `String`（拥有）；切片 `&s[..]` 需落在 char 边界 |
| 表达式语言 | `if` / `match` / 块均返回值；末尾有无 `;` 决定是否返回值 |
| 控制流 | `loop { break v; }`；`while let Some(x) = it.next()`；`for x in &v` |
| 类型转换 | `as`（数值）、`From` / `Into`、`TryFrom`、`"1".parse::<i32>()` |
| 常量/静态 | `const N: u32 = 1;`（编译期内联）；`static S: ...`（全局地址） |
| 常见坑 | 整数溢出；`String` 不支持 `s[0]` 索引；`&str` 生命周期；遮蔽易与赋值混淆 |

## 9. 常见坑与编译错误

### 错误 1：不可变变量重新赋值

```text
error[E0384]: cannot assign twice to immutable variable `x`
 --> src/main.rs:3:5
  |
2 |     let x = 5;
  |         - first assignment to `x`
3 |     x = 6;
  |     ^^^^^ cannot assign twice to immutable variable
```
**原因**：`let x` 默认不可变。**修复**：`let mut x = 5;`

### 错误 2：if 分支类型不一致

```text
error[E0308]: `if` and `else` have incompatible types
 --> src/main.rs:4:14
  |
3 |       let x = if true { 5 } else { "six" };
  |                                   ^^^^^ expected integer, found `&str`
```
**原因**：if 表达式的所有分支必须返回相同类型。**修复**：统一分支类型，如 `else { 6 }`。

### 错误 3：数组越界（运行时）

```text
thread 'main' panicked at src/main.rs:3:15:
index out of bounds: the len is 3 but the index is 5
```
**原因**：运行时索引检查。**修复**：检查索引范围，或使用 `.get(index)` 返回 `Option`。

### 错误 4：字符串索引

```text
error[E0277]: the type `str` cannot be indexed by `{integer}`
 --> src/main.rs:2:13
  |
2 |     let c = s[0];
  |             ^^^^ string indices are ranges of `usize`
```
**原因**：Rust 不允许用整数索引 `str`（因为 UTF-8 字符宽度不固定）。**修复**：`s.chars().next()` 或 `&s[0..1]`（需确保是字符边界）。

### 错误 5：类型推导失败

```text
error[E0282]: type annotations needed
 --> src/main.rs:2:9
  |
2 |     let x = "42".parse().unwrap();
  |         ^ consider giving `x` a type
```
**原因**：`parse()` 是泛型方法，编译器无法推导目标类型。**修复**：`let x: i32 = "42".parse().unwrap();` 或 `"42".parse::<i32>()`。

## 10. 本节小结

- Rust 变量默认不可变，`mut` 显式声明可变性；遮蔽（shadowing）允许同作用域重新声明同名变量，且可改变类型。
- 标量类型包括整数（`i32` 默认，`isize`/`usize` 指针宽度）、浮点（`f64` 默认）、布尔、字符（4 字节 Unicode）。整数溢出在 debug 模式 panic，release 模式回绕。
- 复合类型包括元组（固定长度、类型可异）、数组（固定长度、栈分配）、切片（胖指针、运行时长度）。
- Rust 类型推导强大（双向推导），但函数签名必须显式标注。
- Rust 是表达式语言：if、块、loop 都是表达式，`break` 可带值，控制流可直接参与赋值。
- 字符串系统区分 `&str`（借用视图，类似 `string_view`）和 `String`（拥有所有权，类似 `std::string`），UTF-8 编码，不允许整数索引。
- 常见编译错误包括不可变赋值、if 分支类型不一致、类型推导失败等，编译器错误信息通常包含修复建议。
