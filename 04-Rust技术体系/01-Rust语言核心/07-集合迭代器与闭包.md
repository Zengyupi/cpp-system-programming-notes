## 1. 核心集合类型

### 1.1 序列：Vec / VecDeque / LinkedList

```rust
fn main() {
    // Vec：动态数组，堆分配，连续内存
    let mut v: Vec<i32> = Vec::new();
    v.push(1);
    v.push(2);
    v.push(3);

    let v2 = vec![1, 2, 3];       // 宏创建
    let v3 = vec![0; 10];          // 10 个 0

    // 访问：索引（越界 panic）或 get（返回 Option）
    let first = v[0];               // 1
    let safe = v.get(10);           // None（不 panic）

    // 常用方法
    v.pop();                         // 弹出末尾，返回 Option
    v.insert(0, 100);               // 插入（O(n)，后续元素后移）
    v.remove(0);                     // 移除（O(n)）
    v.len();                         // 长度
    v.capacity();                    // 容量
    v.shrink_to_fit();               // 收缩容量到长度
    v.sort();                        // 排序
    v.dedup();                       // 去重（需先排序）
    v.clear();                       // 清空

    // VecDeque：双端队列，环形缓冲区，O(1) 头尾操作
    use std::collections::VecDeque;
    let mut deque: VecDeque<i32> = VecDeque::new();
    deque.push_back(1);
    deque.push_front(0);
    let front = deque.pop_front();  // Some(0)
    let back = deque.pop_back();    // Some(1)

    // LinkedList：双向链表，O(1) 中间插入（有迭代器时），但缓存不友好
    use std::collections::LinkedList;
    let mut list: LinkedList<i32> = LinkedList::new();
    list.push_back(1);
    list.push_front(0);
}
```

| 特性 | Vec | VecDeque | LinkedList |
|---|---|---|---|
| 内存布局 | 连续数组 | 环形缓冲区（多段） | 节点（含前后指针） |
| 随机访问 | O(1) | O(1) | O(n) |
| 头部插入/删除 | O(n) | O(1) | O(1) |
| 尾部插入/删除 | O(1) 均摊 | O(1) | O(1) |
| 中间插入/删除 | O(n) | O(n) | O(1)（有迭代器） |
| 缓存友好性 | 最佳 | 较好 | 最差 |
| 迭代器失效 | 插入可能 | 可能 | 仅被删除节点失效 |
| C++ 对应 | `std::vector` | `std::deque` | `std::list` |

> **选型建议**：95% 的场景用 `Vec`。需要频繁头尾操作时用 `VecDeque`。`LinkedList` 在 Rust 中几乎不推荐使用——由于所有权和借用规则，链表的实现和使用都比 C++ 困难，且现代 CPU 缓存使连续内存的 Vec 在大多数场景下更快。

### 1.2 映射：HashMap / BTreeMap

```rust
use std::collections::{HashMap, BTreeMap};

fn main() {
    // HashMap：哈希表，平均 O(1) 查找，无序
    let mut scores: HashMap<String, i32> = HashMap::new();
    scores.insert(String::from("Blue"), 10);
    scores.insert(String::from("Red"), 50);

    // 访问
    let blue_score = scores.get("Blue");        // Option<&i32>
    let blue_score = scores["Blue"];             // 10（不存在则 panic）

    // 插入/更新
    scores.insert(String::from("Blue"), 25);     // 覆盖
    scores.entry(String::from("Yellow")).or_insert(50);  // 不存在则插入
    scores.entry(String::from("Blue")).and_modify(|v| *v += 10);  // 存在则修改

    // 迭代（无序）
    for (key, value) in &scores {
        println!("{}: {}", key, value);
    }

    // BTreeMap：B 树，O(log n) 查找，有序（按 key 排序）
    let mut map: BTreeMap<i32, &str> = BTreeMap::new();
    map.insert(3, "three");
    map.insert(1, "one");
    map.insert(2, "two");

    // 有序迭代
    for (key, value) in &map {
        println!("{}: {}", key, value);  // 1: one, 2: two, 3: three
    }

    // 范围查询（BTreeMap 独有）
    for (key, value) in map.range(1..3) {
        println!("{}: {}", key, value);  // 1: one, 2: two
    }
}
```

| 特性 | HashMap | BTreeMap |
|---|---|---|
| 底层结构 | 哈希表（SipHash 1-3） | B 树 |
| 查找 | 平均 O(1)，最坏 O(n) | O(log n) |
| 插入/删除 | 平均 O(1) | O(log n) |
| 顺序 | 无序 | 按 key 有序 |
| 范围查询 | 不支持 | 支持（`range`） |
| Key 要求 | `Eq + Hash` | `Ord` |
| 内存开销 | 较高（哈希表负载因子） | 较低（节点紧凑） |
| 迭代性能 | 较好 | 较好（有序遍历） |
| C++ 对应 | `std::unordered_map` | `std::map` |

> **注意**：Rust 的 `HashMap` 默认使用 SipHash 算法，抗哈希碰撞拒绝服务攻击，但比 C++ `std::unordered_map` 的默认哈希慢。如果需要极致性能且不担心 HashDoS，可以使用 `rustc-hash`（FxHash）或 `ahash` 等第三方 crate。

### 1.3 集合：HashSet / BTreeSet

`HashSet<T>` 和 `BTreeSet<T>` 本质是 `HashMap<T, ()>` 和 `BTreeMap<T, ()>`，只存 key 不存 value：

```rust
use std::collections::HashSet;

fn main() {
    let mut set: HashSet<i32> = HashSet::new();
    set.insert(1);
    set.insert(2);
    set.insert(2);  // 重复插入无效

    println!("{}", set.contains(&1));  // true
    println!("{}", set.len());          // 2

    // 集合运算
    let a: HashSet<i32> = [1, 2, 3].iter().cloned().collect();
    let b: HashSet<i32> = [2, 3, 4].iter().cloned().collect();

    let intersection: HashSet<_> = a.intersection(&b).collect();  // {2, 3}
    let union: HashSet<_> = a.union(&b).collect();                 // {1, 2, 3, 4}
    let difference: HashSet<_> = a.difference(&b).collect();       // {1}
    let symmetric_diff: HashSet<_> = a.symmetric_difference(&b).collect(); // {1, 4}
}
```

### 1.4 String 与 Vec<u8>

`String` 内部是 `Vec<u8>` 的封装，保证内容是合法 UTF-8：

```rust
fn main() {
    // String -> Vec<u8>
    let s = String::from("hello");
    let bytes: Vec<u8> = s.into_bytes();  // 消费 String，返回 Vec<u8>

    // Vec<u8> -> String（需要验证 UTF-8）
    let bytes = vec![104, 101, 108, 108, 111];
    let s = String::from_utf8(bytes).unwrap();  // 验证，失败返回 Err
    let s = String::from_utf8_lossy(&bytes);     // 不验证，非法序列替换为 U+FFFD

    // 直接操作字节（unsafe，因为可能破坏 UTF-8）
    let mut s = String::from("hello");
    unsafe {
        let bytes = s.as_mut_vec();
        bytes.push(b'!');
    }
    println!("{}", s);  // hello!
}
```

### 1.5 集合选型决策表

| 需求 | 推荐类型 | 理由 |
|---|---|---|
| 通用动态数组 | `Vec<T>` | 连续内存、缓存友好、API 丰富 |
| 频繁头尾增删 | `VecDeque<T>` | O(1) 双端操作 |
| 键值对、快速查找 | `HashMap<K,V>` | 平均 O(1) 查找 |
| 键值对、有序遍历 | `BTreeMap<K,V>` | O(log n)、有序、支持范围查询 |
| 去重集合 | `HashSet<T>` | 平均 O(1) 查找 |
| 有序去重集合 | `BTreeSet<T>` | 有序、支持范围 |
| 栈 | `Vec<T>`（push/pop） | 尾部操作 O(1) |
| 队列 | `VecDeque<T>` | 双端 O(1) |
| 优先队列 | `BinaryHeap<T>` | 最大堆，O(log n) 插入/弹出 |

## 2. 迭代器 trait 体系

### 2.1 Iterator / IntoIterator / FromIterator

```rust
// Iterator：核心 trait，定义 next()
pub trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
    // 大量默认方法（map, filter, collect 等）
}

// IntoIterator：转换为迭代器
pub trait IntoIterator {
    type Item;
    type IntoIter: Iterator<Item = Self::Item>;
    fn into_iter(self) -> Self::IntoIter;
}

// FromIterator：从迭代器收集为集合
pub trait FromIterator<A>: Sized {
    fn from_iter<T: IntoIterator<Item = A>>(iter: T) -> Self;
}
```

三个 trait 的关系：
- `IntoIterator` → 调用 `into_iter()` 得到 `Iterator`
- `Iterator` → 调用 `collect()`（内部用 `FromIterator`）得到集合
- `for` 循环自动调用 `IntoIterator::into_iter()`

### 2.2 迭代器的三种获取方式

```rust
fn main() {
    let v = vec![1, 2, 3];

    // 1. iter()：不可变借用迭代，Item = &T
    for x in v.iter() {
        // x: &i32
        println!("{}", x);
    }
    // v 仍然可用

    // 2. iter_mut()：可变借用迭代，Item = &mut T
    let mut v2 = vec![1, 2, 3];
    for x in v2.iter_mut() {
        *x += 1;  // 修改原值
    }

    // 3. into_iter()：获取所有权迭代，Item = T
    for x in v.into_iter() {
        // x: i32，拥有所有权
        println!("{}", x);
    }
    // v 已被消费，不可再用

    // for 循环自动调用 into_iter()
    let v3 = vec![1, 2, 3];
    for x in &v3 {       // 等价于 (&v3).into_iter()，Item = &i32
        println!("{}", x);
    }
    for x in v3 {         // 等价于 v3.into_iter()，Item = i32
        println!("{}", x);
    }
    // v3 已被消费
}
```

| 方法 | 所有权 | Item 类型 | 集合是否可用 |
|---|---|---|---|
| `iter()` | 不可变借用 | `&T` | 可用 |
| `iter_mut()` | 可变借用 | `&mut T` | 可用 |
| `into_iter()` | 获取所有权 | `T` | 不可用（被消费） |

> **对照 C++**：Rust 的 `iter()` 对应 C++ 的 `cbegin()/cend()`（const 迭代器），`iter_mut()` 对应 `begin()/end()`（非 const），`into_iter()` 对应移动迭代器（C++ 没有直接对应，类似 `std::make_move_iterator`）。Rust 的三种迭代器通过所有权系统明确区分，避免了 C++ 中迭代器失效的常见问题。

## 3. 迭代器适配器（惰性）

迭代器适配器（adapter）是惰性的——它们不立即执行，而是返回新的迭代器，直到被消费者（consumer）求值才执行。

### 3.1 map / filter / filter_map

```rust
fn main() {
    let numbers = vec![1, 2, 3, 4, 5];

    // map：转换每个元素
    let doubled: Vec<i32> = numbers.iter().map(|x| x * 2).collect();
    // [2, 4, 6, 8, 10]

    // filter：保留满足条件的元素
    let evens: Vec<&i32> = numbers.iter().filter(|x| *x % 2 == 0).collect();
    // [2, 4]

    // filter_map：map + filter，返回 Option，Some 保留，None 过滤
    let parsed: Vec<i32> = ["1", "abc", "3", "x"]
        .iter()
        .filter_map(|s| s.parse::<i32>().ok())
        .collect();
    // [1, 3]
}
```

### 3.2 take / skip / take_while / skip_while

```rust
fn main() {
    let numbers = vec![1, 2, 3, 4, 5];

    // take：取前 n 个
    let first_three: Vec<_> = numbers.iter().take(3).collect();  // [1, 2, 3]

    // skip：跳过前 n 个
    let rest: Vec<_> = numbers.iter().skip(2).collect();  // [3, 4, 5]

    // take_while：取到条件不满足为止
    let until_four: Vec<_> = numbers.iter().take_while(|x| **x < 4).collect();
    // [1, 2, 3]

    // skip_while：跳过条件满足的，之后全部保留
    let after_two: Vec<_> = numbers.iter().skip_while(|x| **x < 3).collect();
    // [3, 4, 5]
}
```

### 3.3 zip / enumerate / chain

```rust
fn main() {
    let a = vec![1, 2, 3];
    let b = vec!['a', 'b', 'c'];

    // zip：将两个迭代器合并为元组
    let zipped: Vec<_> = a.iter().zip(b.iter()).collect();
    // [(1, 'a'), (2, 'b'), (3, 'c')]

    // enumerate：添加索引
    let indexed: Vec<_> = a.iter().enumerate().collect();
    // [(0, 1), (1, 2), (2, 3)]

    // chain：连接两个迭代器
    let combined: Vec<_> = a.iter().chain(b.iter().map(|c| *c as i32)).collect();
    // [1, 2, 3, 97, 98, 99]
}
```

### 3.4 flat_map / flatten / inspect

```rust
fn main() {
    // flat_map：每个元素映射为迭代器，然后扁平化
    let words = vec!["hello", "world"];
    let chars: Vec<char> = words.iter().flat_map(|s| s.chars()).collect();
    // ['h', 'e', 'l', 'l', 'o', 'w', 'o', 'r', 'l', 'd']

    // flatten：扁平化嵌套迭代器
    let nested = vec![vec![1, 2], vec![3, 4]];
    let flat: Vec<i32> = nested.into_iter().flatten().collect();
    // [1, 2, 3, 4]

    // inspect：查看元素但不修改（调试用）
    let sum: i32 = vec![1, 2, 3]
        .into_iter()
        .inspect(|x| println!("before: {}", x))
        .map(|x| x * 2)
        .inspect(|x| println!("after: {}", x))
        .sum();
}
```

### 3.5 rev / copied / cloned

```rust
fn main() {
    // rev：反转（需要 DoubleEndedIterator）
    let reversed: Vec<_> = (1..=5).rev().collect();  // [5, 4, 3, 2, 1]

    // copied：复制 Copy 类型的引用，Item 从 &T 变为 T
    let v = vec![1, 2, 3];
    let copied: Vec<i32> = v.iter().copied().collect();  // [1, 2, 3]

    // cloned：克隆 Clone 类型的引用
    let strings = vec![String::from("a"), String::from("b")];
    let cloned: Vec<String> = strings.iter().cloned().collect();
}
```

## 4. 消费者（求值）

消费者（consumer）触发迭代器的实际求值，消耗迭代器并产生结果。

### 4.1 collect / to_vec

```rust
fn main() {
    // collect：收集为任何实现了 FromIterator 的类型
    let v: Vec<i32> = (1..=5).collect();
    let s: HashSet<i32> = (1..=5).collect();
    let m: HashMap<i32, char> = (1..=3).zip('a'..='c').collect();

    // turbofish 指定目标类型
    let v = (1..=5).collect::<Vec<i32>>();

    // to_vec：收集为 Vec（需要迭代器 Item 是 Copy 或使用 cloned）
    let v: Vec<i32> = (1..=5).collect();  // 等价
}
```

### 4.2 fold / reduce / scan

```rust
fn main() {
    // fold：从初始值开始，累积计算
    let sum = (1..=5).fold(0, |acc, x| acc + x);  // 15
    let product = (1..=5).fold(1, |acc, x| acc * x);  // 120

    // fold 可以产生任何类型
    let reversed = (1..=5).fold(String::new(), |acc, x| format!("{}{}", x, acc));
    // "54321"

    // reduce：无初始值，第一个元素作为初始值，返回 Option
    let max = (1..=5).reduce(|a, b| if a > b { a } else { b });  // Some(5)
    let empty: Option<i32> = std::iter::empty().reduce(|a, b| a + b);  // None

    // scan：有状态的 fold，可以提前终止
    let result: Vec<i32> = (1..=10)
        .scan(0, |state, x| {
            *state += x;
            if *state > 10 { None } else { Some(*state) }
        })
        .collect();
    // [1, 3, 6, 10]（1+2=3, 3+3=6, 6+4=10, 10+5=15>10 终止）
}
```

### 4.3 sum / product / count

```rust
fn main() {
    let v = vec![1, 2, 3, 4, 5];

    let sum: i32 = v.iter().sum();        // 15
    let product: i32 = v.iter().product(); // 120
    let count = v.iter().count();          // 5

    // 条件计数
    let even_count = v.iter().filter(|x| *x % 2 == 0).count();  // 2
}
```

### 4.4 any / all / find / position

```rust
fn main() {
    let v = vec![1, 2, 3, 4, 5];

    // any：是否有元素满足条件
    let has_even = v.iter().any(|x| x % 2 == 0);  // true

    // all：是否所有元素满足条件
    let all_positive = v.iter().all(|x| *x > 0);  // true

    // find：找到第一个满足条件的元素（返回 Option<&T>）
    let first_even = v.iter().find(|x| *x % 2 == 0);  // Some(&2)

    // position：找到第一个满足条件的索引
    let first_even_idx = v.iter().position(|x| x % 2 == 0);  // Some(1)
}
```

### 4.5 min / max / min_by / max_by

```rust
fn main() {
    let v = vec![3, 1, 4, 1, 5, 9, 2, 6];

    let min = v.iter().min();  // Some(&1)
    let max = v.iter().max();  // Some(&9)

    // 自定义比较
    let words = vec!["apple", "banana", "kiwi", "fig"];
    let longest = words.iter().max_by(|a, b| a.len().cmp(&b.len()));  // Some("banana")
    let shortest = words.iter().min_by_key(|w| w.len());  // Some("kiwi")
}
```

## 5. 闭包：语法与捕获

### 5.1 闭包语法与类型推导

闭包（closure）是可以捕获环境变量的匿名函数：

```rust
fn main() {
    // 完整语法
    let add = |a: i32, b: i32| -> i32 { a + b };

    // 简化：类型推导（参数和返回值类型可省略）
    let add = |a, b| a + b;  // 编译器根据使用推导类型

    // 单表达式闭包（无花括号）
    let double = |x| x * 2;

    // 多语句闭包（需要花括号）
    let complex = |x| {
        let y = x * 2;
        y + 1
    };

    // 调用（与函数相同）
    println!("{}", add(2, 3));  // 5
    println!("{}", double(5));   // 10

    // 闭包捕获环境变量
    let factor = 3;
    let multiply = |x| x * factor;  // 捕获 factor
    println!("{}", multiply(5));    // 15
}
```

闭包与函数的关键区别：
- 闭包可以捕获环境变量，函数不能
- 闭包参数和返回值类型可以推导（函数必须显式标注）
- 每个闭包有唯一的匿名类型，即使签名相同也不是同一类型

### 5.2 三种捕获 trait：Fn / FnMut / FnOnce

闭包根据捕获环境的方式实现三个 trait 之一：

```rust
// Fn：不可变借用环境（&self），可以多次调用，不修改环境
pub trait Fn<Args>: FnMut<Args> {
    extern "rust-call" fn call(&self, args: Args) -> Self::Output;
}

// FnMut：可变借用环境（&mut self），可以多次调用，修改环境
pub trait FnMut<Args>: FnOnce<Args> {
    extern "rust-call" fn call_mut(&mut self, args: Args) -> Self::Output;
}

// FnOnce：获取环境所有权（self），只能调用一次
pub trait FnOnce<Args> {
    type Output;
    extern "rust-call" fn call_once(self, args: Args) -> Self::Output;
}
```

trait 继承关系：`Fn: FnMut: FnOnce`（Fn 一定是 FnMut，FnMut 一定是 FnOnce）。

```rust
fn main() {
    // Fn：不可变借用，可多次调用
    let factor = 2;
    let f1 = |x| x * factor;  // 不可变借用 factor
    println!("{}", f1(5));    // 10
    println!("{}", f1(3));    // 6
    println!("factor = {}", factor);  // factor 仍然可用

    // FnMut：可变借用，可多次调用，修改环境
    let mut count = 0;
    let mut f2 = |x| {
        count += x;  // 修改捕获的 count
        count
    };
    println!("{}", f2(1));  // 1
    println!("{}", f2(2));  // 3
    // println!("{}", count); // 编译错误：count 被可变借用中

    // FnOnce：获取所有权，只能调用一次
    let s = String::from("hello");
    let f3 = move || {
        let s2 = s;  // 获取 s 的所有权
        s2.len()
    };
    println!("{}", f3());  // 5
    // println!("{}", f3()); // 编译错误：f3 只能调用一次（FnOnce）
    // println!("{}", s);    // 编译错误：s 已被 move
}
```

| trait | 捕获方式 | 调用次数 | 能否修改环境 | `self` 类型 |
|---|---|---|---|---|
| `Fn` | 不可变借用 | 多次 | 不能 | `&self` |
| `FnMut` | 可变借用 | 多次 | 能 | `&mut self` |
| `FnOnce` | 获取所有权 | 一次 | 能（消费环境） | `self` |

> **对照 C++**：C++ lambda 的捕获方式是 `[]`、`[&]`、`[=]`、`[&var]`、`[var]`，在 lambda 创建时确定。Rust 闭包的捕获方式由编译器根据闭包体中的使用自动推导（不可变借用→可变借用→move），更智能。C++ lambda 是可调用对象（实现 `operator()`），Rust 闭包实现 `Fn`/`FnMut`/`FnOnce` trait，概念类似但 Rust 的 trait 体系更统一。

### 5.3 move 闭包

`move` 关键字强制闭包获取捕获变量的所有权：

```rust
fn main() {
    let s = String::from("hello");

    // 非 move：编译器自动选择借用
    let len = || s.len();  // 不可变借用 s
    println!("{}", len());  // 5
    println!("{}", s);      // OK，s 仍然可用

    // move：强制获取所有权
    let len_move = move || s.len();  // move s 进闭包
    println!("{}", len_move());       // 5
    // println!("{}", s);             // 编译错误：s 已被 move

    // move 闭包常用于线程（跨线程传递所有权）
    use std::thread;
    let data = vec![1, 2, 3];
    let handle = thread::spawn(move || {
        println!("{:?}", data);  // data 被 move 进线程
    });
    handle.join().unwrap();
    // println!("{:?}", data);  // 编译错误：data 已被 move
}
```

`move` 闭包不一定实现 `FnOnce`——如果闭包体只使用借用（不消费捕获的值），move 闭包可以实现 `Fn`/`FnMut`。`move` 只影响**捕获方式**（获取所有权），不影响**调用次数**。

### 5.4 闭包作为参数与返回值

```rust
// 闭包作为参数：impl Trait（静态分发）
fn apply<F: Fn(i32) -> i32>(f: F, x: i32) -> i32 {
    f(x)
}

// 等价的 where 写法
fn apply2<F>(f: F, x: i32) -> i32
where
    F: Fn(i32) -> i32,
{
    f(x)
}

// 闭包作为参数：&dyn Fn（动态分发）
fn apply_dyn(f: &dyn Fn(i32) -> i32, x: i32) -> i32 {
    f(x)
}

// 闭包作为返回值：impl Trait（必须返回同一具体类型）
fn make_adder(x: i32) -> impl Fn(i32) -> i32 {
    move |y| x + y
}

// 返回不同闭包类型：需要 Box<dyn Fn>（动态分发）
fn make_closure(flag: bool) -> Box<dyn Fn(i32) -> i32> {
    if flag {
        Box::new(|x| x * 2)
    } else {
        Box::new(|x| x + 1)
    }
}

fn main() {
    let double = |x| x * 2;
    println!("{}", apply(double, 5));    // 10
    println!("{}", apply_dyn(&double, 5)); // 10

    let add5 = make_adder(5);
    println!("{}", add5(3));  // 8

    let c = make_closure(true);
    println!("{}", c(5));  // 10
}
```

## 6. 迭代器零成本原理

Rust 迭代器的零成本抽象（zero-cost abstraction）基于两个关键机制：

1. **单态化（monomorphization）**：泛型迭代器适配器在编译期为每个具体类型生成专用代码，无虚函数调用开销。
2. **内联（inlining）**：迭代器的 `next()` 方法和闭包都是小函数，编译器会内联，消除函数调用开销。

```rust
// 源码：迭代器链式调用
let sum: i32 = (1..=100)
    .filter(|x| x % 2 == 0)
    .map(|x| x * x)
    .sum();

// 编译优化后（概念上）：等价于手写循环
let mut sum = 0;
for x in 1..=100 {
    if x % 2 == 0 {
        sum += x * x;
    }
}
```

编译器甚至可以进一步优化：循环展开、向量化（SIMD）、常量传播等。生成的汇编代码与手写 C 循环性能相当。

> **对照 C++**：C++ STL 算法（`std::find_if`、`std::transform`）配合 lambda 也能实现零成本抽象（模板实例化 + 内联）。但 C++ 的迭代器是"指针对"（begin/end），每个算法需要单独实现；Rust 的迭代器是"有状态的 next()"，适配器通过组合实现，表达力更强且代码更简洁。Rust 的迭代器适配器是惰性的，只有消费者触发才求值，这与 C++ 的 ranges（C++20）类似。

## 7. 综合示例：数据处理管道

```rust
use std::collections::HashMap;

#[derive(Debug)]
struct Order {
    id: u32,
    customer: String,
    amount: f64,
    category: String,
    status: OrderStatus,
}

#[derive(Debug, PartialEq)]
enum OrderStatus {
    Pending,
    Completed,
    Cancelled,
}

fn main() {
    let orders = vec![
        Order { id: 1, customer: "Alice".into(), amount: 150.0, category: "Electronics".into(), status: OrderStatus::Completed },
        Order { id: 2, customer: "Bob".into(), amount: 75.5, category: "Books".into(), status: OrderStatus::Pending },
        Order { id: 3, customer: "Alice".into(), amount: 200.0, category: "Electronics".into(), status: OrderStatus::Completed },
        Order { id: 4, customer: "Charlie".into(), amount: 50.0, category: "Books".into(), status: OrderStatus::Cancelled },
        Order { id: 5, customer: "Bob".into(), amount: 300.0, category: "Electronics".into(), status: OrderStatus::Completed },
    ];

    // 管道1：已完成订单的总金额
    let total_completed: f64 = orders
        .iter()
        .filter(|o| o.status == OrderStatus::Completed)
        .map(|o| o.amount)
        .sum();
    println!("Total completed: {:.2}", total_completed);  // 650.00

    // 管道2：按客户分组统计金额
    let customer_totals: HashMap<&String, f64> = orders
        .iter()
        .filter(|o| o.status == OrderStatus::Completed)
        .fold(HashMap::new(), |mut acc, o| {
            *acc.entry(&o.customer).or_insert(0.0) += o.amount;
            acc
        });
    println!("{:?}", customer_totals);
    // {"Alice": 350.0, "Bob": 300.0}

    // 管道3：每个类别的平均金额（已完成订单）
    let category_avg: HashMap<&String, f64> = orders
        .iter()
        .filter(|o| o.status == OrderStatus::Completed)
        .fold(HashMap::new(), |mut acc, o| {
            let entry = acc.entry(&o.category).or_insert((0.0, 0));
            entry.0 += o.amount;
            entry.1 += 1;
            acc
        })
        .into_iter()
        .map(|(k, (total, count))| (k, total / count as f64))
        .collect();
    println!("{:?}", category_avg);
    // {"Electronics": 216.67, "Books": ...}

    // 管道4：找到金额最高的已完成订单
    let largest = orders
        .iter()
        .filter(|o| o.status == OrderStatus::Completed)
        .max_by(|a, b| a.amount.partial_cmp(&b.amount).unwrap());
    println!("Largest: {:?}", largest);

    // 管道5：客户列表（去重、排序）
    let mut customers: Vec<&String> = orders
        .iter()
        .map(|o| &o.customer)
        .collect::<std::collections::HashSet<_>>()
        .into_iter()
        .collect();
    customers.sort();
    println!("{:?}", customers);  // ["Alice", "Bob", "Charlie"]
}
```

## 9. 常见坑与编译错误

### 错误 1：cannot infer type for type parameter

```text
error[E0282]: type annotations needed
  |
  | let v = (1..5).collect();
  |           ^^^^^^^ consider giving `v` a type
```
**原因**：`collect()` 是泛型函数，编译器不知道目标集合类型。**修复**：标注类型 `let v: Vec<i32> = ...` 或 turbofish `(1..5).collect::<Vec<i32>>()`。

### 错误 2：cannot borrow `*x` as mutable, as it is behind a `&` reference

```text
error[E0596]: cannot borrow `*x` as mutable, as it is behind a `&` reference
```
**原因**：在 `iter()`（不可变迭代器）的闭包中尝试修改元素。**修复**：使用 `iter_mut()` 获取可变迭代器。

### 错误 3：the trait `Fn` is not implemented

```text
error[E0277]: expected a `Fn<()>` closure, found `()`
```
**原因**：传入的不是闭包或闭包签名不匹配。**修复**：检查闭包参数和返回值类型是否与 trait bound 一致。

### 错误 4：temporary value dropped while borrowed

```text
error[E0716]: temporary value dropped while borrowed
```
**原因**：迭代器链中创建了临时值并借用，但临时值在语句结束后 drop。**修复**：将临时值绑定到变量延长生命周期。

## 10. 本节小结

- **核心集合**：`Vec`（动态数组，95% 场景首选）、`VecDeque`（双端队列）、`HashMap`（哈希映射，平均 O(1)）、`BTreeMap`（有序映射，O(log n)，支持范围查询）、`HashSet`/`BTreeSet`（集合）。`LinkedList` 在 Rust 中不推荐。
- **迭代器 trait**：`Iterator`（核心，`next()`）、`IntoIterator`（转迭代器，`for` 循环自动调用）、`FromIterator`（从迭代器收集，`collect()` 基础）。
- **三种迭代器**：`iter()`（不可变借用，Item=&T）、`iter_mut()`（可变借用，Item=&mut T）、`into_iter()`（获取所有权，Item=T）。
- **迭代器适配器（惰性）**：`map`/`filter`/`filter_map` 转换过滤，`take`/`skip`/`take_while`/`skip_while` 截断，`zip`/`enumerate`/`chain` 组合，`flat_map`/`flatten` 扁平化，`inspect` 调试。
- **消费者（求值）**：`collect` 收集为集合，`fold`/`reduce`/`scan` 累积，`sum`/`product`/`count` 统计，`any`/`all`/`find`/`position` 查找，`min`/`max` 极值。
- **闭包**：匿名函数可捕获环境，三种捕获 trait——`Fn`（不可变借用，多次调用）、`FnMut`（可变借用，多次调用）、`FnOnce`（获取所有权，一次调用）。`move` 强制获取所有权。
- **零成本原理**：单态化 + 内联，迭代器链式调用编译后等价于手写循环，无运行时开销。
- **与 C++ 对照**：Rust 集合对应 STL 容器，迭代器对应 STL 迭代器+算法（但更统一、更简洁），闭包对应 lambda（但捕获方式自动推导、trait 体系更清晰）。
