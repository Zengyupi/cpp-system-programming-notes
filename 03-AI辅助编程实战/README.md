# AI 辅助编程教学（C++/嵌入式/后端工程师实战版）

> 本节目标：不讲大模型原理，只讲**怎么把 AI 编程工具用得又快又靠谱**——选对工具、写对提示词、让它帮你写码/重构/调试/审查，同时守住质量与代码安全红线。面向 C++/Linux/嵌入式/工业网关开发场景，所有方法都能直接落到日常工作。语言与工程基础见上级目录 `01-C++技术体系` 下的对应模块。

## 学习路径（按顺序）

```text
先建立认知
  01 工具全景与选型 ── 知道有哪几类工具、企业内网/数据合规怎么选
        │
会跟 AI 说话
  02 提示词工程与高效协作 ── 上下文/约束/示例/分步，给 C++ 的提示词模板
        │
把 AI 用在刀刃上
  03 编码、重构与测试 ── 生成样板、现代 C++ 改写、跨语言迁移、补单测、写 CMake
  04 调试与问题定位 ── 喂报错/堆栈/ASAN/Valgrind，让 AI 给假设你来验证
        │
守住底线
  05 代码审查、安全与本地化部署 ── 识别幻觉代码、Review 清单、内网本地化方案、工作流 SOP
```

## 三条铁律（先记住）

1. **AI 是副驾，不是司机**：它给的是"候选答案"，编译、跑测试、读懂每一行再合入的责任在你。
2. **上下文质量决定输出质量**：报错原文、相关头文件、编译命令、约束条件给得越全，结果越准；模糊提问只会得到正确的废话。
3. **公司源码不出内网**：工业网关、电力规约相关代码属于公司资产，优先用企业授权工具或本地化模型（见第 05 篇）。
