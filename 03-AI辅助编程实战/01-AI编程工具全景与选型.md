## 1. 四类工具，先分清

| 类别 | 工作方式 | 代表 | 最适合 |
| --- | --- | --- | --- |
| **行内补全型** | 在编辑器里根据上文灰色补全整行/整块，Tab 接受 | GitHub Copilot、通义灵码、Codeium、Tabnine、腾讯云 AI 代码助手 | 写样板、重复结构、API 调用，追求"不打断思路" |
| **对话/聊天型** | 侧边栏多轮对话，贴代码/报错进去问 | 豆包、Claude、ChatGPT、通义千问、DeepSeek | 解释概念、设计方案、debug、大段生成与重构 |
| **Agent/智能体型** | 能自己读多文件、跑命令、改代码、迭代直到任务完成 | Cursor、Claude Code、Windsurf、Cline、通义灵码 Agent | 跨多文件改造、加功能、修 bug、跑测试闭环 |
| **本地/私有部署** | 模型跑在本机或内网，代码不外传 | Ollama + Continue/Cline、Qwen2.5-Coder、DeepSeek-Coder、vLLM 部署 | 企业内网、离线、信创内网、数据合规 |

> 补全型解决"**写得快**"，对话型解决"**想得清**"，Agent 型解决"**改得全**"，本地部署解决"**安全合规**"。成熟做法是**组合使用**：编辑器里补全 + 复杂问题开对话 + 多文件改造用 Agent。

| 工具 | 形态 | C++ 理解 | 能读整个工程 | 私有化/离线 | 成本 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| GitHub Copilot | IDE 插件(补全+Chat+Agent) | 强 | 较强（Workspace） | 企业版可有限管控 | 订阅 | 生态最成熟，VS/VSCode/CLion 都支持 |

| Claude（网页/Code） | 对话 + 终端 Agent | **很强**，长代码/架构分析突出 | Claude Code 可遍历仓库 | 否（云端） | 订阅 | 啃大型 C++ 源码、写长文档首选之一 |

## 3. 选型方案

### 3.1 个人学习 / 求职准备

- 预算够：**Copilot 或 Cursor**（补全/Agent）+ 一个强对话模型（Claude/豆包）啃源码、改简历项目。
- 零预算：**通义灵码/Codeium 免费补全** + **DeepSeek/豆包/通义千问网页版对话**，能力对学习完全够用。
- 用它做什么：刷 LeetCode 让它讲思路（别只要答案）、仿写 muduo/TinyWebServer 时让它解释源码、给 Reactor 网络库补单测和压测脚本。

### 3.2 公司项目 / 工业网关 / 电力规约（重点：合规）

```text
代码能不能出公司内网？
├─ 不能（多数硬件/电力/国企情况）
│   ├─ 优先：公司统一采购、签了数据协议的企业版（企业 Copilot/灵码企业版等）
│   └─ 否则：本地/内网部署（Ollama/Qwen-Coder/DeepSeek-Coder + Continue），见第 05 篇
└─ 能（明确允许上传的非核心代码）
│   使用云端工具，但仍要脱敏：去掉 IP、密钥、客户名、业务表名
```

- **红线**：未脱敏的规约实现、密钥/证书、客户现场配置、未公开协议细节，不要贴进公网模型。
- 信创/国产化环境（ARM 鲲鹏/飞腾、统信/麒麟）本地部署见《../01-C++技术体系/02-系统原理/04-信创国产化技术栈.md》与本模块第 05 篇。

## 4. 编辑器与工程适配（C++ 特别注意）

AI 工具对 C++ 的效果高度依赖它**能不能看到项目头文件、编译参数和工程结构**：

1. **给它 `compile_commands.json`**：CMake 加 `set(CMAKE_EXPORT_COMPILE_COMMANDS ON)` 生成，AI/ clangd 才能知道真实的 include 路径、宏、交叉编译目标，补全和问答准确率明显提升。
2. **说明工具链与目标平台**：是 x86 主机还是 ARM 交叉编译？glibc 版本？C++ 标准（-std=c++17）？这些不说明，AI 容易给你主机环境的答案，编不过板子。
3. **关键第三方库给版本**：Qt 5 还是 Qt 6、Boost 版本、OpenSSL 1.1 还是 3.x，API 差异很大。
4. 大工程让 Agent 动手前，先让它**列出打算改哪些文件、怎么改**，确认后再执行（见第 02 篇）。

## 5. 快速参考卡片

```text
四类：补全(写得快) / 对话(想得清) / Agent(改得全) / 本地(安全)
个人：免费=灵码/Codeium补全 + DeepSeek/豆包对话；付费=Copilot/Cursor + Claude
公司内网：企业授权版 或 本地 Ollama+Qwen/DeepSeek-Coder，源码不出内网
C++ 提效关键：导出 compile_commands.json、说明交叉编译/标准/库版本
选工具四看：C++效果、多文件工程能力、数据是否出内网、价格
```

## 6. 常见问题与坑

| 问题 | 说明与对策 |
| --- | --- |
| 装了一堆工具却没提效 | 工具在精不在多，固定"补全+对话+Agent"三件套，形成肌肉记忆 |
| AI 不知道我工程里的自定义类型 | 没给工程上下文；用 codebase 索引、贴相关头文件、提供 compile_commands.json |
| 补全的 API 编不过 | 可能是幻觉或版本不符；查官方文档/头文件确认，别硬抄（详见第 05 篇） |
| 把公司代码贴公网模型 | 合规风险；脱敏或改走本地/企业版 |
| 追新工具焦虑 | 工具半年一换，底层"提示词+验证+工程上下文"的能力不变，先把方法练好 |
