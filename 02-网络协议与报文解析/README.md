# 网络协议报文解析（10 篇 · 抓包 + 逐字节 + 手写解析）

> 本节目标：一套"**对着真实字节学网络**"的模块——从物理/数据链路层一路向上到应用层，逐字段拆报文。编号顺序即 **OSI 由下到上**：先看链路上怎么成帧（以太网、CAN/工业总线），再到网络层 IP、传输层 TCP/UDP、应用层 HTTP/工业规约，最后用 tcpdump/Wireshark 抓包、用 C++/Python 手写解析器。概念性的网络体系见 `../01-C++技术体系/03-计算机网络编程/01-计算机网络协议详解.md`，本模块强调"报文长什么样、怎么抓、怎么解析"。

## 协议分层与封装地图（编号即自下而上的阅读顺序）

```text
应用层    HTTP/HTTPS/TLS、Modbus TCP、IEC104、DNS、DHCP      ← 05、06、07 篇
传输层    TCP(可靠/面向连接)  UDP(无连接)                    ← 04、05 篇
网络层    IP(寻址/路由/分片)、ICMP(ping)、ARP(IP→MAC)         ← 03 篇
数据链路层 以太网帧(MAC/VLAN/MTU)、CAN/CAN FD、LIN、RS485     ← 01、02 篇
─────────────────────────────────────────────
物理层    网线/光纤/差分双绞线/串口(RTU、CAN 走物理总线，不经以太网)
封装方向：发送时自上而下加首部；接收时自下而上剥首部
```

> 为什么链路层放两篇：**01 讲以太网**（互联网/局域网的链路层），**02 讲 CAN 与车载/工业总线**（汽车、机器人、工控设备里另一大类"会仲裁、差分抗干扰、多主广播"的链路层），两者并列、都在 IP 之下。

## 学习路径（由下到上）

```text
打地基（数据链路层）
   01 分层与以太网封装（大小端/对齐/以太网怎么成帧）
   02 CAN 与车载/工业总线（CAN 仲裁/帧/错误机制、CANopen/J1939/UDS、LIN/FlexRay/车载以太网、SocketCAN）
      ↓
网络层  03 IP/ARP/ICMP（寻址、分片、ping）
      ↓
传输层  04 TCP 报文 + 三次握手四次挥手【核心，对应模块名】
        05 UDP/DNS/DHCP（无连接与常见应用）
      ↓
应用层  06 HTTP/HTTPS/TLS/WebSocket（文本与加密握手）
        07 Modbus/IEC104 工业报文【工业规约，重点】
        09 MQTT 发布订阅（物联网低带宽报文）
        10 RTMP 推流（音视频直播协议）
      ↓
落地    08 抓包分析 + 手写报文解析器（checksum/粘包半包，落成 C++/Python 代码）
```

## 怎么用这套笔记

1. **边抓边学**：每篇都对着真实抓包看，命令在 08 篇；CAN 用 `candump`/Wireshark 抓 `can0/vcan0`。光看结构图记不牢。
2. **能手写**：看到一段 hex 能逐字节标出字段，能手写 checksum 和最小解析器，才算掌握。
3. **连到工程**：报文解析直接服务于 Reactor 服务器（半包/粘包）、工业网关规约栈、车载/工业总线接入、面试手写题。
